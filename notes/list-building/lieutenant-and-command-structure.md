# List-Building Strategy — Lieutenant and Command Structure

The Lieutenant should usually do more than merely satisfy the Lieutenant requirement. Good command structures either **minimize the cost and risk of the Lieutenant**, **convert the Lieutenant resource into useful Orders**, or **turn the Lieutenant into a genuinely productive command/attack piece**.

A useful default rule is:

> **Either take the cheapest practical Lieutenant package, take a Lieutenant with a strong command ability/order advantage, or take an apex Lieutenant that can productively use its own Lieutenant Order(s).**

Mid-cost Lieutenants with no important advantage are often unattractive. They cost too much to be efficient decoys or cheerleaders, but may still be too fragile or too mediocre to justify active use.

## Preferred Lieutenant architectures

### Cheap Lieutenant + identical decoy + NCO

This is one of the strongest generic command packages when available.

Use:

- the cheapest practical Lieutenant profile;
- one non-Lieutenant trooper with the **same visible profile/equipment** as an informal Lieutenant decoy;
- an NCO that can productively spend the Lieutenant resource.

The project term **Lieutenant decoy** is informal and does not refer to the Infinity Decoy skill. The purpose is simply to make two apparently identical models plausible Lieutenant candidates.

The main weakness of a cheap defensive Lieutenant is normally that its Special Lieutenant Order is difficult to use without revealing or exposing it. NCO fixes that problem by converting the Lieutenant Order into a Tactical Order for the NCO.

NCO does **not** require the Lieutenant and NCO to be in the same Combat Group. This makes the package especially flexible: the Lieutenant can remain protected in one group while the NCO operates in another.

This package becomes exceptionally efficient with **Lieutenant (+1 Order)**, because the NCO can use each generated Special Lieutenant Order.

### Protected Lieutenant + NCO

The same NCO principle applies even when the Lieutenant is not especially cheap.

A Lieutenant protected by strong deployment, Marker State, armour, Fireteam position, bodyguards, or a difficult-to-reach location can remain passive while the NCO converts the command resource into active Orders.

This is attractive when the Lieutenant profile itself brings passive value but has little reason to spend Orders personally.

Examples of useful passive value include:

- Counterintelligence;
- specialist capability that is only needed occasionally;
- hacking or support utility;
- defensive equipment;
- Fireteam membership;
- a strong defensive chassis.

### Protected Strategos Lieutenant

Strategos is one of the cleanest answers to the otherwise-wasted Lieutenant Order problem.

Strategos L1 converts Special Lieutenant Orders into **Regular Orders in the Lieutenant's Combat Group**, making the resource fully flexible instead of tying it to the Lieutenant or an NCO.

Strategos also improves deployment by allowing two reserve troopers instead of one.

Because Strategos requires the user to be the Lieutenant and its benefits are extremely valuable, the Strategos model should normally be **physically protected**. If the Lieutenant is lost, the army loses both the Lieutenant and the command advantage.

Strategos and NCO generally compete for the same Lieutenant resource. If Strategos converts the Special Lieutenant Order into a Regular Order, there is no Lieutenant Order left for NCO to use.

### Strategos L2

Strategos L2 is rare and especially strong.

In addition to the L1 benefits, it allows one trooper to move to a different Combat Group during the Tactical Phase **without spending a Command Token**.

This makes the second Combat Group easier to build around models that may later need to reinforce Group 1, and preserves Command Tokens for Coordinated Orders, rerolls, Fireteam rebuilding, or other uses.

### Active attack Lieutenant + Chain of Command

An aggressive Lieutenant can be excellent because the Lieutenant Order becomes an extra attack/movement Order on a piece that already wants to consume Orders.

Typical candidates are:

- apex gunfighters;
- mobile HI;
- TAGs;
- strong motorcycles/VH;
- durable assault characters;
- models with strong deployment or escape tools.

The default support for an aggressive Lieutenant is **Chain of Command**.

Chain of Command allows the army to avoid Loss of Lieutenant when the Lieutenant is lost or Isolated, provided the Chain of Command trooper is on the table and not itself Null or Isolated.

This lets the Lieutenant be used more aggressively without risking the entire next turn's Order economy.

The downside is package cost: an expensive Lieutenant plus a dedicated Chain of Command model can consume a lot of points. Prefer Chain of Command profiles that also provide useful specialist, support, or combat value.

### Extremely strong/mobile active Lieutenant without Chain of Command

Chain of Command is preferred for aggressive Lieutenants, but it is not mandatory in every case.

An apex Lieutenant can sometimes justify operating without Chain of Command when it is:

- exceptionally durable;
- very mobile;
- difficult to reach;
- able to attack from favorable positions and retreat;
- already such a major part of the army that losing it would be disastrous regardless of Lieutenant status.

This is a conscious risk choice. The benefit is avoiding the Chain of Command tax and allowing more points to remain in the active plan.

The stronger and safer the Lieutenant is, the more reasonable this becomes. A merely "good" mid-cost attacker usually does not justify the same risk.

### Passive Lieutenant with a useful second role

A passive Lieutenant is much better when it does something useful while remaining protected.

Examples include:

- specialist;
- hacker;
- support piece;
- Counterintelligence carrier;
- Fireteam member;
- defensive ARO or short-range protection;
- command utility.

The ideal passive Lieutenant contributes without needing to spend its own Lieutenant Order or reveal itself unnecessarily.

Chain of Command may still be worthwhile if the Lieutenant is strategically important, exposed by mission requirements, or embedded in a Fireteam that is likely to fight.

### Lieutenant under Camouflage, Holoprojector, or similar protection

Marker-state or identity-misdirection Lieutenants can be excellent because they make direct Lieutenant hunting more difficult.

Useful forms include:

- Camouflage/Hidden Deployment where legal;
- Holoprojector or similar identity confusion;
- multiple visually plausible Lieutenant candidates;
- deployment positions that make the real Lieutenant difficult to distinguish or reach.

This is especially valuable when the Lieutenant is passive and the list can exploit its Order through NCO or another command mechanic.

Do not spend the Lieutenant Order casually if doing so unnecessarily reveals which model is the Lieutenant or forces it into danger.

## Inspiring Leadership

Inspiring Leadership is **list-defining** when the faction or sectorial has access to several useful Irregular troops.

When the Inspiring Leadership user is the Lieutenant and active on the table, qualifying troops that provide Orders become Regular and gain Courage. This can radically change the Order economy of armies with multiple Irregular warbands or support pieces.

The other major benefit is the special Coordinated Order: the Lieutenant can declare a Coordinated Order including itself by spending only the Special Lieutenant Order, with no Command Token or additional Orders required.

This matters beyond the immediate movement/attack because it preserves Command Tokens for:

- Combat Group transfers;
- rerolls;
- Fireteam rebuilding;
- other Coordinated Orders;
- mission-specific command uses.

Therefore, evaluate Inspiring Leadership not merely as a Lieutenant skill but as an **army-building engine**. Its value rises sharply with the number and quality of Irregular troops available.

Because the effect depends on the Inspiring Leadership Lieutenant remaining active, protecting that Lieutenant is especially important.

## Lieutenant (+1 Order)

**Lieutenant (+1 Order)** is one of the strongest command bonuses because every good Lieutenant architecture can exploit it:

- active Lieutenant: two extra personal Orders;
- NCO package: two Orders available to the NCO;
- Strategos: two Special Lieutenant Orders can be converted into flexible Regular Orders.

It is particularly valuable when the Lieutenant resource is already easy to use. A +1 Order Lieutenant that must remain hidden and has no NCO or Strategos can still waste much of the advantage.

## SWC discounts and rebates

Lieutenant profiles can be attractive even when the underlying trooper is not the ideal command piece if the Lieutenant option provides a meaningful **SWC discount or rebate**.

Examples include:

- a weapon that normally costs 1–1.5 SWC becoming 0 SWC as Lieutenant;
- an LT profile that provides positive SWC;
- an LT version that frees enough SWC to enable another important attack or support profile elsewhere.

Treat this as part of the Lieutenant package's value. A profile may effectively contribute to the list by making another premium gun or hacking piece affordable.

## Counterintelligence

Counterintelligence is a strong bonus on a Lieutenant or another already-protected command model because it adds first-turn command protection without requiring active use.

It reduces the impact of the opponent's Strategic Use of Command Tokens by either:

- reducing the number of Orders the opponent can nullify to one; or
- increasing the first-turn Command Token-use limit imposed by the opponent to two.

This is particularly valuable in aggressive lists where preserving first-turn tempo matters.

Counterintelligence does not need to be on the Lieutenant, but when it is bundled onto a Lieutenant you already intended to protect, it is efficient role compression.

## Tough expensive Lieutenant as double-duty

Sometimes simply making an already-expensive, resilient model the Lieutenant is efficient.

The model already consumes a large part of the army's points and already wants Orders. Making it Lieutenant can:

- avoid paying for a separate dedicated Lieutenant;
- give the model another Order it can actually use;
- gain an SWC discount or rebate;
- consolidate command and attack roles.

This can be rational even without Chain of Command when the model is so central that losing it would already severely damage the army.

However, Lieutenant status increases the consequence of losing it, so the model should be genuinely durable/mobile rather than merely expensive.

## General decision rules

When selecting a Lieutenant package:

1. **If a good NCO exists**, cheap/protected Lieutenant + decoy where appropriate + NCO is often the first option to test.
2. **If no useful NCO exists**, prefer Strategos or an active Lieutenant that can productively spend its own Order.
3. **If using an aggressive Lieutenant**, try to include Chain of Command unless the Lieutenant is exceptionally durable/mobile or the package cost is prohibitive.
4. **If using a cheap conventional Lieutenant**, add one identical-profile decoy when practical.
5. **If the Lieutenant has +1 Order**, prioritize command structures that can actually exploit both Orders.
6. **If an LT profile offers an SWC discount/rebate**, include that value when comparing otherwise similar choices.
7. **If Inspiring Leadership is available with several good Irregular troops**, evaluate the entire list around it rather than treating it as a small profile upgrade.
8. **Prefer command profiles that double-duty.** Counterintelligence, specialist capability, durable chassis, NCO synergy, Strategos, Inspiring Leadership, +1 Order, Marker protection, or SWC rebates all make a Lieutenant slot more efficient.

## Profiles to be skeptical of

A **mid-cost Lieutenant without a significant advantage** is usually the least attractive command profile.

Be skeptical when the Lieutenant:

- is meaningfully more expensive than the cheapest option;
- cannot use its own Lieutenant Order safely;
- has no NCO support;
- has no Strategos/Inspiring Leadership/extra Order;
- provides no meaningful SWC advantage;
- is not durable enough to be an apex Lieutenant;
- lacks Marker protection or strong identity concealment;
- offers no useful passive role.

In practice, Lieutenants often cluster toward one of three ends:

- **cheap and hidden/protected**;
- **command-enhancing** through Strategos, Inspiring Leadership, +1 Order, Counterintelligence, NCO support, or SWC economy;
- **apex active pieces** that can directly exploit the Lieutenant resource.
