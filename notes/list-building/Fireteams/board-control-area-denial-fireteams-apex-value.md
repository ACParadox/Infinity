# Board Control / Area Denial Fireteams — N5.3 Apex and Value

**Scope:** Infinity N5.3 / ITS 18, 300-point all-comers lists. **Review date:** 19 November 2026. This is an **editorial cross-faction ranking** of *actual linked 2–5-trooper Fireteams*, not a ranking of every army's independent midfield mines, Camo tokens, deployable Repeaters, warbands, or network support. Costs and chart permissions are taken from the repository's pinned September 2026 Infinity Army rosters; tournament reports and videos are identified separately from reconstructed or designed compositions.

**Definition of the role:** make one or more approaches, objectives, firing lanes, or hacking corridors costly to traverse or occupy. Reward **persistent E/M / Adhesive / Jammer / mines / perimeter weapons**, credible **direct or speculative fire / templates**, **Repeater–hacker projection**, **vision denial**, and the ability to **survive, relocate and re-establish** those threats. A Fireteam that simply wins open-lane AROs belongs primarily in the [defensive/ARO](../../list-building/aro-units-apex-and-value.md) analysis; an assault link with Smoke but no lasting control is not automatically a top board-denial Fireteam.

**Interpretation:** White Company Hawkwood/Emily Fusilier Core, Druze Bayram Security E/M Core and StarCo Outrage E/M/network Haris lead because a credible **E/M grenade launcher** changes what areas a heavy opponent is willing to occupy while their teammates cover counterplay. Starmada Security control Core excels at **close/mid-range objective choke points**, and Imperial Service Wú Míng heavy cyber Core excels at **durable anti-heavy denial**. These are *not* claims that E/M is automatically the answer to every enemy: unhackable troops, open boards, negative-range engagements, poor Repeater placement and enemy Engineer support can change the order.

Ties are close qualitative calls, not mathematically calibrated scores.

## 3. Reproducible Fireteam recipes and chart provenance

Each line names **every paid Fireteam member**, using the pinned source's profile labels/options and **individual points/SWC**. "Same counts-as" labels in source files, not an assumed wildcard bonus, determine the printed level.

### How to choose by table and mission

- **Compact, objective-dense boards:** Starmada Security denial Haris, Starmada Security control Core, Corregidor Wildcat technical Core, Bakunin Riot / Taskmaster / Uhahu Core and Qapu's Disco variants rise; E/M mines, Adhesive, Jammer, template and mine-dispenser reach are meaningful.
- **Mid-range multi-lane boards:** White Company Hawkwood/Emily Fusilier Core, Druze Bayram Security E/M Core, StarCo Outrage E/M/network Haris and Onyx Unidron / Nexus / Kerr-Nau Core rise; E/M GL, linked snipers/rockets and projected hacking control crossings without requiring a forward rush.
- **Heavy TAG / HI opposition:** Imperial Service Wú Míng heavy cyber Core, Druze Bayram Security E/M Core, White Company Hawkwood/Emily Fusilier Core and Tunguska Securitate / Interventor / Tsyklon Core become more valuable for E/M, Repeater/Pitcher, TinBot and heavy gun reach. Against non-Hackable targets, downgrade *network-only* denial.
- **Low SWC or separate attack piece needed:** Starmada Security denial Haris, Bakunin Moderator network Core, Steel Phalanx Dactyl / K2 mine Duo, Starmada Security control Core and Acontecimento Regular FastPanda Core save resources for independent midfield screens and premium attackers. The ranking does **not** double-count those independent pieces as part of the Fireteam.
- **Coherency is a cost:** multiple listed weapons do **not** mean every member independently controls a distant objective while remaining in the Fireteam. If spreading out or breaking the link makes the plan better, reconsider whether the army's *unlinked* board-control package is actually superior.
