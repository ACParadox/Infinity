# List-Building Strategy — Order Efficiency

Order efficiency is broader than simply generating more Orders. A list can improve its Order economy by generating extra usable Orders, making restricted Orders more flexible, activating several useful pieces with one Order, reducing the number of Orders needed to reach a task, increasing the chance that each Order succeeds, and creating setup or support effects that multiply later activations.

A useful framework is:

> **Order efficiency = generate more usable Orders, make them easier to spend where needed, compress multiple useful actions into one activation, reduce movement/setup costs, increase success per Order, and create effects that make later Orders more productive.**

## 1. Order generation and Order density

This is the closest thing to pure Order efficiency: how many useful activations the army gets for its points and Combat Group slots.

Important mechanisms include:

- **Cheap Regular troops.** The simplest source of Order density: one Regular Order for minimal points, at the cost of one Combat Group slot.
- **Irregular troops with FT Master.** Cheap Irregular profiles can become Regular while part of the relevant Fireteam, producing unusually cheap Regular Orders.
- **Irregular troops with Inspiring Leadership.** When the list can regularize several useful Irregular troops, Inspiring Leadership can become an army-wide Order engine.
- **Lieutenant Orders.** An additional resource beyond the normal Regular Order pool, especially strong when the Lieutenant can actually use the Order productively.
- **Lieutenant (+1 Order).** Provides two Lieutenant Orders, but is only exceptional when both Orders can be exploited.
- **NCO.** Converts an otherwise awkward Lieutenant resource into useful activations on an NCO.
- **Strategos.** Makes the Lieutenant resource substantially more flexible and can improve Combat Group management.
- **Tactical Awareness.** A troop provides its normal Regular Order plus an additional Tactical Order for itself. This is especially valuable on a model that already wants to activate every turn.
- **Impetuous.** Provides a self-funded activation that can produce movement, Smoke, trading, or attack value without consuming the main Regular pool.
- **Peripherals.** Increase the amount of board presence and useful action attached to one Controller and one Combat Group slot.

Two related concepts are useful:

> **Order density = usable Orders per point.**

> **Slot efficiency = useful activations, capabilities, or board presence per Combat Group slot.**

A very cheap Regular cheerleader may have excellent Order density but only modest slot efficiency. A Tactical Awareness combat piece or Controller plus Peripheral can have excellent slot efficiency because one slot represents more than one useful activation or body.

## 2. Order flexibility and avoiding stranded Orders

Generating Orders is not enough. They need to exist in a Combat Group with models capable of spending them.

A model can be individually efficient and still be badly placed if its group cannot exploit its Orders.

Examples:

- a primary attacker with only three Regular Orders available is inefficient even if the attacker itself is excellent;
- a passive Flash Pulse REM in a full Group 1 can be less useful than placing a scalable secondary attacker there if Group 2 is starved;
- a healthy Group 2 normally benefits from one scalable Order sink plus several models that remain useful on zero to two Orders;
- a 9/6 split can preserve a vacancy for promoting a Group 2 piece into Group 1 after attrition;
- Strategos L2 can improve this further by moving one trooper between Combat Groups without spending the normal Command Token.

A useful principle is:

> **Order efficiency includes putting Orders beside models that can productively spend them.**

This is why Combat Group architecture is part of Order efficiency rather than merely list organization.

## 3. Command Token efficiency

Command Tokens are a secondary Order-economy resource. They usually do not generate Orders directly; instead they **deny, convert, redistribute, or compress** activations.

### Deny enemy Orders

Spending a Command Token to remove Orders from the opponent's first-turn pool creates an immediate Order differential.

This is particularly strong when the removed Orders come from the opponent's main attack group and reduce the reach or depth of an alpha strike.

### Convert Irregular to Regular

Turning an Irregular Order into a Regular Order is valuable because it transfers a restricted personal resource into the Combat Group's flexible pool.

The important value is not merely "+1 Regular Order." It is the ability to redirect the Order from a cheap Irregular model to a much stronger active piece.

For example, converting the Order of an 8-point Irregular warband may enable another activation by a TAG, apex gunfighter, or critical specialist.

### Switch Combat Groups

Moving a trooper between Combat Groups does not create an Order immediately, but it redistributes future Order generation and Order sinks.

This is especially valuable after casualties, when one group has lost models and another still contains useful survivors.

### Coordinated Orders

A Coordinated Order uses one Regular Order plus a Command Token to activate several compatible troops.

This is especially efficient for:

- moving several independent models;
- establishing Suppressive Fire;
- repositioning multiple defensive pieces;
- coordinating Disposable attacks;
- advancing several specialists or Camo pieces;
- accomplishing work with models that are not already receiving Fireteam activation compression.

Inspiring Leadership is notable because it can provide a special Coordinated Order while preserving Command Tokens for other uses.

### Extra Command Tokens and Strategos L2

Anything that increases available Command Tokens, or performs a normally Command-Token-funded function without spending one, improves the army's secondary Order economy.

The more the list depends on rerolls, Combat Group transfers, Coordinated Orders, Fireteam rebuilding, or Irregular conversion, the more valuable these effects become.

## 4. Activation compression

Another form of Order efficiency is increasing the number of useful things that happen when one Order is spent.

The key question is:

> **How many useful assets advance, reposition, attack, or support the plan when I spend one Order?**

### Fireteams

A Fireteam can move several models with one Order instead of spending separate Orders on each.

This is most efficient when at least two members genuinely need to occupy roughly the same place.

Examples include:

- attacker + specialist;
- attacker + vision-control piece;
- long-range ARO + short-range/template protection;
- Hacker + Pitcher carrier;
- combat piece + Doctor/Engineer support.

A Fireteam whose members constantly want to split in different directions gains much less movement efficiency.

Fireteams can also improve roll efficiency through +SD, Discover/Dodge bonuses, +BS, and Sixth Sense depending on Fireteam level.

### Peripherals and Palbots

Peripherals provide several kinds of compression simultaneously:

- Controller and Peripheral activate together;
- the Peripheral extends physical reach without moving the Controller all the way to the task;
- one Combat Group slot can represent several useful bodies;
- Doctor/Engineer support can act remotely through a Palbot.

This makes Peripherals especially valuable for support pieces that otherwise waste several Orders walking toward a casualty or objective.

### G: Jumper

G: Jumper similarly creates exceptional slot and positional efficiency by distributing useful presence across several bodies while concentrating the troop's active resource.

The value is not simply additional models; it is the ability to already have the relevant body near the job instead of spending several Orders transporting one model around the table.

## 5. Movement and positional Order efficiency

Many skills do not generate extra Orders. They make each Order cover more useful distance or eliminate movement Orders entirely.

### Raw movement efficiency

Important tools include:

- high MOV;
- Motorcycle or Vehicle movement;
- Super-Jump;
- Climbing Plus;
- Terrain (Total).

These increase the amount of meaningful movement produced by one Order or allow routes that would otherwise require ladders, stairs, detours, or several separate movements.

### Deployment compression

Deployment skills are often even more efficient because they provide positional value before the first Active-Turn Order is spent.

Important examples:

- Forward Deployment;
- Infiltration;
- Airborne Deployment / Combat Jump / Parachutist;
- Strategic Deployment;
- reserve-deployment advantages.

An infiltrator that starts near an objective or attack lane may effectively receive several free movement Orders during Deployment.

Airborne Deployment can similarly bypass the entire approach path and begin directly on the relevant flank or rear area.

### Marker-state movement

Camouflage does not increase MOV, but it can improve **risk-adjusted movement efficiency**.

A Camo Marker can:

- move without immediately accepting normal gunfights;
- force Discover attempts;
- create uncertainty about whether an ARO is worth declaring;
- approach a target while preserving Surprise Attack;
- cross areas where a revealed troop would first need to remove or bypass ARO pieces.

The model is not physically moving farther, but it may reach the intended position with fewer clearing or recovery Orders.

## 6. Roll and task efficiency

A major component of Order efficiency is simply succeeding on the first attempt instead of spending additional Orders repeating the same task.

### Specialists

Higher WIP reduces the expected number of Orders required for objectives and many support tasks.

The most efficient specialist combines:

- strong WIP;
- good starting position;
- enough mobility to reach the objective cheaply;
- protection or Marker State that prevents the approach from becoming expensive.

A WIP 15 specialist already beside the objective can be dramatically more efficient than a WIP 12 specialist starting in the Deployment Zone.

A useful shorthand is:

> **Specialist efficiency = success probability × positional access.**

### Combat pieces

Attack efficiency works the same way.

A good attacker reduces the expected number of Orders needed to remove a target through combinations of:

- strong BS, WIP, PH, or CC as appropriate;
- high Burst;
- +SD;
- good range bands;
- Mimetism or Surprise Attack;
- MSV or other counter-MOD tools;
- useful ammunition;
- Fireteam bonuses;
- target-appropriate attack modes.

A 50-point attacker that reliably solves a problem in one Order can be more **Order-efficient** than a cheaper piece that requires four attempts.

Therefore:

> **Points efficiency and Order efficiency are related, but they are not the same thing.**

## 7. Delivery-tool efficiency

Support weapons and equipment often require a roll to establish an effect. Better attributes and modifiers reduce the number of Orders wasted on failed setup.

Important examples include:

- high-BS Pitcher carriers;
- +SD or Fireteam bonuses on Pitchers;
- X-Visor on Pitchers to improve poor Range MODs;
- high-PH Smoke throwers;
- good BS on Disco Ballers;
- good BS on MediKits;
- good BS on GizmoKits.

The relevant question is:

> **How many Orders should I expect to spend before the support effect is successfully established?**

For Pitchers specifically, good BS, +SD, Fireteam bonuses, range quality, X-Visor, Disposable support, and safe firing positions all improve network-projection efficiency.

## 8. Setup efficiency and Turn-0 value

Some models create useful game state before anybody spends an Active-Turn Order.

This is one of the strongest forms of efficiency because it is effectively free setup.

### Minelayer

Minelayer creates board control during Deployment rather than requiring an Order to place the first Mine or other legal Deployable.

A cheap no-SWC Minelayer can therefore be much more efficient than an equally priced pure cheerleader.

### Repeaters and Turn-0 network

Native Repeaters, especially on Forward Deploying or Infiltrating troops, can create hacking coverage immediately.

Minelayer + Deployable Repeater can create an additional network node during Deployment.

This can provide midfield denial or hacking access before the first active Order is spent.

### Strategic Deployment

Strategic Deployment can move several troops forward before Turn 1. If those models already wanted to advance, the skill can represent several movement Orders saved across the army.

### Reserve deployment and deployment quality

Good reserve or set-aside deployment options do not literally generate Orders, but they can prevent later repositioning costs.

Deploying an attacker, specialist, or network piece into the correct matchup or lane can save several Orders that would otherwise be spent crossing the table or changing flanks.

A useful concept is:

> **Turn-0 efficiency = useful board state created before the first Active-Turn Order is spent.**

## 9. Information and obstacle-clearing efficiency

Enemy Camouflage, Hidden information, Mines, and similar obstacles can impose an Order tax before the real attack or objective work begins.

Tools that reduce that tax are therefore part of Order efficiency.

Important examples include:

- Sensor;
- Discover bonuses;
- MSV where relevant;
- templates;
- Intuitive Attack;
- Coordinated Discover or other multi-model solutions.

Sensor is particularly efficient when one Order can reveal or pressure several markers instead of requiring repeated Discover attempts.

The relevant comparison is often:

> **How many setup/Discover Orders does this tool save before my actual attack can begin?**

## 10. Network projection as Order efficiency

Hacking networks are especially easy to evaluate through the Order-efficiency lens.

### Turn-0 network

The strongest Turn-0 network tools include:

- native Repeater + Forward Deployment/Infiltration;
- Minelayer + Deployable Repeater;
- Minelayer + Deployable Repeater + Forward Deployment/Infiltration.

These establish useful hacking presence for zero Active-Turn Orders.

### Active Pitcher projection

Pitchers trade a shooting Order for a new network node.

The best Pitcher platforms maximize the chance that the node is established on the first attempt through:

- high BS;
- +SD;
- Fireteam +BS;
- favorable range;
- X-Visor;
- Baggage or other Disposable support;
- safe firing geometry.

One successful Pitcher Order can enable several later hacking Orders from multiple Hackers, making it a strong multiplicative investment.

### Mobile Repeater projection

A fast, relatively expendable native-Repeater troop or Deployable-Repeater carrier can physically move the network into position.

Useful traits include:

- high MOV;
- Motorcycle;
- Climbing Plus or Super-Jump;
- Forward Deployment or Infiltration;
- low enough cost that sacrificing the carrier is acceptable;
- enough durability, Camo, or Mimetism to cross danger zones.

The ideal exchange is spending one or two Orders on the carrier to create a decisive Repeater position that enables many later hacking activations.

## 11. Support efficiency

Support tools often save Orders indirectly by making later movement, attacks, recovery, or deployment more efficient.

### Vision control

Smoke, Eclipse, White Noise, Disco Balls, and similar effects can let the army bypass an ARO instead of spending several Orders fighting it.

One successful vision-control Order may allow:

- a Fireteam to cross a dangerous lane;
- several later models to move safely;
- an MSV attacker to create a favorable engagement;
- a CC piece to approach;
- specialists to reach objectives without clearing every defender.

Vision control is therefore strongest when several later activations exploit the same effect.

### Doctor and Engineer support

Doctor/Engineer efficiency depends on:

- WIP or relevant success value;
- distance to the casualty;
- Peripheral access;
- availability of Command Token rerolls;
- value of the recovered model.

Palbots are especially efficient because they can turn several Orders of Doctor/Engineer movement into one remote support activation.

Command Token rerolls are also an Order-efficiency tool: spending the token can prevent the army from wasting additional movement or replacement effort after a failed recovery roll.

Recovering a TAG, premium attacker, or key specialist can restore a model capable of converting many future Orders into useful work.

### EVO Hacker and Combat Jump

Controlled Jump improves the reliability of Combat Jump deployment.

This is an Order-economy effect because a failed or poor deployment can destroy the intended attack sequence or force several additional movement Orders.

EVO support is most efficient when the list also gains value from several other EVO functions instead of paying for the model purely to support one isolated deployment roll.

# Efficiency for points and slots

The previous sections describe how Orders are generated and spent. The following heuristics focus specifically on **how cheaply the army can buy those efficiencies**.

## Cheerleaders

The baseline cheerleader is a cheap Regular troop that contributes one Order while demanding few or no active Orders itself.

A rough minimum-cost target is usually around the cheapest Regular profiles available to the army, often roughly 7–10 points.

Better cheerleaders provide passive value in addition to the Order:

- Repeater;
- Flash Pulse;
- Minelayer;
- cheap specialist capability;
- Baggage;
- Lieutenant decoy function;
- ARO speedbump;
- Fireteam glue;
- Counterintelligence or other passive utility.

A no-SWC Minelayer is especially attractive because it creates Turn-0 board control without reducing the SWC budget.

Very cheap Irregular troops can become exceptional Order generators when regularized through FT Master or Inspiring Leadership.

## Impetuous warbands

A strong low-cost warband often sits roughly in the 6–10 point range and combines several kinds of efficiency:

- cheap body;
- Regular or Irregular Order;
- Impetuous activation;
- Smoke/Eclipse;
- template threat;
- CC threat;
- Forward Deployment or Camo on some profiles.

The best warbands provide useful movement or vision control before eventually trading into something more expensive.

Their main efficiency comes from producing multiple forms of value from a very small points investment.

## Tactical Awareness

Tactical Awareness is best viewed as:

> **A two-Order piece occupying one Combat Group slot.**

It is strongest on models that already have something useful to do with the Tactical Order every turn, especially:

- TAGs;
- attack REMs;
- mobile specialists;
- Fireteam active pieces;
- models that need one movement/setup Order before consuming the shared Regular pool.

Tactical Awareness is much weaker on a passive model that technically receives the extra Order but rarely wants to activate.

## Lieutenant (+1 Order)

Lieutenant (+1 Order) is exceptionally efficient when the list has a reliable way to spend both Lieutenant Orders.

Best cases include:

- LT (+1) + NCO;
- LT (+1) + Strategos;
- durable active Lieutenant.

It is far less efficient on a fragile passive Lieutenant with no NCO or Strategos that cannot safely use the Orders.

## NCO

NCO is best evaluated as an **Order-unlocking mechanism**.

If the Lieutenant would otherwise remain hidden or passive, the NCO can turn the Lieutenant Order into useful movement or attack work.

If the Lieutenant already wants to use its own Order actively, NCO adds much less Order-economy value.

## Fireteams

Fireteams provide two distinct efficiencies:

1. **Movement compression:** several models move on one Order.
2. **Roll/combat efficiency:** Fireteam bonuses can improve the chance that an attack, Discover, Dodge, or other supported action succeeds.

The central heuristic is:

> **A Fireteam is most Order-efficient when at least two members already want to be in roughly the same place.**

Do not form a Fireteam purely for theoretical movement efficiency if the members' jobs constantly pull them in different directions.

## Mobility

For pure positional Order savings, a useful rough hierarchy is:

1. **Free positioning:** Infiltration, Forward Deployment, Strategic Deployment, Airborne Deployment.
2. **Very fast movement:** Motorcycle, Vehicle, high MOV.
3. **Terrain/path bypass:** Climbing Plus, Super-Jump, Terrain (Total).

Skipping several movement Orders entirely is usually more efficient than merely moving slightly farther each Order.

## Support

Support pieces are efficient when one setup Order improves several later activations.

Vision control is the clearest example: one Smoke, Eclipse, White Noise, or Disco Ball action can allow several later troops to bypass an otherwise expensive ARO problem.

Support should therefore be evaluated by the **downstream Orders it saves or improves**, not just by the cost of the support action itself.

# Quick evaluation checklist

When evaluating a troop or package for Order efficiency, ask:

1. **Does it generate extra resources?** Regular Order, Impetuous, Tactical Awareness, Lieutenant (+1 Order), Inspiring Leadership, FT Master.
2. **Does it make restricted resources more flexible?** NCO, Strategos, Combat Group placement, Command Token conversion or transfer.
3. **Does one Order activate more useful assets?** Fireteam, Peripheral, Coordinated Order, G: Jumper positional coverage.
4. **Does it save movement Orders?** Infiltration, Forward Deployment, Airborne Deployment, high MOV, Motorcycle, Climbing Plus, Super-Jump, Palbot.
5. **Does it improve success per Order?** High WIP/BS/PH/CC, Burst, +SD, range quality, Fireteam bonuses, Sensor.
6. **Does it create value before Turn 1 or multiply later Orders?** Minelayer, Turn-0 Repeater coverage, Strategic Deployment, reserve deployment, Smoke, Pitcher, EVO support.
7. **Is the model in the correct Combat Group?** Extra Orders are wasted if the group cannot use them effectively.
8. **Does the profile justify its points and slot?** Order density and slot efficiency should both be considered.

The best Order-efficient units often score in several categories at once. A cheap Forward Deploying Minelayer specialist with a Repeater, for example, may contribute an Order, save movement, create Turn-0 board control, project a hacking network, and score objectives without demanding many active Orders.
