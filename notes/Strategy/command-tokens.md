# List-Building Strategy — Command Tokens

Command Tokens are scarce, flexible resources. Their value comes less from any one effect than from converting them into the kind of efficiency, recovery, or restructuring the army needs at the right moment.

A useful way to think about them is:

- **Strategic disruption** — mostly Turn 1;
- **Order-pool smoothing and restructuring** — converting or relocating Orders;
- **Recovery insurance** — Doctor, Engineer, Possessed, Guts;
- **Multi-model efficiency** — Coordinated Orders;
- **Fireteam reconstruction**;
- **preplanned utility** — Speedballs.

## Second player: usually remove two Orders

When going second, removing two Regular Orders from the opponent's first-turn Order Pool is usually the strongest default Procedural Strategic Use when legal.

The opponent must have more than ten total Regular + Irregular + Tactical Orders for this option to be available, with Hidden Deployment and off-table Airborne Deployment troops excluded from that threshold. Counterintelligence reduces the loss to one Regular Order.

Usually remove both Orders from the Combat Group expected to carry the opponent's main Turn-1 plan. Splitting them can be worthwhile if two groups contain separate critical attack packages.

Order removal is generally preferable to the alternative Turn-1 Procedural options unless there is a specific reason to limit the opponent's Command Token use or begin with a particularly valuable model in Suppressive Fire.

## Speedballs

Speedballs are best treated as a **planned utility package**, not as an automatic use of a Command Token.

One Command Token provides two Speedballs:

- one item is chosen;
- the other is random.

The most reliable reason to buy them is usually to select a recovery item the list expects to exploit:

- **VitaPack** — deterministic recovery for a valuable VITA model;
- **AutoRepairS** — particularly attractive insurance for an expensive STR model such as a TAG or important REM;
- **Switch On** — deterministic recovery from IMM-A, IMM-B, Isolated, or Stunned.

The random second Speedball is bonus value rather than the primary reason to spend the token.

Jetpack, Overkill, and NanoShield can also produce strong plays, but are harder to build around because the second Speedball is random and Speedballs must still be physically collected and used.

Speedballs become more attractive when:

- the army has an expensive centerpiece with weak Doctor/Engineer support;
- the chosen recovery effect protects a key list plan;
- disposable-heavy attack pieces can exploit Overkill;
- a specific movement route makes Jetpack valuable;
- the army has **Lieutenant (+1 Command Token)** or other reasons its Command Token budget is unusually comfortable.

The main opportunity cost is that spending a Token on Speedballs before the game leaves fewer Tokens for group restructuring, rerolls, Fireteam reconstruction, or Coordinated Orders.

## Doctor and Engineer rerolls

Command Tokens are excellent recovery insurance, but the rerolls are restricted:

- Doctor rerolls apply when using Doctor on a trooper with a **Cube**;
- Engineer rerolls apply when using Engineer on a trooper with **Remote Presence**.

The reroll does not require a new Order and does not generate a new ARO.

Spend these Tokens in proportion to the value of the patient and the importance of the current game state. Rerolling a repair on an apex TAG, key Remote Presence attack piece, Lieutenant, or mission-critical specialist can be an excellent exchange. Rerolling a low-value model simply because the option exists often is not.

## Convert an Irregular Order to Regular

A Command Token can convert one Irregular Order into a Regular Order in that trooper's Combat Group for the current Turn.

This is best understood as:

> **1 Command Token -> 1 flexible Regular Order.**

That is valuable when the original Irregular Order would otherwise be difficult or impossible to use productively and another model in the group needs one additional Order.

Good uses include:

- funding one more important attack;
- reaching an objective;
- retreating or repositioning an exposed attacker;
- late-game scoring;
- converting an otherwise wasted Irregular Order when future Command Token needs are low.

Do not convert automatically. Early in the game, preserving the Token for recovery, Fireteam reconstruction, or Combat Group restructuring may be better.

## Combat Group transfer

Moving a trooper to a different Combat Group is one of the strongest mid-game Command Token uses.

Executive Command Token use occurs during the Tactical Phase before Order Count. This means a surviving Regular trooper moved from a secondary group into a depleted main group generates its Regular Order directly into the new group for that Turn.

This makes Combat Group transfer a form of **Order-economy insurance**.

It is especially good when:

- Group 1 has lost several members;
- Group 2 still contains a useful attacker, specialist, REM, or support piece;
- a previously secondary piece has become the army's main active-turn option;
- an Airborne trooper has arrived and now deserves access to the main Order Pool.

When constructing Group 2, it can be useful to include at least one trooper that would remain valuable if transferred into Group 1 after casualties.

## Coordinated movement

A Coordinated Order can activate up to four eligible troopers from the same Combat Group for one Regular Order and one Command Token.

Coordinated movement is often one of the best uses because Burst penalties do not matter when the goal is simply to Move or Move-Move.

Useful cases include:

- repositioning several unlinked models;
- moving Group-2 pieces into useful midfield positions;
- evacuating multiple troops from an exposed area;
- advancing several specialists toward later objectives;
- repositioning defensive pieces late in the turn;
- shifting multiple zone-scoring bodies efficiently.

The participants all activate and can generate AROs, so coordinated movement is strongest through safe routes rather than through overlapping enemy fire.

Fireteam members and Controllers/Peripherals cannot participate.

## Coordinated Suppressive Fire

Coordinated Suppressive Fire is one of the strongest end-of-turn efficiency plays for unlinked models.

For one Regular Order and one Command Token, up to four eligible troopers can enter Suppressive Fire at once.

This is especially valuable when several models have already advanced into useful positions and the active turn is nearly over.

Strong candidates include:

- midfield specialists;
- Mimetism troops;
- durable HI;
- models guarding objectives;
- short- and mid-range guns controlling likely approaches.

Fireteam members cannot participate in a Coordinated Order, and entering Suppressive Fire causes a trooper to leave a Fireteam. A deliberate late-turn sequence can therefore be:

> Fireteam completes its active-turn job -> voluntarily break or shed members -> coordinate several survivors into Suppressive Fire.

## Re-forming or creating a Fireteam

Creating a Fireteam during the game costs a Command Token.

This is very valuable when the Fireteam itself has been cancelled and the army needs to restore or restructure it immediately.

Do not confuse this with a single member merely leaving an otherwise intact Fireteam. A trooper who left can automatically rejoin at the end of the next States Phase if the Fireteam still exists and the trooper is again in coherency with the Fireteam Leader.

Spend the Token when:

- the actual Fireteam was cancelled;
- the team must be restored before the next States Phase;
- the desired new composition is different;
- rebuilding the team restores an important attacker, specialist, TinBot, or Fireteam Level bonus.

## Other emergency uses

Two less common uses are worth remembering:

- **automatic Guts success or failure** can preserve a key position or force a model out of danger;
- **cancel Possessed** can be game-saving when an expensive TAG or similar piece is compromised.

These are rarely planned expenditures, but the possibility increases the value of retaining at least one flexible Command Token into the mid- or late game.

## Practical priority

A useful default hierarchy is:

1. **Second player: remove two Orders** when legal.
2. **Critical recovery or restructuring:** Doctor/Engineer reroll, Combat Group transfer, Fireteam rebuild.
3. **High-efficiency planned action:** Coordinated movement or coordinated Suppressive Fire.
4. **Order smoothing:** convert an otherwise poor Irregular Order into a Regular Order.
5. **Speedballs:** when the selected item is part of a deliberate plan rather than speculative insurance.

The exact order changes by list. A TAG army may value Engineer recovery and AutoRepairS much more highly; an Irregular-heavy army may care more about order conversion; a Vanilla list with many independent pieces may exploit Coordinated Orders more often than a Fireteam-heavy sectorial.

## Command skills that replace normal Command Token expenditures

Some command skills should be evaluated not only for their printed effect, but for the **Command Token expenditure they make unnecessary**.

This creates two kinds of value:

1. build the army to repeatedly exploit the free effect itself; or
2. spend the saved Command Tokens on other powerful effects that the army would otherwise have had to forgo.

### Inspiring Leadership

When the Inspiring Leadership user is the Lieutenant and active on the table, the list gains several army-wide effects, including converting qualifying Order-providing troopers to Regular Training and allowing a Coordinated Order that **includes the Lieutenant** to be declared by spending only the Lieutenant Special Order, with no Command Token or extra Regular Order.

This is list-defining in armies with substantial Irregular access because those troops can become Regular without spending Command Tokens one by one.

The free Coordinated Order also deserves proactive list construction. Consider including several independent models that can profitably coordinate with the Lieutenant for:

- mass repositioning;
- movement toward scoring zones;
- simultaneous attacks that create difficult ARO choices;
- state activation such as Suppressive Fire, when legal and tactically appropriate.

The requirement that the Lieutenant participate matters. The best supporting pieces are therefore ones whose coordinated route and battlefield role are compatible with where the Lieutenant can safely or productively move.

The larger strategic benefit is **Command Token substitution**. If a list expects to use a Coordinated Order each Turn anyway, Inspiring Leadership can effectively preserve Command Tokens for:

- Doctor/Engineer rerolls;
- Combat Group transfers;
- Fireteam reconstruction;
- Speedballs;
- additional Coordinated Orders later in the Turn;
- emergency Guts or Possessed recovery.

Do not evaluate the skill only as "free coordination." Evaluate the entire list as having a much looser Command Token budget.

### Strategos L1 and L2

Strategos already changes Command Token economics before considering L2:

- both L1 and L2 allow **two reserve troopers** during deployment instead of the usual one, overlapping with the first player's Command Token option to hold back an additional reserve trooper;
- both convert Lieutenant Special Orders into Regular Orders in the Lieutenant's Combat Group.

Strategos L2 additionally allows **one trooper to move to another Combat Group during the Executive Use step without spending a Command Token**.

This should influence list construction proactively.

A Strategos L2 list can deliberately make Group 2 more modular because it expects a free group transfer when necessary. Good candidates include:

- a secondary attacker intended to graduate into Group 1 after casualties;
- a fast specialist;
- a Sensor/FO REM;
- an Airborne attacker after arrival;
- a support piece that becomes relevant later in the game.

The key principle is:

> **Do not merely use the free transfer when something goes wrong. Build the Combat Groups knowing that one free rebalance is available every Tactical Phase.**

That can support a more aggressive initial Group-1 structure, a stronger self-contained Group 2, or deliberate Turn-2/Turn-3 migration of surviving useful pieces.

As with Inspiring Leadership, the second source of value is the Command Token that was **not** spent. If a normal list expects to spend one or more Tokens restructuring its groups over the game, Strategos L2 can redirect those Tokens into:

- Speedballs;
- Doctor/Engineer rerolls;
- Fireteam rebuilding;
- Irregular-to-Regular conversions;
- Coordinated movement or Suppressive Fire;
- emergency recovery effects.

### General command-efficiency principle

Command abilities that duplicate or replace normal Command Token functions should be valued at more than the immediate effect printed on the profile.

Ask two questions:

1. **Can the list be designed to use the free effect regularly rather than incidentally?**
2. **What other Command Token effect becomes affordable because this one is now free?**

This is particularly important for **Inspiring Leadership** and **Strategos L2**, because both can alter how the entire list is structured rather than merely improving one trooper.
