# Miniature proxying guidelines (Infinity N5.3)

**Status:** repository-wide collection, inventory and buy-list policy · **Adopted:** 2026-10-30. Applies when recommending an *owned or purchasable sculpt* to represent a different legal unit. This is a **preference/clarity standard**, not an assertion that Corvus Belli formally mandates matching armour or troop class. Always apply the current event/tournament proxy policy as well as the current Army roster.

## Non-negotiable checks

1. **Correct silhouette, including base diameter AND silhouette height.** Match the *target profile's exact* S attribute, not just base size. In N5.3, **S2 = 25 mm base / 40 mm height, S3 = 40 / 32, S4 = 55 / 32, S5 = 40 / 45, S6 = 40 / 55, S7 = 55 / 67**. Same-base **S5 dog ≠ S6 TAG**; both 40 mm, but different height. **S6 PanO TAG ≠ S7 Jotum**. Never quietly accept a silhouette mismatch; explicitly label it **not suitable under this policy**. Consult [repo silhouette rules](../rules/1_Basic%20Rules/Silhouettes.md).
2. **Distinct model identity in the actual sectorial.** **Avoid using a sculpt of a unit also selectable in the very sectorial being played**, even if the donor is not in this particular list. For example, do not suggest a **Senku** sculpt as a **Tanuki** stand-in in a roster where Senku itself is selectable; and do not recommend a **Fusilier** sculpt for Richard Quinn when both are selectable. This is a strong *clarity preference*, not a claim of tournament illegality. A model's **same named unit in a different sectorial is not a proxy**. Alternate sculpt/loadout of that same unit also is not a cross-unit proxy.
3. **Similar troop category and apparent protection.** Prefer **LI ↔ LI, MI ↔ MI, HI ↔ HI, SK ↔ SK, WB ↔ WB, REM ↔ REM, TAG ↔ TAG**, with comparable armour/clothing. Treat this as a visual guideline; **SK may reasonably resemble a lightly equipped LI or MI**, and some unusually armoured MI visually resemble HI. Prefer similar figure pose/equipment/weapon where possible, though matching weapon exactly ranks below matching silhouette and identity.
4. **Respect distinct physical archetypes.** A **humanoid HI should look like heavy armour**; **REM** like a robot/drone; **TAG** like an armoured mecha; **motorcycle** like a rider on a bike; **dog-warrior/canine** like an animal/hybrid; **alien** like an alien where distinctive. **Don't suggest a dog as a bulky HI merely because both are S5, or an alien Exrah TAG as a human PanO TAG solely because both are S7**. Those are *last-resort test stand-ins*, not recommended proxies.
5. **Physical model bookkeeping.** Only use owned figures actually recorded in [inventory/](../inventory/). One physical sculpt can represent exactly **one trooper/body** at a time; a shared REM pool is not additive across unit types. Peripheral, K9, bike, Devabot, Auxbot, RacerBot, TAG pilot/Crabbot, transformed form, or other secondary body must have an appropriate **separate figure/marker** and its own correct footprint. Don't claim a model is already owned merely because another buy list recommended it.
6. **Legal target comes first.** A sculpt being owned does **not** make its printed unit selectable in another sectorial. Choose a legal target profile from the [sectorial reference](../sectorials/), then check silhouette, unit class, appearance, donor-sectorial collisions, and expected coexistence with that donor. Fireteams and equipment use the **target profile**, not the donor sculpt.
7. **Tell the opponent / TO upfront.** Prefer easy-to-distinguish models, ideally labelled or shown on an army list; verify event rules for models, proxies, bases and painting. A blank silhouette marker, a model from another faction, or a 3D print is **not assumed tournament-legal** merely because it is physically convenient.

## Practical ranking and confidence

| Tier | Recommendation | Example / condition |
|---|---|---|
| **A — preferred** | Same silhouette **and troop type**, matching look; sculpt is **not a selectable unit** in the target sectorial. | S2 Naga SK for an S2 Dart SK in a PanO sectorial, **if not separately fielded**. |
| **B — good** | Same silhouette, plausible armour/role and equipment, minor troop-type mismatch; donor not on target roster. | S2 non-NCA PanO medium infantry as an NCA Bolt; suitable S2 specialist in disguise for a different S2 LI specialist. |
| **C — conditional** | Correct silhouette and recognizable broad archetype, but visually different faction/style, or donor is also a **legal** target-sectorial unit. **Avoid when better available**. | A Caskuda standing in for a Jotum: **S7 TAG size correct**, but unmistakable alien Exrah form and not recommended as routine representation. An ORC model standing in for an Aquila inside NCA is also confusing, even though both are HI. |
| **Reject / no current proxy** | Wrong silhouette/base/height, wrong physical archetype, no model known owned, or a misleading representation that would reasonably confuse an opponent. | **S5 dog → Bøyg S5 HI: reject** despite S5 match. **S2 knight → S5 Bøyg: reject**. **S6 Tikbalang → S7 Jotum: reject**. |

**If no Tier A/B match exists, say “no good known owned proxy”** and recommend obtaining a fitting miniature or testing with clearly labelled silhouette markers only where the opponent/event allows it. **Do not fill a proxy table with a bad match simply to avoid a purchase.**

## Checklist for writing a buy list or an inventory note

1. Confirm the target's **N5.3 silhouette and troop category** from its current sectorial roster; check base/silhouette and physical appearance.
2. Verify the candidate's **silhouette and unit type** from its reference (not visual guesswork alone), and confirm it's **actually owned** in the current inventory.
3. Check whether the candidate's **named unit is selectable in the target sectorial**. Prefer a different donor if yes, even if the donor isn't being used in the test list.
4. Check category, visible armour/weapon, faction styling, species/mechanical architecture and special form (bike, dog, alien, bot, pilot).
5. Check collisions across **owned models, shared robot pools, multiple troopers, synchronized peripherals and active Fireteam composition**.
6. Record a **specific physical candidate, its S value, category/look, tier and caveat**. If uncertain or no match, record **“none confirmed”**, don't imply one.
7. Keep **verified ownership** separate from **shopping suggestions** and **previously suggested but now rejected proxies**. Preserve historical user suggestions only when explicitly labelled *superseded / not recommended*.

The sixth body is not a good *distinct-identity* proxy. |

**Scope of corrections:** These guidelines supersede proxy recommendations in older inventory/buy-list notes wherever inconsistent. When a file is edited, **rewrite conflicting individual suggestions**; a generic link alone is not a substitute for removing conspicuously bad proxies. Gameplay reviews and price evidence are independent from proxy visual quality.
