# Notes / Glossary

## Lieutenant decoy

In project discussion, **Lieutenant decoy** is an informal list-building term. It does **not** refer to the Infinity **Decoy** skill/equipment.

A Lieutenant decoy is a non-Lieutenant trooper using the **same visible profile and equipment** as the Lieutenant. Because Lieutenant identity is Private Information, fielding two apparently identical profiles prevents the opponent from knowing which model is actually the Lieutenant from roster-visible information alone.

A common implementation is a **cheap line-troop Lieutenant plus one identical cheap line trooper**. This is often an efficient way to protect a low-cost Lieutenant without paying for a more elaborate command package.

The main drawback is order efficiency: a cheap defensive Lieutenant often has little productive use for its Lieutenant Order. This setup becomes much more attractive when the list has an **NCO** that can convert and spend that Lieutenant resource effectively.
