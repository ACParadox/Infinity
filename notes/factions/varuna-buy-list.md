## Executive purchase decision for the existing collection

- **Already have major shared Varuna pieces:** **Squalos Mk-II 1, Bipandra 1, foot Knight of Montesa 1, motorized Montesa 1, Trauma-Doc 1, Machinist 1, Tech-Bee 1, Warcor 1, two Armbot chassis (shared Bulleteer/Peacemaker pool), four Dronbot chassis (shared Sierra/Clipper/Fugazi/Pathfinder pool), Mulebots 2, Palbots 2, Crabbot 1.** Do **not** buy these again as though you had no PanO army.
- **P1 actual distinct aesthetics:** **1–3 Helot figures**, ideally from the **four-model Helot box** if available and fairly priced; **1–2 Kamau**, especially **MULTI Sniper MSV2** and/or **HRL** (HMG is useful too); **1 Zulu-Cobra** is a great core-game investment but **proxy first** as requested.
- **P2 for specific architecture:** **Cutter 1** only if wanting an S7 Hidden Deployment TAG; **Patsy Garnett 1** for NCO/Helot FT Master; perhaps **Richard Quinn 1** via cheap PanO Reinforcements Beta if needed. **Croc Men** are valuable but disputed against Zulu and can be proxied with owned stealth models.
- **P3/optional:** **Echo-Bravo (+ WildParrot)**, **Captain Uma** (especially if its distinctive Lieutenant/FTO structure is used), generic Varuna ORC models. Extra bikes, TAGs, remote chassis, Croc variants and a fourth Helot are **not automatic buys**.
- **Strong old-box option only if genuinely cheap:** **2018 Varuna Starter** has **three Kamau (Combi/HRL/MSR) + one Croc Hacker + Zulu Spitfire + ORC Feuerbach**, all six presently **Varuna-legal**; no named minis from this starter are dedicated-owned. The **$35 USD Varuna Starter** lead from [Vanilla PanO buy list](vanilla-pano-buy-list.md) would be **CAD $48.95 if real**, but the box is officially **discontinued**. Beware aftermarket premiums.
- **Beyond Icestorm warning:** its **PanO trio = Kamau HMG, Swiss Guard HMG, Bolt Paramedic**. **Only Kamau is Varuna-legal**; Swiss is usable in **NCA/WinterFor**, Bolt in **NCA**, if purchased once. Original **Beyond Icestorm is a SIX-model expansion** (also 3 Nomads). An online listing specifically labeled “PanO Beyond Icestorm” may be only a split PanO **three-model half**; verify exact photos and included figures before paying.

## Proxy guidelines — correct S silhouette, class, looks and roster identity

The [repo policy](../miniature-proxy-guidelines.md) favors **same silhouette**, then **same troop class/visual armour and physical archetype**, and **avoids using sculpts of units legal in the target sectorial** for a different target. Declare each represented model and weapon before play. S2 = standard infantry; S4 = motorbike; S6 = Squalos; S7 = Cutter. No use of S6 TAGs as S7 proxies. Distinct alien aquatic Helots are a stronger visual requirement than generic LI.

## Whole-unit / profile-level skips and practical fireteam caveats

1. **Not worth dedicated purchase for this collection:** **extra Squalos Mk-II, Bipandra, standard basic support/REMs, foot Montesa, first Montesa bike**; owned already. A **second bike** is niche and **must really be S4**. Four Dronbots and two Armbots are **shared total chassis**, not AVA for each variety.
2. **Clipper FTO is actually Fireteam-capable in Varuna** via **Wildcard FTO** (unlike in current SAA/SWF where FTO isn't a chart row). **Swiss Miss calls Clipper low value as a default**; already have pooled Dronbot, so **do not buy a Clipper just because FTO is legal**. It needs a meaningful linked missile/Guided/Targeted plan.
3. **Croc Men are NOT “never take”**: Tactical Awareness questions their cost vs Zulu; Swiss Miss praises Hidden specialist potential. **Skip extra Crocs and niche variants**, not every Croc. Same for Echo-Bravo: **defer multiple off-table units**, not ban AD.
4. **Overbuilding Helot/Kamau static defense** can starve attack and objective specialists. Buy 1–2 Helot working bodies (4-pack if good deal), 1–2 Kamau, then fund **Zulu/Montesa/ORC/Pathfinder**; do **not** assume old N3/N4 Kamau pure-core rules survive N5.3.
5. **Cutter** is extremely strong but requires a 95–97pt commitment, useful specialists and safe orders. You already own **TacAware Squalos**; Cutter has **no TacAware**, and **Varuna has no Chain of Command unit**. A Cutter LT is not automatically safe.
6. **Richard Quinn is FO/Disco, not CoC**. Patsy NCO + Helot FT Master, Uma FTO LT, Fusilier LT are distinct choices; do not mistake their command skills. The current standard roster **has no generic CoC insurance**.
7. **Unsupported purchases**: Swiss Guard, Bolt, Shona and other models printed in **shared boxes** are **NOT Varuna roster entries**, even when otherwise excellent for NCA/SWF. A purchased item may be **useful in another legal sectorial**, never in Varuna solely by ownership.
8. **Weapon-specific OOP sculpts**: old Kamau HMG, Croc Sniper, Helot LRL, Zulu Hacker sculpts need not exactly match the current profile weapons to be usable as correctly declared same-unit representations. Tournament proxy rules still apply.
9. **Limited editions**: the **Beyond Icestorm preorder Authorized Bounty Hunter** is the confirmed special bonus; the **2018 Varuna Starter** and normal **Helot four-pack** are **commercial products**, not “LE” because OOP. Uma's Defiance sculpts are non-retail alternatives, not established as an official limited-number miniature.
