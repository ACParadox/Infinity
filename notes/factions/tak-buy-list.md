## Strict proxy choices using actual collection

**Before approving any donor:** same target **silhouette including height and base diameter**; visually comparable **LI/MI/HI/SK/WB/REM/TAG** and armour; similar distinct creature/motorcycle/robot archetype; avoid a sculpt whose **named unit is legal in this very force**; one physical figure at a time. Mark FTO profile-specific Fireteam selection, and the actual proxy on the army list. Ask opponent/TO and observe event proxy rules.

| Target type | Existing owned figure or shared physical pool | Restriction / suitability |
|---|---|---|
| S2 LI line soldiers (when not their own selectable name) | **TAK Line Kazaks x3**, **Caledonia Volunteers x3**, or **Kestrel Fennecs x6**, subject to target force roster | Human S2 line soldier and rifle appearance; do **not** use a named troop that is also legal in current sectorial. If its original unit is legal, use it as *itself* not proxy for another unit. |
| S2 SK camouflaged troops | **TAK Scouts x2**, **Caledonia SAS x1**, or **OSS Naga x1** if none of the donor names are legal in the target army | Prioritize similar stealth gear; **do not borrow** a TAK Scout for another TAK trooper or a SAS for Caledonia/Kosmoflot/vanilla where SAS selectable. |
| S2 armoured infantry/character | **TAK Veteran Kazak x1**, **Caledonia Mormaer x2 / Greys x3**, **Kestrel Griffin x2/Hetkari x1**, only when donor type is not on this roster | Match LI vs HI, and dress/protection; **never use a light rifleman to depict a bulky armoured Patcher/Blackjack** without verifying S and obvious appearance. |
| S4 motorcycle | **TAK Dynamos x2**, **TAK motorized 112 x1**, or **Steel Phalanx Penthesilea x1** if not selectable as that same unit in sectorial | Only for S4 motorbikes such as Maverick, Desperado, Carmen; don't let a foot S2 scout proxy a bike or allocate one Dynamo twice. |
| S1 servant / Elektronik | **Steel Phalanx Yudbots x2** / **PanO Palbots x2** if correct physical S and remotelike appearance | Not automatically official Elektronik/Remontnik; each concurrent peripheral needs a distinct matching figure/marker. |

## Entire-unit skips, deferred duplicates and opportunity cost

Do not buy to full AVA of Tankhunters, Scouts, Spetsnaz, Veteran Kazaks, Line Kazaks, Dynamos, Ratnik or artillery. **Pavel** is already owned; tactical evidence is contested for general-purpose value. **Konduktor** can be useful as a cheap body, but a model with that name is not a replacement for Strelok's forward/camouflage role. If the planned list needs more than two combined Traktor/Kuryer chassis, then investigate more models; otherwise the shared pair is sufficient.

A unit can be competitively valuable but **not worth an additional miniature purchase** when adequately represented by the collection. Tactical [Ariadna evidence audit](ariadna-must-have-go-to-avoid-source-audit-2026.md) distinguishes **unit** from **profile-specific** objections: avoid claiming any unproven universal never-take. In particular, original SKU/edition can be **OOP** while still depicting a legal current N5.3 unit.
