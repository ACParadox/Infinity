## Sectorial inventory

Role-based index of the standard 29-unit roster (not miniature ownership). Entries describe alternative options, not cumulative loadouts. See the pinned roster for option IDs and full statistics.

- **Acontecimento Regular:** 10/0 Combi LT, identical visible loadout to the basic 10/0 Regular.

## Detailed REM ecosystem

| REM | Practical use and combination | Limit / counterargument |
|---|---|---|
| **Pathfinder 14, TacAware 17 (AVA1)** | FO + Sensor + Repeater + Triangulated Fire, **Wildcard**. Best TAG/Bulleteer companion when the extra TacAware order and scoring access will be used; **TA, Swiss Miss and Dante** repeatedly praise it. | Only one. If kept as a solitary sensor/FO support bot with no useful second activation, save 3 points for the 14-point version. |
| **Peacemaker 23–27 (AVA2)** | FD(+20), Repeater, Mimetism(-3), shotgun and optional Auxbot/Minelayer: fast middle-board suppression, deployable mines and hacking projection; **Swiss Miss** strongly recommends it. | Heavy S4 + Auxbot + possible mine require **several viable deployment/attack positions**. Dante warns two Peacemakers can overcrowd; do not mistake the no-Auxbot 23-point profile for the minelayer model. |
| **Bulleteer 19 shotgun / 22 Spitfire (AVA2)** | Mimetism(-6), high movement and Repeater: premium attack angles for low points; **Swiss Miss** praises pairing them as a mobile assault group. The Spitfire's **1 SWC** is economical beside Bagh-Mari HMG / TAG. | Fragile W1, hackable, competes with TAG for engineer/time; Fireteam must use the **correct** Acontecimento or Moto-mecanizados chart, not arbitrary all-Bulleteer setups. |
| **Fugazi 7 (AVA3)** | Fast Regular order, Flash Pulse ARO, Repeater, Mimetism(-3); fills order count and network for Scylla/Naga. | Can unintentionally expose a hacked network to opponents. Doesn't clear a strong hard ARO. |
| **Mulebot 8 Baggage / 14 EVO / 17 TR** | 8-point Baggage is a cheap Order and useful resupply for Pitcher/limited ammo; **TA** specifically likes reloading Montesa Blitzens; EVO if it enables an actual REM/AD plan. | Passive purchases have diminishing returns if the relevant weapons/units are absent. |
| **Sierra 18 Thunderbolt(+1B) / 23 HMG** | No-link Total Reaction defense with 360º Visor; HMG patrols longer lanes, Thunderbolt saves SWC. | Can be countered by vision-control and strong active gunfight; its price may buy a Sapper sniper or distributed mines instead. |
| **Clipper 16/1.5 Guided ML; 19/1.5 FTO-labelled ML(+1B)** | Guided attack becomes a real tool only if hackers/FO/repeaters can successfully Target and feed Orders; credible area denial otherwise. | **No SAA link row for Clipper FTO**; do not assume the second option can join a team. Spending SWC on unused Guided is a trap. |
| **Charybdis FTO / Palbot** | Charybdis in the **Scylla 37-point package** supplies a second Regular Order, mobile Repeater and HFT. Palbots are cheap medical/engineering **Servants**, not order-pool troopers. | The Scylla pair has an explicit package dependency; peripheral Servants do not independently create Orders. |
