# Lt. Stephen Rao — Shock Army of Acontecimento (Infinity N5.3)

**Verdict: A− / strong but list-dependent Lieutenant. Prefer Lieutenant (+1 Order) with Bagh-Mari NCOs. Agnes CoC is optional, not an automatic purchase; a protected Rao can fund the attack from the backline. NCO Rao is situational and the extra Command Token profile is generally a skip.**

## Lieutenant (+1 Order) — 27/0

Rao's main purpose is to generate two useful Lieutenant Orders per turn while remaining protected. Any Bagh-Mari NCO can spend these Orders, and an NCO acting as Fireteam Leader activates the whole legal team. Kirpal Singh also has NCO. Multiple NCOs increase flexibility, not the number of available Orders.

Compared with a 21/0 Bagh-Mari Lieutenant, six extra points buy an additional Lieutenant Order, WIP14 Specialist Operative, D-Charges, Shock Immunity and Wildcard access, with the same BS13, MSV1, Mimetism (-3), ARM2/BTS3/W1 and Warhorse chassis.

| Lieutenant | Pts / SWC | LT Orders | Main reason to select |
|---|---:|---:|---|
| Regular | 10 / 0 | 1 | Cheap, concealment with identical decoy |
| Bagh-Mari Combi | 21 / 0 | 1 | Resilient matching member |
| Bagh-Mari HMG | 27 / 1.5 | 1 | Discounted fighting LT |
| Rao | 27 / 0 | 2 | Protected order engine with NCO recipients |
| ORC MULTI Rifle | 28 / 0 | 1 | Two Wounds, ARM4 |
| ORC HMG | 34 / 1 | 1 | Discounted SWC |
| Tikbalang | 73 / 1.5 | 2 | Only four points over the 69/1.5 standard TAG |

If already fielding a Tikbalang, its LT upgrade is very efficient, but exposes command if the TAG attacks and its own activations compete with Bagh-Mari for those Lieutenant Orders. Rao is preferable when the main purpose of the extra Orders is to feed an independent Bagh-Mari attack team without risking the LT.

## Command package: Rao + Agnes vs two Regulars

| Attribute | Rao LT + Agnes CoC | Regular LT + identical decoy |
|---|---:|---:|
| Pts / SWC | 45 / 0 | 20 / 0 |
| Regular Orders | 2 | 2 |
| Lieutenant Orders | 2 | 1 |
| Trooper slots | 2 | 2 |
| Specialists | 2 | 0 |
| LT WIP | 14 | 13 |
| Command security | Chain of Command | Concealed identity |
| Fireteam contribution | Two Wildcards; Rao counts as Bagh-Mari | Two native Regulars |

The 25-point premium buys up to three extra LT Orders over three rounds if Rao survives and those Orders are spent, two specialists, more capable combat/defensive models and CoC. It does not buy more pooled Regular Orders. Agnes brings WIP13 SO, BTS6, Sixth Sense and Nanopulser (+1B) (extra Burst in active turn, not ordinary ARO). Keep her separated from the exposed LT if buying her as insurance. CoC prevents Loss of Lieutenant when its conditions are met but does not inherit Rao's +1 Order skill.

### Opportunity cost

| Rao + Agnes CoC | 45 / 0 | 2 | 2 | 2 |
| Two Regulars + Bagh-Mari Paramedic | 45 / 0 | 3 | 1 | 1 |
| Two Regulars + Regular FO + Regular Paramedic | 44 / 0 | 4 | 1 | 2 |
| Two Regulars + Bagh-Mari FO | 42 / 0 | 3 | 1 | 1 |
| Rao + Regular Sensor/Minelayer | 40 / 0 | 2 | 2 | 1 |
| Rao + Regular FO | 39 / 0 | 2 | 2 | 2 |

A Peacemaker + Auxbot (23/0) is another valuable use of the 25-point saving. The 15-trooper cap matters: the more expensive command pair compresses capabilities into two slots, whereas cheaper extra bodies only add pooled Orders if there are slots available.

**Preferred compromise: Rao without Agnes.** Keep him out of dangerous firefights, spend both LT Orders through Bagh-Mari NCOs, and use the remaining points on an independent Regular Sensor/Minelayer, FO, or another needed tool. Rao has Warhorse (including immunity to Isolation), Mimetism (-3), ARM2 and Shock Immunity, but is still a single-Wound, identifiable Lieutenant. Protect him accordingly.

Agnes CoC becomes attractive if Rao will actively lead attacks, if the mission exposes him, or if the army already needs her specialist/defensive Wildcard role. Taking CoC also forgoes Agnes's useful RemDriver alternative (AVA1). For a budget TAG list or when struggling to fill Order slots, prefer the two Regulars. For an aggressively used Tikbalang LT, Agnes's CoC is much more compelling.

## NCO — 25/0

Rao is a capable secondary short/mid-range fighter and WIP14 specialist, but ordinary Bagh-Mari already have NCO.

| | Rao NCO | Bagh-Mari FO |
|---|---|---|
| Pts / SWC | 25 / 0 | 22 / 0 |
| BS / WIP | 13 / 14 | 13 / 13 |
| Weapons | Combi, Assault Pistol | BSG (+1B), Flash Pulse |
| Specialist | SO | FO |
| D-Charges | Yes | Yes |
| MSV1 / Mim(-3) / NCO | Yes | Yes |
| Shock Immunity | Yes | No |
| Wildcard | Yes | No |

Prefer the FO for AP shotgun fire, close-range attack and cheaper mission support. Rao offers more useful rifle range, better WIP, Shock Immunity and flexible Wildcard placement. Buy the NCO profile when those differences matter, including mixed ORC teams or a Tikbalang LT plan without a native Bagh-Mari NCO in the relevant team. Rao does not add an Order merely by having NCO.

## Fireteam construction

Rao counts as Bagh-Mari, including alongside the SAA Machinist in the Acontecimento family. Wildcard access does not replace the required native ORC or Bagh-Mari anchor, nor the native requirements of other teams. Agnes has no Counts-as label.

| Package | Pts / SWC | Level | Use |
|---|---:|---:|---|
| Bagh-Mari HMG + Rao NCO + E/Mitter Turret Machinist | 74 / 1.5 | FT3 | Gun, WIP14 scoring, Engineer and turret |
| Bagh-Mari HMG + Rao LT (+1 Order) + same Machinist | 76 / 1.5 | FT3 | Two LT Orders for HMG NCO; exposes Rao with team |
| Bagh-Mari HMG + FO + same Machinist | 71 / 1.5 | FT3 | Cheaper assault Haris with complementary AP shotgun |
| Bagh-Mari HMG + FO + basic Machinist | 69 / 1.5 | FT3 | Preferred economical gun/mission Haris |
| Bagh-Mari HMG + Rao NCO | 55 / 1.5 | FT2 | Mobile gun and specialist |

FT2 grants +1SD rather than additional actual Burst; FT3 adds Discover +3 and Dodge +1. The first Haris is an existing chart-validated recommendation; the others are tactical constructions, not confirmed deployed lists.

Do not link the LT simply because he has a matching identity: keeping Rao independently sheltered may be more valuable. Bagh-Mari HMG + FO + Machinist can attack with his Orders while Rao remains safe. A Regulars Core with two identical basic Regulars also supports a cheap concealed LT strategy without reducing native composition.

## Lieutenant (+1 Command Token) — 27/0

Same chassis and cost as the two-Order LT. Consider only for a specific Command Token-heavy plan where an extra token matters more than a recurring additional LT Order. With Bagh-Mari's native NCO access, prefer the +1 Order option in ordinary lists.

## Final assessment

| Role | Rating |
|---|---|
| Lieutenant economy | A |
| Fireteam utility | A |
| Mission specialist | B+ |
| Gunfighter | B− |
| Independent attacker | C+ |
| Overall | A− |

Rao is a command enabler, not an apex gunfighter: one Wound, ordinary movement, no marker state or forward deployment, no AP gun and no Tactical Awareness. Select him for the recurring two-Order engine and flexible specialist utility. **Rao + Agnes is not mandatory; protected Rao without CoC is often the better balance.** Use two Regulars when points and pooled Orders matter more, and reserve Agnes for a genuinely exposed Lieutenant or another worthwhile support role.
