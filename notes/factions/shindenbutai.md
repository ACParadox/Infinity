## Core identity — modular teams, not a mandatory Core

The strongest repeated Shindenbutai list-building theme is:

> **Build several compact problem-solving modules rather than one large Fireteam carrying the army.**

Current Shindenbutai has **1 Core, 1 Haris, and unlimited Duos**. That unlimited-Duo access is not trivia; it strongly supports the sectorial's practical identity.

A good Shinden list often looks more like:

> **command package + 1–2 Sayō modules + independent midfield threats + visibility/control tools + long-range answer + mission specialists**

than:

> **five-model Core + primary Rambo + cheerleaders.**

Robert Shepherd explicitly demonstrates that a good Shinden list can contain **no Senku and no Hatamoto at all**. Tactical Awareness demonstrates the opposite extreme with **two Hatamoto**. Both constructions work because the army's strength is the modular architecture rather than one mandatory premium troop.

## The most repeated go-to pieces

These are not literal auto-includes, but they recur because they compress multiple roles or enable a major architecture.

| Unit | Typical role | Why it repeatedly appears |
|---|---|---|
| **Tanuki Hacker** | network/control specialist | Pitcher + Disco Baller + HD + Sayō anchor; creates multiple attack/control lines from one 20-point slot |
| **Hatamoto** | premium active piece | NCO on every profile, specialist, Mimetism, Nanoscreen, CC, strong LT option |
| **Shizoku** | direct heavy gunfighter | BS13 HI with Mimetism and serious weapons; current FTO/Strategic Deployment profiles support different teams |
| **Rui Shi** | Sayō gun/control REM | MSV2 Spitfire or MSV1 Red Fury + Mine Dispenser; excellent partner for Tanuki |
| **Kyojin Killer** | cheap forward trade/control | current 15-point HFT + Flammenspeer profile is a very compressed disposable threat; AVA2 makes duplication natural |
| **Yamabushi** | midfield marker/trader | one-use Camo profiles create independent pressure; FTO versions exist but should not automatically consume AVA |
| **Motorized Yojimbo** | smoke + fast CC/trade | gives Shinden conventional smoke, Koala pressure, and a fast asymmetric attacker |
| **Metsuke** | safe command architecture | Strategos/Counterintelligence or +1 Lt Order depending on NCO plan |
| **Monstrucker** | recovery + area-control infrastructure | repairs REM/TAG pieces while also creating Drop Bear/turret board state |

The faction-defining distinction is not “which one is mandatory?” but **which packages you want to assemble around them**.

# Architecture A — Sayō network / toolbox Shinden

This is the architecture most strongly represented in Robert Shepherd's material.

His published example list is especially informative because it has:

- **2× Tanuki Hacker**;
- **2× Rui Shi** — one MSV2 Spitfire, one Mine Dispenser;
- Shizoku Strategic Deployment HRL;
- Metsuke Strategos LT;
- Teishin KHD;
- EVO Pangguling;
- 2× Camo Yamabushi;
- Kyojin;
- Uran;
- Motorized Yojimbo;
- Monstrucker + servant;
- Lù Duān.

The notable absence is **Hatamoto**. The list proves that Tanuki/Sayō infrastructure can be the real structural heart of Shinden.

## Tanuki Hacker — closest thing to a structural staple

Current profile:

- 20 pts / 0.5 SWC;
- SMG;
- **Pitcher**;
- **Disco Baller**;
- normal Hacking Device;
- BS13 / WIP13;
- Sayō-required member.

The value is not “WIP13 Hacker wins hacking wars.” The value is that a single model creates multiple decision branches:

- launch Pitcher and hack;
- place a Disco Ball and deny LoF;
- push a specialist;
- enable a linked gunfighter;
- help another assault piece cross dangerous space.

Robert's material treats the profile as an unusually dense utility package, and his sample list takes **two**.

## Signature fighting Sayō Haris

A major go-to team is:

> **Tanuki Hacker + Rui Shi MSV2 + Shizoku Strategic Deployment HRL**

Current legality:

- Sayō requires a Tanuki.
- Rui Shi is legal.
- The **Strategic Deployment Shizoku profile** is the Sayō-legal Shizoku.

This small team covers an unusually large decision tree:

- **long range:** Shizoku HRL (+1B);
- **mid range / visibility MODs:** Rui Shi MSV2 Spitfire;
- **hackable target:** Tanuki Pitcher + HD;
- **bad gunfight:** Disco Ball instead of taking the FtF;
- **close assault:** Shizoku has serious CC and Assault Pistol capability;
- **objective:** Tanuki is already a specialist.

The point is not merely “good Haris.” It is:

> **maximize the number of ways the team can refuse the opponent's preferred interaction.**

## Compact Sayō Duo — do not add a third member automatically

Because Shinden has unlimited Duos, the two-model team is a real endpoint rather than an unfinished Haris.

> **Tanuki Hacker + Rui Shi**

is already complete enough to justify itself.

A third model should be added because it provides a needed role, not because “three models must be better.”

This is especially important with Yamabushi: consuming one of only two Yamabushi to gain a third Fireteam body may be worse than retaining an independent midfield Camo threat.

## Utility Sayō Duo — Tanuki Hacker + Mine Dispenser Rui Shi

Current Rui Shi profiles:

- 23/1 MSV2 Spitfire;
- 21/0.5 MSV1 Red Fury + **Mine Dispenser**.

The Mine Dispenser profile supports a distinctive secondary-group package:

> **Tanuki Hacker + Mine Rui Shi + Pangguling Baggage + Monstrucker**

When Group 2 does not have an attractive target, its Orders can still become persistent table state:

1. shoot mines into useful locations;
2. reload disposable ammunition from Baggage when appropriate;
3. launch Pitchers;
4. place Disco Ball zones;
5. deploy Drop Bears or an Armed Turret through the Monstrucker;
6. repair a damaged REM later if needed.

This is one of Shinden's best “less obvious” list-building packages.

The key concept is:

> **A support group does not need exposed enemy models to spend productive Orders.**

It can manufacture board control before the main attack group commits.

## Uran as a consequence layer

Current Uran is a 16-point Guided Missile REM.

In a Tanuki-heavy network, Uran is less interesting as a dedicated “Guided list” and more interesting as a consequence attached to the hacking network.

Pitchers and Repeaters become harder to ignore because a successful Targeted state can now lead to a Guided attack. Even when Uran never fires, it changes how safely an opponent can tolerate the network.

Do not overbuild around this unless the mission/matchup supports it; Shinden's network is useful even without committing to a Guided plan.

# Architecture B — aggressive double-Hatamoto command package

Tactical Awareness demonstrates a very different Shinden list.

The published list contains:

- **Hatamoto LT +1 Order**;
- **Hatamoto NCO**;
- **Tanuki Chain of Command**;
- 2× Kyojin;
- 2× Raiden HRL;
- 2× Camo Yamabushi;
- Senku specialists;
- Monstrucker;
- EVO Pangguling;
- Yuriko.

This is the strongest evidence for a second major Shinden construction principle:

> **If an efficient profile is central to the plan, duplication can be better than broad toolbox diversity.**

## Hatamoto is an unusually complete premium attacker

Current Hatamoto chassis:

- AVA2;
- NCO on every profile;
- Mimetism (-3);
- Nanoscreen;
- X-Visor;
- Specialist Operative;
- strong Martial Arts / Natural Born Warrior package;
- Monofilament + E/M melee tools;
- Plasma Carbine, Red Fury, or Spitfire choices;
- aggressive Lieutenant profiles with **+1 Lt Order and +1 SWC rebate**.

The value of the chassis is not merely raw shooting. Nanoscreen reduces dependence on ordinary Cover geometry, while the CC/equipment package gives the model answers after it closes distance.

### Double Hatamoto is not just redundancy for redundancy's sake

The package:

> **Hatamoto LT +1 Order + Hatamoto NCO + Tanuki CoC**

creates several layers of value:

- the LT is a real attacker instead of a hidden tax;
- the NCO can use Lieutenant-order economy;
- both premium pieces present similar but separate threats;
- Tanuki CoC prevents an aggressive LT loss from automatically causing Loss of Lieutenant;
- the opponent cannot solve the entire attack plan by removing one Hatamoto.

This is expensive, but it is a coherent architecture rather than a gimmick.

# Lieutenant and command packages

## 1. Metsuke Strategos — safest general default

Current profile: 22 points, Lieutenant + Strategos L1, with Counterintelligence and Holoprojector on the chassis.

Use when the list values:

- reserve/deployment control;
- a safer command piece;
- Counterintelligence;
- a generic command benefit that does not require a specific attacker.

This is the clean “when in doubt” LT.

## 2. Metsuke +1 Lt Order → Hatamoto NCO

Current Metsuke also has a 23-point **Lieutenant (+1 Order)** profile.

This is a build-around option, not simply an alternate flavour of Metsuke.

Take it when the list has a Hatamoto NCO and expects to convert those LT Orders into useful activity.

A practical decision rule:

> **Strategos if you value deployment/control more; +1 Order if the NCO economy is central to the list.**

## 3. Hatamoto LT + Tanuki CoC

Current Hatamoto LT profiles all provide +1 Lt Order and an SWC rebate.

This is the aggressive command plan:

- actively spend the LT;
- let Tanuki CoC absorb succession risk.

The full double-Hatamoto version adds an NCO partner to exploit the Order economy more aggressively.

## 4. Mechazoid LT

Current Mechazoid LT is a 69-point MULTI Spitfire TAG with Tactical Awareness.

This is a distinct TAG architecture rather than a normal Shinden default. Use it because the list genuinely wants the TAG as a central attack/command piece, not merely because it generates efficient Orders.

## 5. Senku LT

Current Senku LT is 9 points / 0.5 SWC.

Use it as a **budget command solution** when the saved points materially improve the rest of the list. Do not treat Senku LT as a defining Shinden command package.

## 6. Tanuki HMG MSV2 LT

Current Tanuki has an HMG MSV2 Lieutenant profile.

This can work when the list specifically wants the LT to be a ranged MSV piece, but it is more exposed and less structurally distinctive than Metsuke/Hatamoto command packages.

# Go-to Fireteam structures

Current canonical chart is in `sectorials/jsa/shindenbutai.md`. Important current facts:

- **1 Core**;
- **1 Haris**;
- **unlimited Duos**;
- Sayō requires a **Tanuki**;
- Shizoku access differs by family/profile;
- Shurayuki is an explicit Wildcard counting as **Senku**;
- Yuriko FTO is a Wildcard counting as **Senku/Sayō**.

## 1. Sayō Duo/Haris — default modular family

Current legal members include:

- required Tanuki;
- Jizamurai;
- FTO Yamabushi;
- Rui Shi;
- Strategic Deployment Shizoku;
- Aïda FTO;
- Ioann Bann;
- FTO Yuriko via Wildcard access.

Best practical uses:

- **Tanuki Hacker + Rui Shi MSV2** — compact gun/network module;
- **Tanuki Hacker + Mine Rui Shi** — utility/control module;
- **Tanuki Hacker + Rui Shi + Strategic Deployment Shizoku** — premium toolbox Haris;
- specialist or control variants when the mission needs them.

Sayō is the Fireteam family most aligned with Shinden's “small module” identity.

## 2. Senku Haris/Core — cheap structural material

Current Senku family allows Senku plus limited Jizamurai, Hatamoto and Taguraidā, with Shurayuki/Yuriko Wildcard options.

The repeated tactical lesson is:

> **Senku are useful because they let better pieces access a cheap team, not because Shinden needs a Senku Core.**

A simple cheap structure is:

> **Hatamoto + Senku Paramedic/FO + cheap Senku**

Use a larger Senku Core only when the actual list needs what it provides. A completely Senku-free list is normal.

## 3. Bushi-tai — specialized Core-slot package

Bushi-tai requires at least one Jizamurai and can include:

- Jizamurai;
- up to two Hatamoto;
- one FTO Shizoku;
- one FTO Yamabushi.

The structural reason to use it is not that it is automatically better than Sayō. It is that **Bushi-tai can consume the Core slot while Sayō uses the Haris/Duo structure**.

This permits a list to retain:

- a strong Sayō Haris;
- additional Sayō Duos;
- a separate Bushi-tai Core.

## Jizamurai — useful tax, not default goodstuff

Jizamurai is the admission price for Bushi-tai.

Current useful distinctions include:

- E/M CCW profile;
- **E/Mitter** profile;
- Thunderbolt profile;
- cheap SMG profile.

The E/Mitter is especially useful when a mandatory team body needs to create a credible heavy-unit deterrent.

Do not add Jizamurai merely because they can link. Add them because the Bushi-tai structure itself solves a list problem.

## 4. Mechazoid Duo

Current Mechazoid Duo can include:

- Mechazoid;
- Tanuki;
- Atom.

This supports TAG-centric lists without requiring a traditional Core shell.

A Mechazoid + Atom package can add Sensor/FO/Repeater utility; a Mechazoid + Tanuki package can attach specialist/network support directly to the TAG's movement axis.

## 5. Yamabushi Duo

Current FTO Yamabushi can form a Duo, with Ioann Bann eligible as a Yamabushi-counting member.

This is niche compared with the Camo versions because using FTO Yamabushi consumes limited AVA that could otherwise provide independent midfield markers.

# Yamabushi — default to independent midfield pressure first

Current Shinden has AVA2 Yamabushi.

The one-use Camo versions provide:

- Forward Deployment (+10);
- Mimetism (-3);
- Dogged;
- Panzerfaust / bow / mine variants;
- serious CC threat.

Robert's example takes **two Camo Yamabushi**, not the FTO profiles.

This supports a strong default rule:

> **Value Yamabushi as independent midfield markers first; spend the AVA on an FTO only when the Fireteam specifically needs it.**

A three-member Fireteam bonus is not automatically worth sacrificing an independent marker.

# Kyojin — AVA2 cheap trading package

Current Kyojin are Irregular, AVA2, with Forward Deployment (+20), Mimetism and Super-Jump.

The standout current profile is:

> **15 pts: Heavy Flamethrower + Flammenspeer + DA CCW**

The videos repeatedly value the unit as a cheap, awkward threat rather than a primary attacker. Tactical Awareness takes **two**.

Use Kyojin to:

- occupy approaches;
- threaten template trades;
- force respect for disposable long-range fire;
- exploit unusual vertical routes;
- make an opponent spend premium Orders removing a cheap piece.

One is easy to justify; two is a normal deliberate architecture rather than an indulgence.

# Raiden — genuine player-style divider

Current Raiden are:

- Hidden Deployment;
- Minelayer;
- Mimetism (-3);
- BS13;
- HRL or Missile Launcher;
- AVA3.

The main disagreement in the tacticas is not whether Raiden can work, but **how much support/geometry they need**.

### Cautious view

Robert's concern is that a single Burst-1 Raiden does not automatically stop a determined attacker. Its mine may also hint that something is present. Therefore the model is strongest when its reveal is layered with another ARO/problem.

### Aggressive view

Tactical Awareness's Owen likes the profile enough to take **2× HRL Raiden**.

So the right conclusion is:

> **Raiden is not a universal staple; it is a strong layered-ARO tool for players who deliberately build around hidden timing and cross-pressure.**

Do not deploy it as though Hidden Deployment alone makes B1 invincible.

# Visibility control — use both kinds

Shinden has two distinct visibility-control plans.

## Disco Ball

Tanuki Hacker can create a zone where conventional shooting interaction is denied.

Use it to:

- cross a dangerous lane;
- bypass an opponent's superior long-range shooter;
- create a path into CC;
- protect movement of an expensive Fireteam;
- force the opponent to reposition instead of simply winning a FtF.

## Smoke + MSV

Motorized Yojimbo provides conventional Smoke, while Rui Shi/Tanuki have MSV options.

This creates the opposite interaction:

> **Disco Ball:** neither side gets the normal shooting fight.  
> **Smoke + MSV:** create a shooting interaction that disproportionately favours you.

A robust list should know which visibility-control axis it is using rather than simply taking all the tools by habit.

# Yojimbo — motorized version as the default starting evaluation

Current Motorized Yojimbo is 20 points and brings:

- 20-15 MOV;
- Smoke Grenades;
- CrazyKoala;
- NWI;
- elite CC;
- Impetuous/Irregular economy.

Shinden does not have limitless cheap conventional Smoke, so Yojimbo's contribution is strategically larger than “good warband.”

Use him for:

- Smoke delivery;
- forcing respect around approaches with Koalas;
- fast CC trading;
- enabling MSV attack lines;
- late-turn objective-area disruption after the premium attackers have moved on.

# Monstrucker + support infrastructure

The Monstrucker is easy to misread as “the cheap Engineer.”

Current useful profiles include:

- 12-point SMG/Chain Rifle + Drop Bears;
- 15-point version adding an **Armed Turret (AP Rifle)**.

In Shinden it can support:

- Rui Shi;
- Lù Duān;
- Uran;
- Mechazoid/Triphammer;
- other REM/TAG infrastructure;

while also converting spare Orders into deployables.

This makes the Monstrucker especially good in lists where Group 2 already contains the Mine Rui Shi / Pangguling package.

# Pangguling — infrastructure, not Fireteam filler

Current Shinden Pangguling is AVA1 and has Baggage on the chassis.

Useful profiles include:

- 8-point Repeater/Deactivator;
- 14-point EVO Hacker;
- 17-point Combi Total Reaction;
- 12-point Light Shotgun Repeater.

Important current-rules point:

> **The Pangguling's profile may carry an FTO label, but the current Shinden Fireteam chart does not include Pangguling. It cannot be added to a Shinden Fireteam merely from that label.**

Its value in the tactica architecture is primarily Baggage, Repeater/EVO support, and enabling disposable-ammunition plans.

# Lù Duān — useful sleeper REM

Robert's example includes a Lù Duān despite already having substantial REM infrastructure.

Current options provide:

- MSV1;
- Holoprojector;
- E/M Mine;
- Mk12/HFT or Thunderbolt/E/M Carbine package.

This fits Shinden's layered-control identity well:

- mobile E/M pressure;
- additional vision utility;
- another model that benefits from Engineer support;
- Holoprojector uncertainty.

It is not a default staple, but it is a good off-meta candidate when the list needs a mobile midrange/control REM rather than another premium HI.

# Teishin — attack the hacking network from another angle

Current Teishin provides Combat Jump/Parachutist access with:

- plain attack profile;
- normal Hacking Device;
- KHD;
- Forward Observer.

Tanuki creates the network from the front. Teishin can attack from a different axis, especially with the KHD or objective-focused FO profile.

Use Teishin when the matchup rewards:

- backfield specialist pressure;
- attacking vulnerable hackers from unexpected angles;
- forcing DZ defence to respect airborne entry;
- D-Charge mission work.

# Shurayuki — reevaluate older negative reviews

Early Shinden reviews often criticized Shurayuki partly because of weak Fireteam integration.

That criticism is outdated under the current reference:

> **Shurayuki is now an explicit Wildcard counting as Senku.**

Current profile is a 30-point NWI/MA4/Holomask/X-Visor model with MULTI Rifle, Nanopulser and Viral CCW.

She is still not an automatic include, but older “doesn't fit the teams” conclusions should not be copied forward without adjustment.

# Ruby Monday — newer option absent from early tacticas

Ruby Monday was not part of the early Shinden video ecosystem.

Current profile is a 19-point Irregular, durable specialist with:

- 2 STR;
- Climbing Plus;
- Adhesive Launcher Rifle;
- E/M Grenades;
- Flash Pulse;
- Immunity (IMM-B).

She should be evaluated as a cheap independent mission/control piece rather than against old lists that could not take her.

She does not invalidate the older tactical architectures; she adds another compact specialist/control option to them.

# TAGs, REMs and motorbike — transcript-tested decision guide

The sectorial has **two TAG families (Mechazoid, Triphammer), no standard-roster VH-class entry**, and several complementary REM roles. Motorized **Yojimbo** is a fast **Warband** on a bike, not a VH. This section combines direct MCP transcripts with the current N5.3 source; older videos cannot establish today's points, SWC or Fireteam legality.

## Mechazoid vs Triphammer — genuine disagreement

| Choice | Current N5.3 profile(s) | Why pick it / why hesitate |
|---|---|---|
| **Mechazoid AP HMG** | **66/1.5**, TacAware | Better long-range opener when the list otherwise relies on midrange HI. Climbing Plus, stealth, CC and Kobaruto give it unusual secondary jobs; expensive and hackable, so the team around it matters. |
| **Mechazoid MULTI Spitfire** | **69/1.5**; **69/1.5 LT** option | Fits the faction's midtable brawling/vertical flanking style better than the HMG, and can challenge targets in CC. Its shorter optimum gun range makes opening the first lane and handling opposing hackers essential. |
| **Triphammer HRL / Panzerfaust** | **48/0**, Heavy Shotgun, HRL, Panzerfaust (+1B), TacAware | Extremely economical independent heavy threat: long-distance disposable/HRL deterrence plus shotgun close defence and anti-materiel CC, without SWC pressure. Transmutation reduces its performance after damage; poor native Dodge and lower BTS constrain reckless pushes. |
| **Triphammer AP Spitfire / HFT** | **53/1.5**, TacAware | Cheaper midrange anti-armour + template pressure, useful when a full Mechazoid costs too much. Lacks Mechazoid's superior mobility/stealth/CC toolkit. |
| **Other Triphammer** | **52/1.5** AP Spitfire/Chain-colt; **52/0** Shotgun/Thunderbolt (+1B) | Swap gun/area denial according to lane and SWC needs; do not assume every Triphammer is the 48-point profile. |

**Why the reviewers disagree:**

- **MetaChemistry (May 2025)** prefers the Mechazoid for a single premium TAG: mobility, specialist ancillary, midrange MULTI Spitfire and CC justify its higher ceiling; considers Triphammer a cheap TAG/second TAG alternative.
- **The Dice Gods (Aug 2025)** likes the Mechazoid in isolation but worries that its cost displaces the small Fireteams Shinden wants. Leans toward the cheap Triphammer, especially the 48-point heavy-shotgun/HRL profile.
- **The Dice Gods (Jan 2026)** actually builds a post-Sandtrap **Triphammer** list rather than automatically upgrading to Mechazoid. The appeal is a self-funding Tactical Awareness heavy threat that leaves points for Sayō, specialists and smoke.
- **Practical resolution:** start with the **role**. Need an independent long-range AP gun and high-mobility TAG? Mechazoid AP HMG. Need a midfield assault TAG? MULTI Spitfire. Need affordable redundancy, SWC relief or a second attack axis? Triphammer. *Do not force either TAG into a list already solving those problems.*

**TAG support:** Taguraidā is **12/0**, a **Regular specialist** and TAGCom source (**Dodge PH +3, GizmoKit PH +1**) for TAGs in its **combat group**. Cheap insurance plus a mission body, not a compulsory "TAG tax." Put a Tokusetsu Engineer / Monstrucker and possibly Yáozăo where they can actually recover the TAG. Mechazoid's **Kobaruto** and Triphammer's **TurtleMek** are ancillary specialists, **not separate army slots**; they offer objective reach while letting the big chassis pursue its main job. The Mechazoid can make a **Duo with Atom or Tanuki** under the current chart: Atom adds Sensor/FO/Repeater utility; Tanuki adds the wider specialist/hacking/visibility toolkit. These partners are alternatives, not mandatory bodyguards.

## Opponent-side checks: why a powerful Shinden list can still fail

Direct **Sneaky Snake Military Orders matchup** and **MetaChemistry takedown** transcripts emphasize:

- **High-quality long-range AROs and layered DZ defence** tax Shinden's mostly BS13-or-lower, often short/midrange attackers. **Answer:** include an AP HMG/HRL or credible visor lane-opener, or deliberately use Smoke/Disco Ball to *decline* the gunfight; don't assume good melee alone gets you into range.
- **Mimetism snipers with hard-to-reach angles** can force disproportionate Orders if only a non-MSV attacker is available. **Answer:** Rui Shi MSV2 / Tanuki MSV gun, alternative angle, or visibility denial.
- **Repeaters/hackers** punish Hatamoto, Shizoku and TAG routes, especially without TinBot-style linked protection. **Answer:** carry a real KHD/Engineer/Disco-Baller plan; do not equate having Tanuki Pitchers with hacking dominance.
- **Cheap exposed one-Wound/STR1 support** can be removed more easily than Shinden's standout HI suggest. **Answer:** layer protection for Tanuki, the cheap remotes and Turn 3 specialists; preserve mission capability after trading away Irregular pressure.
- **Hard-to-snipe LTs** (Metsuke Holoprojector/Strategos or aggressive Hatamoto plus Tanuki CoC) mean *opponents* may be better off removing order infrastructure than chasing the obvious LT.

These are **matchup tendencies**, not universal counters. Notably the old videos sometimes omit current **Shurayuki Wildcard**, **Ruby Monday**, or post-N5 launch roster differences. The current sectorial reference controls legality.

## Contrasting list-construction opinions — keep all three

- **Robert Shepherd:** Tanuki + Rui Shi toolbox with multiple independent modules and **zero Hatamoto**. *Why:* each Order can choose hacking, mine/visibility denial, gunfighting or scoring instead of paying for one all-purpose HI.
- **Tactical Awareness / Owen:** **two Hatamoto**, NCO/LT/CoC and disposable screening troops. *Why:* Nanoscreen, Mimetism, specialist/CC and order efficiency make each Hatamoto a formidable self-contained assault piece; redundancy beats over-reliance on one hero.
- **The Dice Gods (2026):** **Hatamoto + cheap Senku Core** is a viable *different* starting route after Sandtrap. *Why:* inexpensive Senku specialist bodies can buy improved Fireteam shooting bonuses and follow the premium attacker onto objectives. This contrasts with Robert's "Core unnecessary" approach, not a contradiction in legality.

**Default choice:** decide whether the list needs **(a) multiple utility choices, (b) overwhelming two-piece assault, or (c) a cheap Core boosting one attacker**. Then add TAG/REM packages only if they fix a missing role.

# Weaknesses to account for during construction

Opponent-side analysis consistently identifies a few Shinden pressure points.

## 1. Do not rely only on short/midrange HI

Shinden's premium pieces often want to work inside the table rather than simply dominate every 32-inch gunfight.

A list should have some plan for long-range opening or denial, such as:

- Shizoku AP HMG;
- Shizoku HRL team;
- Raiden hidden ARO;
- Mechazoid AP HMG;
- Tanuki MSV2 HMG/Sniper;
- Garon depending role/table.

## 2. Protect the hacking exposure of expensive pieces

Hatamoto, Shizoku and TAGs are hackable. Do not interpret Shinden's own Pitcher access as meaning it automatically wins a hacking contest.

Useful counterplay inside the roster includes:

- Disco Ball to avoid the engagement;
- Teishin/Ninja KHD;
- aggressive CC attack on the hacker/network;
- killing repeaters;
- routing expensive HI outside the enemy network;
- Engineers positioned to recover states.

## 3. Preserve real Turn 3 specialists

Kyojin, Yojimbo and other trade pieces are excellent at dying profitably. A list made entirely of efficient violence can still lose the mission after clearing the table.

Keep enough surviving mission capability through:

- Tanuki;
- Hatamoto specialist;
- Senku specialists;
- Ninjas/Kurayami/Nokizaru;
- Teishin;
- Yuriko/Tokusetsu/Taguraidā;
- Sāchā/Ruby Monday where appropriate.

# Things not to do automatically

## Do not automatically build a five-model Senku Core

Senku are cheap structural models. Use as many as the actual list needs.

## Do not automatically maximize every Duo into a Haris

Unlimited Sayō Duos are one of the sectorial's advantages. Two models may already solve the job.

## Do not automatically spend Yamabushi AVA on Fireteam filler

The independent Camo versions are often more strategically valuable.

## Do not assume Tanuki must win through hacking

Pitcher, Disco Ball, specialist status, and Fireteam access retain value even in bad hacking matchups.

## Do not assume Hatamoto is mandatory

Robert's published example has none; Tactical Awareness takes two. This is exactly the faction's architectural flexibility.

## Do not assume Raiden is bad because the ARO is Burst 1

Its value depends on hidden timing and layered defence. Conversely, do not assume Hidden Deployment makes it self-sufficient.

## Do not import old Shurayuki Fireteam conclusions

Current Shurayuki has explicit Senku-counting Wildcard access.

## Do not treat Pangguling's FTO profile label as actual Shinden Fireteam access

Current canonical Fireteam chart does not include it.

# Practical build order

A useful Shinden list-building process is:

1. **Choose command architecture.** Metsuke Strategos, Metsuke + NCO, aggressive Hatamoto LT/CoC, or TAG LT.
2. **Choose primary opening piece.** Hatamoto, Shizoku, Mechazoid, or another deliberate plan.
3. **Choose Sayō module(s).** At least ask whether Tanuki Hacker + Rui Shi improves the list.
4. **Add distributed cheap pressure.** Kyojin, Camo Yamabushi, Yojimbo, Raiden as appropriate.
5. **Check vision control.** Disco Ball, Smoke, MSV, Sensor.
6. **Check long-range answer.** Do not discover after deployment that every attacker wants to be inside 24 inches.
7. **Check hacking defence/recovery.** Especially if multiple HI/TAGs are present.
8. **Check mission specialists.** Ensure some are expected to survive to Turn 3.
9. **Use remaining slots for infrastructure.** Monstrucker, Pangguling, Uran, Lù Duān, cheap REMs according to the architecture.
10. **Only then decide whether a bigger Core actually adds more than another independent module.**

## Short version

If building Shinden blind, the first questions should be:

> **What is my LT/order package?**  
> **Which Sayō module am I using?**  
> **What opens long range?**  
> **Which cheap pieces tax the midfield?**  
> **How do I manipulate LoF instead of taking fair fights?**  
> **Which specialists survive after the attackers trade?**

That sequence captures the strongest repeated insight from the Shindenbutai video/list material: **the sectorial wins by stacking small complementary modules and forcing the opponent to solve multiple different interaction types, not by building one dominant Fireteam and pushing it forward.**

#### How to read the labels

- **Must-have / near-auto-include:** a creator expressly says "every list", "auto-include", "always", or several **actually played** builds repeatedly include it; when even one credible competing architecture omits the piece, call it "**near-must, not compulsory**" instead of inventing consensus.
- **Go-to:** source-reviewed as a repeatedly strong selection with a clear role that remains worthwhile even though an independent successful list can omit it. **Never imply all go-tos fit in one list.**
- **Never take / strong avoid:** commentator expressly rejects the **specific profile**, preferably for a direct substitute **in that same roster**, confirmed in current Army. **No faction has a defensible blanket "never take" list for every profile of an entire multi-option unit.** Where another interview disagrees, place it in **contested** rather than pretending an objective veto.
- **Specific source** is cited in the row (video/podcast, and approximate podcast minute when identifiable). These are opinions, not N5.3 legality. [Ōban transcript-reviewed tactica](oban.md), [Shindenbutai tactica](shindenbutai.md), and [Vanilla JSA event analysis](vanilla-jsa.md) contain deeper alternatives.
