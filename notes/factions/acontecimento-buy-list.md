## Whole-unit / second-model skips and low-value choices

- **Skip dedicated Agnes** (your "nope"), **all named non-SAA purchases** for this sectorial, **any second Tikbalang/Montesa bike/foot Montesa** until a specific dual-sculpt list exists, and **extra support/REM chassis** until four Dronbots / two Armbots prove insufficient.
- **Skip dedicated Bagh-Mari under current proxy preference**, but do **not** mislabel the unit bad; it is a real SAA cornerstone and the Beta box is an optional affordable way to own a five-member visual team. The **$85.00 Tistaminis Beta** works out to **$10.63 per physical mini**, and some duplicates are useful elsewhere in Vanilla PanO (only where their rosters allow).
- **Skip a second Guarda by default** (cost + separate S1 bot). Some Tactical Awareness commentators like a **double-Guarda** build; it is a specialized architecture, not an always-purchase rule. One test setup first.
- **Do not build the army around Clipper Guided/FTO** absent a real Targeted network: FTO name alone **does not allow an SAA link**. You already have a Dronbot pool.
- **Do not pay for a Naga monofilament-specific sculpt** just for that rarely favored 26pt profile: its KHD/FO/repeater/minelayer roles are much more generally useful, and you own **one Naga**.
- **Skip Kirpal solely for off-table CoC**, **generic ORC guns** that duplicate your owned Montesa/Tik/Bagh-Mari role, and **extra Akalis** until testing one AD specialist. Character figures may still be useful for a distinct plan, but not default purchases.
- **Regular Sapper sniper is contested, not a whole-unit skip**. MetaChemistry praises static Sapper defense; Dice Gods is more skeptical about 20pts/1 SWC, while the **13pt Regular minelayer/sensor** remains broadly valuable. Proxy the weapon for a few games instead of assuming a dedicated sniper sculpt is mandatory.
- **Do not buy old 2010/2016 starter at inflated OOP prices** simply for a Regular LGL or old Montesa: current repacks have distinct contents, current N5.3 profiles decide utility.
