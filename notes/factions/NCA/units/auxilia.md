# Auxilia — Neoterran Capitaline Army (N5.3)

**A-tier — versatile independent defence, specialist work and cheap command. Default to the 18-point Combi Rifle FO if the budget permits; use the 15-point basic Combi for dedicated defence or the 15-point SMG FO for budget scoring/network projection.** All four profiles have a purpose. Usually take 1–2; three are reasonable when using an Auxilia LT and decoy plus a mobile FO.

**Sources:** [Pinned NCA roster](../../../../sectorials/panoceania/neoterran-capitaline-army.md#auxilia), [NCA listbuilding](../nca-listbuilding.md), [NCA references and transcript research](../nca-references.md), [Peripheral rules](https://infinitythewiki.com/Peripheral), [Place Deployable](https://infinitythewiki.com/Place_Deployable), [Deployable Repeater](https://infinitythewiki.com/Deployable_Repeater). Ratings are tactical judgments.

## Profiles and priorities

AVA Total; LI; MOV 4-4, CC16, BS11, PH10, WIP12, ARM1, BTS0, W1, S2. Regular. No Fireteam access.

| Opt | Profile | Pts / SWC | Rating | Preferred use |
|---:|---|---:|---|---|
| 2 | Combi Rifle, Nanopulser (+1B), Flash Pulse, FO + Auxbot_2 | 18 / 0 | A | Default complete package: defence, close-range trading, mission scoring |
| 1 | Combi Rifle, Nanopulser (+1B) + Auxbot_1 | 15 / 0 | A− | Dedicated DZ defence; save 3 points if no specialist needed; LT decoy |
| 3 | SMG, Flash Pulse, FO, Deployable Repeater + Auxbot_2 | 15 / 0 | A− | Budget specialist; save 3 points if combat is secondary; dedicated hacking network |
| 4 | Combi Rifle, Nanopulser (+1B), Lieutenant + Auxbot_1 | 15 / 0 | A | Protected command and DZ defence |

The 18-point FO is the reference profile. The two cheaper non-LT options sacrifice different capabilities rather than being strictly worse. Prefer the basic Combi for defence, the SMG FO for scoring on a tight budget, and the Combi FO when both jobs matter.

## What the Auxbot adds

Both variants have a Heavy Flamethrower and 360° Visor. Auxbot_2 additionally supplies Forward Observer, Flash Pulse and Deployable Repeater. The controller and its synchronized Peripheral activate together on a single Order, but can move and attack from different angles within coherency. Each package contributes only one Regular Order, not two.

- DZ/flank protection: hide the controller and use the small Auxbot to threaten doors, corners and approaches against infiltrators and airborne troops.
- Active-turn trading: use the flamethrower and controller's gun or Nanopulser to threaten an enemy from two angles. Against expensive targets, sacrificing a cheap bot or controller can be worthwhile.
- Mission work: the FO packages bring two specialist bodies, subject to mission eligibility and interaction rules. Preserve them for later-turn objectives if the premium attackers are doing the early fighting.
- Network: Auxbot_2 can leave a persistent Repeater behind, rather than requiring a mobile Repeater carrier to remain in position.

Maintain synchronized coherency (controller's Zone of Control) and protect the controller from isolation or Null states that disconnect the bot. Avoid placing both models where one enemy template can hit them. Neither profile has forward deployment; this is a cheap DZ-based package, not an immediate midfield roadblock.

## Combi FO (18/0) versus SMG FO (15/0)

| Capability | Combi FO | SMG FO |
|---|---|---|
| Main weapon | Combi Rifle | SMG |
| Controller Nanopulser (+1B) | Yes | No |
| Controller Deployable Repeater | No | Yes |
| Controller FO / Flash Pulse | Yes | Yes |
| Auxbot_2 (HFT, FO, Repeater) | Yes | Yes |
| Total Repeater carriers | 1 | 2 |

### Why the Combi FO is the default

BS11 is mediocre, so a direct template weapon is particularly useful. The Nanopulser requires no BS roll, bypasses ordinary shooting MODs from Mimetism and Cover, and targets BTS. It has Burst 2 in the Active Turn and normally Burst 1 in ARO.

A Combi Auxilia and its Auxbot can potentially apply two Nanopulser hits plus a Heavy Flamethrower hit with one BS Attack Order if the geometry and ARO resolution permit it. Alternatively, the Combi Rifle and Heavy Flamethrower create a conventional gun-versus-template ARO dilemma. The controller retains a meaningful template threat even after the bot is lost.

For only 3 points over the SMG FO, this materially improves close defence, trading and objective clearance. The second Repeater carrier is not usually worth giving up this capability if the points are available.

### When the SMG FO is preferable

Take it when the main purpose is inexpensive specialist work, Flash Pulse coverage, or deliberate hacking-network expansion. Three saved points can fund a more valuable upgrade elsewhere.

The second Deployable Repeater carrier is useful for placing two Repeaters in a single synchronized Order, increasing redundancy, and distributing coverage while the two models remain in coherency. Deployable Repeaters are Disposable (3); the Combi FO's Auxbot already has three uses, whereas the SMG package has six across two carriers.

NCA has plentiful alternative network infrastructure: Fugazi (7/0, AVA3), Blocker Pitcher Specialist (15/0), Pathfinder (14/0 or TacAware 17/0), Tech-Bee, Bulleteer and Peacemaker. Usually one Auxbot Repeater carrier is enough. Use the SMG's extra network capacity deliberately rather than assuming more Repeaters are always better.

### When the basic Combi is preferable

If the job is simply defensive coverage, the 15-point Combi with Auxbot_1 retains both the Nanopulser and Heavy Flamethrower. It saves three points by dropping the FO, Flash Pulse and Auxbot_2 mission/network utility instead of sacrificing the controller's close-range combat.

## Lieutenant + decoy

**Auxilia LT 15/0 + basic Auxilia 15/0 = 30/0, two Regular Orders plus the Lieutenant Order, four physical models and two army-list slots.** The ordinary Combi profile has identical public equipment and masks the LT's identity. This is an ordinary Lieutenant lookalike, not the Decoy Special Skill. Neither FO is an identical decoy.

| Command package | Pts / SWC | Regular Orders | Models | Close-range defence |
|---|---:|---:|---:|---|
| Fusilier LT + basic Fusilier | 20/0 | 2 | 2 | Basic rifles |
| Auxilia LT + basic Auxilia | 30/0 | 2 | 4 | Two HFTs, two Nanopulsers (+1B) |

The 10-point premium buys meaningful DZ protection rather than merely another command decoy. Hide the controllers separately and position their Auxbots to cover different avenues of approach; do not expose the Lieutenant to unnecessary AROs. If the opponent kills a controller, its bot may be disconnected regardless of its own survival.

Especially attractive in TAG-heavy lists, with Squalos Mk-II NCO to use the LT Order, or when no Fusilier Fireteam is planned. The cheapest possible command shell is still the Fusilier pair. An Auxilia LT plus an FO costs 30–33 points but leaves the LT identifiable by loadout if there is no other identical candidate.

## Order efficiency, objective interactions and Coordinated Orders

- Synchronized Auxilia and Auxbot_2 can both declare the same eligible objective interaction if each satisfies the requirements. Check the actual ITS mission and peripheral restrictions; do not assume all consoles accept two attempts or every mission allows the bot to score. With independent unmodified WIP12 and WIP11 attempts, at least one succeeds 82% of the time, where both attempts are permitted.
- SMG FO + Auxbot_2 can both declare Move + Place Deployable, placing two Repeaters if both meet the placement requirements. The Combi FO can do this with the Auxbot while the controller Idles for the placement.
- **Neither Auxilia nor their Auxbots can participate in a Coordinated Order or Fireteam.** Do not count four Repeater placements from two Auxilia packages as part of a single Coordinated Order.
- Example: two SMG FO packages each spend one Regular Order placing two Repeaters; then a third Regular Order plus a Command Token coordinates a Tech-Bee and other eligible independent deployable carriers in the same Combat Group. That can place five Repeaters plus up to three other deployables across three Orders (assuming all placement requirements are met). Use this only when the network geometry justifies the expense.

## Alternatives and complementarity

| Alternative | Pts / SWC | Prefer when |
|---|---:|---|
| Fusilier FO | 12/0 | A native Fusilier Fireteam anchor is required |
| CSU Specialist | 11/0 | Cheap linked specialist, Sixth Sense and close defence |
| Fugazi | 7/0 | Cheap Regular Order, mobile Repeater and Flash Pulse are sufficient |
| Tech-Bee | 9/0 | TAG support and cheap independent specialist |
| Blocker Specialist | 15/0 | Sensor, Pitcher, Adhesive Launcher and Fireteam access are needed |
| Pathfinder | 14/0 or 17/0 TacAware | Speed, Sensor, Deactivator or extra personal activation |
| Peacemaker HSG + Auxbot_3 | 23/0 | Immediate forward presence and aggressive REM/template pressure |
| Peacemaker HSG + Auxbot_3B | 24/0.5 | Forward mine-based denial |

None is a strictly superior replacement for the Auxilia package. Blockers project Repeaters at range; Pathfinders are faster and can clear markers; Peacemakers start farther forward; Auxilia offer inexpensive distributed DZ protection with optional specialist work and template trading. Use appropriate actual Hackers to exploit network coverage.

## Recommended quantities and packages

| Package | Pts / SWC | Use |
|---|---:|---|
| Combi FO | 18/0 | Default single Auxilia |
| Basic Combi | 15/0 | Dedicated defence |
| SMG FO | 15/0 | Budget scoring / network |
| Combi FO + SMG FO | 33/0 | Mixed specialist roles and distributed defence |
| LT + basic decoy | 30/0 | Protected command shell |
| LT + basic decoy + Combi FO | 48/0 | Preferred complete command, defence and scoring package |
| LT + basic decoy + SMG FO | 45/0 | Budget version of the complete package |

One to two is a good starting point. Three is reasonable when using LT + decoy + FO; zero is viable when other units cover all their jobs. For collection purposes, up to three Auxilia and three Auxbots provide useful flexibility. Do not take more merely because AVA is Total.

## Community context

The [existing NCA transcript synthesis](../nca-references.md) notes that WIP12 E201's Trent commonly starts from a TAG plus 1–2 Auxilia; Robert Shepherd values cheap protected command packages; Swiss Miss Gaming rated Auxilia A-tier. The revised preference for the 18-point Combi FO over the SMG FO is a local tactical judgment, not a claim that these presenters endorse that exact ranking.

**Bottom line:** The Combi FO is the complete package. Save 3 points with the basic Combi if defence is all you need; save 3 with the SMG FO if specialist work is the priority. The Lieutenant + identical basic decoy is an excellent optional command shell when the list benefits from two defensive Auxbots.
