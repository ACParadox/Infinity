# Hexas — Neoterran Capitaline Army (N5.3)

**Low priority: generally skip.** Prefer Locust, Deva, Bolt or Blocker for hacking, and Bulleteer or other dedicated attackers for active shooting. The MULTI Sniper Rifle is the one genuinely distinctive profile worth considering for concealed long-range AROs. Counterintelligence is incidental upside, not a reason to spend roughly 30 points. Collection priority: optional (C-tier).

## Why Hidden Deployment in the DZ is of limited value

Hidden Deployment conceals a threat and protects it from direct attacks until revealed. It does not grant advanced deployment: a Hexa still starts inside its own deployment zone and must spend Orders moving towards objectives or favorable attack positions.

- Hidden hackers can reveal when an enemy Hacker becomes a legal target through the Repeater network. The opponent may not have accounted for the extra hacking ARO.
- This is an information advantage, not a hacking combat MOD in ARO. Surprise Attack (-3) is an active-turn benefit; Mimetism (-6) does not affect hacking rolls.
- Reusable Camouflage is valuable for protection, movement and active-turn Surprise Attack. Starting as a marker already provides considerable safety and contributes the Regular Order to the shared pool.
- Starting in Hidden Deployment withholds the unit's Regular Order from the shared pool until it enters play (its own Order can be used to reveal in the active turn).
- Counterintelligence mitigates the opponent's strategic use of Command Tokens, including first-turn Order removal. It is useful but does not justify the cost by itself, and multiple Hexas do not stack the benefit.

For a hidden specialist, prefer a unit that also gains a real positional advantage, notably the Locust with Forward Deployment (+20 cm).

## KHD — 27/0: generally skip

| Unit | Pts / SWC | Why take instead |
|---|---:|---|
| Locust KHD | 27 / 0 | WIP13, Hidden Deployment, FD (+20 cm), Pitcher, Firewall (-3), Breaker Combi Rifle |
| Deva KHD | 20 / 0 | WIP15, NWI, Immunity (Isolated), CSU Fireteam access |
| Bolt KHD | 22 / 0 | BTS6, Boarding Shotgun (+1B), E/M Mine, Marksmanship, Fireteam access |
| Swiss Guard KHD | 47 / 0 | Premium durable combat specialist: 2W, BTS6, Firewall, Camo, HD, FD (+10 cm) |

The Locust is the strongest direct comparison: same cost and WIP, Hidden Deployment and Mimetism (-6), but starts farther forward and can establish its own Repeater network using a Pitcher. Its Firewall improves relevant hacking engagements.

The Hexa offers reusable Camouflage, Counterintelligence, BS13 versus BS12, Shock Immunity and E/Marat. Those are real differences, but for this listbuilding philosophy they seldom outweigh the Locust's proactive utility. Deva is preferable for economical WIP15 hacking from an established network; Bolt for a durable BTS6 linked hacker.

The Hexa KHD can be justified as a concealed backline counter-hacker supporting an already established network, particularly if the list also values Counterintelligence and the E/Marat. A hidden KHD is not an automatic deterrent to every enemy entering a Repeater area: a legal hacking target and ARO are required.

## HD — 30/0.5: generally skip

Spotlight, Carbonite and Oblivion provide standard control against appropriate targets; the Panzerfaust adds an opportunistic long-range threat. However, a hidden hacker in the DZ is an expensive way to obtain this utility.

| Alternative | Pts / SWC | Advantage |
|---|---:|---|
| Blocker HD | 19 / 0.5 | Firewall (-3), Sensor, Fireteam access |
| Deva HD | 25 / 0.5 | WIP15, NWI |
| Bolt HD | 24 / 0.5 | BTS6, E/M Mine, Fireteam access |
| Locust HD | 29 / 0.5 | Hidden Deployment, FD (+20 cm), Pitcher, Firewall (-3) |

Prefer Blocker/Deva/Bolt for conventional network support and Locust for a hidden advanced hacker that can project its own network. Take Hexa HD only if specifically seeking the combination of reusable Camouflage, Counterintelligence and a concealed Panzerfaust.

## MULTI Sniper Rifle — 30/1.5: situational

The best argument for a Hexa. Unlike the hacking and short-range attack profiles, a sniper naturally operates from the DZ and does not need advanced deployment.

- Set up an unexpected long-range angle covering an approach not obviously defended by visible pieces.
- Reveal after an opponent commits to attacking another ARO piece, or when a vulnerable specialist or support unit crosses the lane.
- Punish a Move-Move declaration across a seemingly safe corridor when the Hexa has a valid ARO.
- Preserve the threat rather than revealing immediately into a poor face-to-face against an elite attacker. Surprise Attack does not apply in ARO.

| Alternative | Pts / SWC | Difference |
|---|---:|---|
| Bolt MSR | 26 / 1.5 | MSV1, Marksmanship, Fireteam; preferable conventional sniper |
| Swiss Guard ML | 60 / 1.5 | BS15, 2W, ARM5, Mimetism (-6), Hidden Deployment, explosive template threat |
| Sierra HMG | 23 / 1 | Total Reaction; cheaper visible ARO |
| Sierra Thunderbolt (+1B) | 18 / 0 | Total Reaction; SWC-free visible ARO |
| Black Friar HRL | 22 / 1.5 | MSV2, Albedo (-6), Wildcard |

The Hexa is NCA's economical dedicated concealed long-range ARO relative to the much more expensive Swiss ML, not a replacement for the more efficient visible ARO alternatives. It remains a one-wound ARM1 investment of 30 points and 1.5 SWC.

Useful layered defense: **Hexa MSR + Sierra Thunderbolt = 48/1.5**. One visible threat and one hidden angle. The Hexa is optional even here; do not buy it solely because a list needs an ARO.

## Spitfire — 31/1.5: skip

BS13, Mimetism (-6), Surprise Attack and X Visor make it a respectable ambush gun. Nevertheless, no forward deployment, Tactical Awareness, extra wounds or Fireteam access means that it competes poorly with NCA's efficient attack pieces.

| Alternative | Pts / SWC | Advantage |
|---|---:|---|
| Bulleteer Spitfire | 22 / 1 | Mimetism (-6), speed, Repeater, Wildcard |
| Bolt Spitfire | 25 / 1.5 | Marksmanship, Fireteam |
| Locust MULTI Marksman Rifle | 27 / 0 | Hidden Deployment, Mimetism (-6), FD (+20 cm), no SWC |
| Black Friar Thunderbolt (+1B) | 24 / 0 | MSV2, Albedo (-6), Wildcard |
| Redeye Spitfire | 37 / 1.5 | BS14, speed, Mimetism (-6), ARM6, 2 STR |
| Garuda Spitfire | 25 / 1.5 | Airborne attack axis |

## Listbuilding conclusion

Default to **zero Hexas**. Consider one MULTI Sniper Rifle if the list specifically needs concealed long-range ARO coverage and a Swiss Guard is too expensive. The HD/KHD remain valid niche options, but normally use the cheaper conventional hackers or the forward-deployed Locust. Skip the Spitfire in ordinary lists.

The broader NCA listbuilding notes recognize the useful Blocker Pitcher + hidden Hexa KHD architecture. This unit assessment does not dispute that combination's legality or potential; it assigns it lower priority because the same network can be supported by cheaper or more proactive hackers.
