# GizmoKit

Equipment

Special piece of Equipment that allows other Models with the Structure Attribute to remove Wounds.

- The target of a GizmoKit must be an Allied Model with the STR Attribute.

- A GizmoKit can be used in one of two ways, each one with their own Requirements: To use it remotely, the user must have LoF to the target. To use it as a piece of contact equipment, the user must be in Silhouette contact with the target.

- To use it remotely, the user must have LoF to the target.

- To use it as a piece of contact equipment, the user must be in Silhouette contact with the target.

- Used remotely, a GizmoKit is a Non-Lethal BS Weapon. If the user passes a BS Attack Roll, applying the corresponding MODs (for Range, Cover, etc.), the target performs a single PH Roll.

- A GizmoKit can also be used in Silhouette contact. To do so, the user must spend one Short Skill, without the need for a Roll, and their target performs a PH Roll.

- In both cases, by passing the PH Roll, the target removes a Wound. This cancels Unconscious State if applicable. If the PH Roll is failed, the target receives a Wound instead of removing it, entering Unconscious or Dead State if applicable.

- The target of a GizmoKit does not perform a Saving Roll.

- A GizmoKit can be used as many times as necessary to remove all the Wounds that the target has.

- If, due to a Special Skill or rule, a Trooper receives more than one successful hit or use of GizmoKit during the same Order, if any of the corresponding PH Rolls is successful, the Trooper removes a Wound. Even if the Trooper passes every PH Roll, they only remove one single Wound.

- The user can apply this piece of Equipment on themselves, to remove any Wounds they have received, or cancel any states that can be canceled by a GizmoKit. However, this cannot be done if the user is in a Null State.

- If a Trooper lists GizmoKit in their Unit Profile with a PH value between brackets, the Trooper will use this PH value when a GizmoKit is used on them.

### GizmoKit and Remote Presence

- GizmoKit and Remote Presence: Regardless of which level of Unconscious State the target is in, with a single successful PH Roll, they remove all the Wounds necessary to cancel their Unconscious State.

- Regardless of which level of Unconscious State the target is in, with a single successful PH Roll, they remove all the Wounds necessary to cancel their Unconscious State.

# GizmoKit — Interactions & Unofficial Commentary

## [UNOFFICIAL COMMENT] General Function
GizmoKit is the engineering equivalent of a MediKit for troopers with the **STR Attribute**.  
It automatically provides a chance to **remove a Wound** or **cancel Unconscious** after a PH roll, either:
- Via **remote BS Attack** (Non-Lethal) requiring LoF, or  
- Via **contact use** requiring Silhouette contact (no BS Roll).

A **failed PH roll inflicts a Wound**, possibly forcing the target into **Unconscious or Dead**.

---

# [UNOFFICIAL COMMENT] Core Interactions

## GizmoKit vs. Engineer
- **Engineer** performs repairs through a **WIP Roll** using his WIP, in Silhouette contact.  
- **GizmoKit** allows *ranged* Wound removal, as well as in contact, but using the target's PH.
- Engineer can also cancel STATES (Imm-A/B, Isolated, Stunned, Targeted, etc.).  
- GizmoKit **does not inherently cancel states**—states are only canceled if paired with **Tech-Recovery** or other rules that explicitly allow cancellation.

## GizmoKit + Remote Presence
Remote Presence allows a trooper with multiple levels of Unconscious to rise fully with **one successful PH roll**.  
This makes GizmoKit extremely order-efficient on REMs and remote TAGs and gives more leeway if a roll fails (as Remote Presence allwos 2 levels of Unconscious).

**Advantages:**  
- Single PH success restores from ANY level of Unconscious.  
- Ranged application = less need to expose Engineers.

**Disadvantages:**  
- Failure still inflicts a Wound, so a REM in Unconscious level 2 may still die on a failed PH.

---

## GizmoKit + Tech-Recovery
Tech-Recovery allows a trooper to cancel **all Engineer-cancelable states** (Imm-A, Imm-B, Isolated, Targeted, Stunned, Disconnected) **in a single PH roll** after being hit by a GizmoKit.

**Benefits:**  
- The GizmoKit becomes a ranged *mass state-clearing tool*.  
- A single successful PH roll can undo multiple debuffs simultaneously.  
- Works even if the model is in a Null state (Tech-Recovery stays active).

**Limitations:**  
- Still requires a successful GizmoKit hit.  
- PH-dependent; low-PH units are unreliable.

---

## GizmoKit + Technorganic
Technorganic allows both Doctor and Engineer (and MediKit/GizmoKit) to cancel **Unconscious**, even on models with inconsistent STR/VITA attributes.

**Effects with GizmoKit:**  
- A GizmoKit may revive a Technorganic trooper, regardless of STR or VITA.  
- After revival, further GizmoKit use may have no effect if the trooper lacks STR (rules limitation).

# [UNOFFICIAL COMMENT] Comparison with MediKit

### GizmoKit (STR units)
- Works on STR Attribute models.  
- Removes Wounds even if target is not Unconscious
- Cancels Unconscious on PH success.  
- Failure **inflicts** a Wound.  
- Can be used remotely (BS Attack).

### MediKit (VITA units)
- Works on VITA Attribute models.  
- Removes Wound/cancels Unconscious on PH success, but target needs to unconscious to heal.
- Failure **kills** the target outright—since target is already unconscious.

### Pros / Cons Comparison

**GizmoKit Pros**
- Remote healing on STR targets.  
- Synergy with Tech-Recovery for state clearing.  
- Very strong on REMs with Remote Presence.  

**GizmoKit Cons**
- Requires LoF for remote use.  
- Less reliable on low-PH platforms.

**MediKit Pros**
- Only allows healing when target is unconscious.
- Often paired with high-WIP Doctors.  

**MediKit Cons**
- Failure = instant Dead.  
- No synergy with Engineer-only state cancellations.

# [UNOFFICIAL COMMENT] Common Tactical Uses

### 1. Ranged Revival for REM-heavy Lists
GizmoKits allow safe revival without exposing an Engineer.  
Particularly strong in:
- O-12  
- ALEPH  
- Nomads  
- PanO REM-heavy builds

### 3. Fireteam Synergy
Fireteams containing models with GizmoKits can:
- Heal the Team Leader at range without breaking position  
- Avoid dangerous movement to bring an Engineer forward  
- Provide reliable backup for TAGs or REMs supporting the team
- Fireteam SD bonus applies to Gizmokit range attack roll

# [UNOFFICIAL COMMENT] Pros & Cons of GizmoKit (Standalone)

### Pros
- Ranged healing for STR troopers.  
- Order-efficient revival of REMs with Remote Presence.  
- Combines with Tech-Recovery for long-range debuff clearing.  
- Safe positioning—no need to expose Engineers.

### Cons
- Requires LoF for remote use.  
- PH-dependent—remotes often have only moderate values.  
- Does not directly cancel Engineer-state tokens unless paired with Tech-Recovery.

---

# [UNOFFICIAL COMMENT] Summary
GizmoKit is a **risk–reward tool** that becomes dramatically stronger when combined with:
- **Remote Presence** (efficient revival)  
- **Tech-Recovery** (mass state clearing)  
- **Fireteams** (positional support without breaking formation and SD bonus)

Used carefully, it is one of the most order-efficient ways to restore STR models in Infinity N5.
