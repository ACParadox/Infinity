# Infinity N5 rules

**Current rules baseline: N5.3 + N5 FAQ v0.1 (September 1, 2026).**

The Markdown files under `rules/` are a local reference copy of the Infinity N5 rules plus project commentary. When a local page still contains wording inherited from an older snapshot, the N5.3/FAQ material below is authoritative until that page is corrected.

- `N5.3_Changes.md` — N5.3 rules changes, including the smaller corrections visible on pages tagged `N5.3 Update` on the official Infinity Wiki.
- `N5_FAQ_0.1.md` — September 2026 FAQ v0.1 rulings, deduplicated from the official wiki's cross-listed FAQ entries.

Official references:
- https://infinityuniverse.com/en/news/infinity-rules-update-5-3
- https://infinitythewiki.com/Category:N5.3_Update
- https://infinitythewiki.com/Category:N5_FAQ_0.1

Where a rule page is edited for this release, use a callout/header containing **`N5.3 change`** (or **`N5 FAQ v0.1 clarification`**) so version-specific wording remains easy to audit later.
