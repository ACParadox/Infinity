# Infinity N5 rules

**Current rules baseline: N5.3 + N5 FAQ v0.1 (September 1, 2026).**

The Markdown files under `rules/` are a local reference copy of the Infinity N5 rules plus project commentary. N5.3 changes have been folded directly into the relevant canonical rule pages where practical. Large generated/reference pages use explicit versioned override files so older generated material is not silently truncated.

## N5.3 / FAQ authority

- `N5.3_Changes.md` — complete deduplicated N5.3 rules changelog, including smaller corrections visible on pages tagged `N5.3 Update` on the official Infinity Wiki.
- `N5_FAQ_0.1.md` — all distinct September 2026 FAQ v0.1 rulings, deduplicated from the official wiki's cross-listed FAQ entries.
- `N5.3_Modifier_Clarifications.md` — Dodge (ARM+3), PARA CCW (-6), and pointer to the Protheion modifier clarification.
- `4_Ammunition and Weaponry/N5.3_Weapon_Updates.md` — authoritative N5.3 override for changed/new weapon-chart entries until the large generated charts are regenerated.
- `4_Ammunition and Weaponry/N5_FAQ_0.1_Deployable_Placement.md` — fired-Deployable vertical-surface FAQ ruling for Pitcher, Drop Bears, Disco Baller, and Mine Dispenser.
- `5b_Special Skills/Peripheral_N5.3_Update.md` — Cyberplug N5.3 wording plus Peripheral FAQ v0.1 rulings.

If an older generated/reference page conflicts with one of the versioned files above, **the N5.3 / FAQ v0.1 file wins**.

## Version annotations

Where a canonical rule page was edited for this release, the new/current wording is marked with a callout/header containing **`N5.3 change`**. FAQ-only changes use **`N5 FAQ v0.1 clarification`**. This makes later edition audits and diffs explicit.
