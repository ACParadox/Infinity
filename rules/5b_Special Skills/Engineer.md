# Engineer

Special Skills
 SHORT SKILL
Optional 

Engineers have the means and the skill to repair damaged Equipment on the field.

- Troopers using this Special Skill must be in Silhouette contact with their target.

- Engineer allows, by passing a Normal WIP Roll, removing a Wound from a target with the Structure Attribute (STR). This cancels Unconscious State if applicable.

- This Special Skill can be declared as many times as necessary to remove all the Wounds that the target has.

- If the Engineer fails the Normal WIP Roll, the target receives a Wound instead of removing it, entering Unconscious or Dead State if applicable.

- Alternatively, by passing a Normal WIP Roll, a Trooper with Engineer may cancel all of their target's States that can be canceled by this Special Skill except Unconscious ( Immobilized -A and B, Targeted, etc.), removing the corresponding State Tokens.

- Failing the Normal WIP Roll when trying to cancel other states has no negative consequence, and the Roll can be performed again in future Orders.

- A Trooper with the Engineer Special Skill can use it on themselves, to remove any Wounds they have received, or cancel any states that can be canceled by Engineer. However, this cannot be done if the Trooper is in a Null State.

- Engineer (ReRoll WIP=X ): Once per Order, any failed Roll with this Skill may be rerolled, but applying the WIP Attribute indicated between brackets. The player must accept the result of this last Roll. This reroll does not provide a new ARO to the enemy.

Even if the player failed the roll granted by Engineer (ReRoll WIP=X), they could still apply the Operational Use of the Command Tokens to repeat an Engineer’s WIP Roll.

However, the Attribute value provided by the Engineer (ReRoll WIP=X) Skill does not apply when repeating this Roll.

Engineer can be used to cancel these States:

- Disconnected State

- Immobilized-A State

- Immobilized-B State

- Isolated State

- Stunned State

- Targeted State

- Unconscious State (See above for restrictions.)

## Engineer - Command Tokens: Operational Use and Remote Presence

If the target has Remote Presence, Command Tokens can be expended to reroll failed Engineer Rolls.

## Engineer - Technorganic

- The Unconscious State of the Trooper can be cancelled by using either the Doctor or Engineer Skill, or the MediKit or GizmoKit pieces of Equipment, regardless of whether they have the VITA or STR Attribute.

## Engineer - Order Expenditure Sequence

If a Trooper receives and removes Wounds or States in the same Order, the positive effect is always applied first, followed by the negative effect.

# Engineer — Unofficial Commentary and Interaction Notes

## [UNOFFICIAL COMMENT] General Role
Engineer is the primary method for repairing STR-based units (REM, TAGs, some Heavy Infantry with STR, etc.) and for clearing many debilitating States. 

## [UNOFFICIAL COMMENT] Interactions with GizmoKits
- GizmoKits and Engineer overlap: both recover STR and cancel Unconscious.  
- Engineer requires Silhouette contact; GizmoKit does not (when used as a BS Attack).  
- Engineer recovers Wounds on STR units with a WIP Roll; failing causes a Wound.  
- GizmoKit uses the target’s PH; failing causes a Wound.  

**Pros of Engineer vs GizmoKit**
- Higher chance to succeed if WIP > target PH.  
- Can clear multiple States at once.  
- Can repair specialized cases like Technorganic, Remote Presence second level, etc.

**Pros of GizmoKit vs Engineer**
- Can be performed at range.  
- No need to expose the Engineer above the wall or into danger.  

## [UNOFFICIAL COMMENT] Interactions with States
Engineers can cancel Immobilized-A, Immobilized-B, Targeted, Stunned, Isolated, and Unconscious (with usual restrictions).

**Common tactical patterns:**
- **Versus hacking-heavy opponents:** Engineer is one of the few direct counters to Oblivion (Isolated), Targeted, and Carbonite (IMM-B).  
- **Versus PARA ammunition:** giving IMM-A, Engineer can reliably remove the state with WIP.  
- **Reset vs Engineer:** Reset cancels some states but with penalties; Engineer provides a more reliable or safer alternative.


**Pros of Engineer over Doctor**
- Failure is less lethal (only hurts STR targets, often with extra Unconscious level).  
- Remote Presence rerolls make Engineer extremely reliable.  
- Fixes States that Doctor cannot.  

**Pros of Doctor over Engineer**
- Recovers VITA troops that Engineers cannot repair.  
- Doctor is better for factions depending on cheap LI.

## [UNOFFICIAL COMMENT] Remote Presence Synergy
Remote Presence targets can reroll failed Engineer Rolls using Command Tokens, on top of any rerolls from Engineer (ReRoll WIP=X). This gives Engineers the highest success potential in the game for restoring a unit.

**Implications:**
- TAG lists effectively require an Engineer for maximum board longevity.  
- Remotes become durable anchor pieces when supported by an Engineer.

## [UNOFFICIAL COMMENT] Risk Management When Repairing
Repair failure deals a Wound to the target, possibly killing it. Engineers should avoid repairing:
- Targets with only **1 STR remaining** and **not** having Remote Presence.  
- Units exposed to enemy AROs that might kill the Engineer before completion.  
- Units that require many Orders to reach safely.

When safe, repairing a Remote Presence target with two layers of rerolls is extremely efficient and should usually be done.

## [UNOFFICIAL COMMENT] Servant Bots (Peripheral: Servant / Cyberplug)
Servant units dramatically extend an Engineer’s area of influence.  

## [UNOFFICIAL COMMENT] Competing Roles: Engineer vs Paramedic vs Doctor
- **Paramedic**: uses MediKit at range but kills on failure; cannot repair STR or clear Engineer-specific States.  
- **Engineer**: safer, more controlled, and covers more States.  
- **Doctor**: crucial for VITA units but less helpful in robot/TAG armies.

**Typical faction choices:**
- ALEPH, PanO, Nomads: heavy REM/TAG focus → Engineer preferred.  
- Haqqislam, Ariadna: VITA-heavy armies → Doctor/Paramedic more common.

## [UNOFFICIAL COMMENT] Tactical Uses Beyond Repairs
- Removing Targeted on key pieces to avoid enemy Guided missile strategies.  
- Clearing Isolated to restore valuable Order contributors.  
- Fixing Immobilized on heavy assault pieces before pushing into the next attack.  
- Clearing Stunned from key shooters to maintain Fireteam effectiveness.  
- Resurrecting TAGs from double-Unconscious with Remote Presence.


## [UNOFFICIAL COMMENT] Optimal Unit Types to Repair
Best to repair:
- TAGs (high value, multiple STR, Remote Presence for rerolls).  
- REM gunfighters (TR bots, FO bots, attack remotes).  
- Heavy remotes used for mission objectives (e.g., EVO, Repeater REMs).  
- Technorganic troops with STR.

Avoid repairing:
- Disposable or cheap STR troops where the Orders are not worth the return.  
- Units that are likely to die again due to bad positioning.

## [UNOFFICIAL COMMENT] Practical Order Efficiency Notes
- Sometimes clearing a State (IMM-B, Isolated, Targeted) is more important than recovering STR.  
- When both clearing and repairing occur in the same Order, positive effect applies first — meaning you can safely repair before a negative effect applies, or vice versa depending on timing.

## [UNOFFICIAL COMMENT] Strategic Summary
Engineer is one of the strongest utility roles in Infinity N5:
- Counters hacking-heavy and state-focused opponents.  
- Provides exceptional longevity when paired with Remote Presence.  
- Extends tactical resilience in objective play and Fireteam support roles.  
- Requires careful movement planning to leverage Servants and avoid unnecessary risk.
