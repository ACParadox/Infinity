# Remdriver

Special Skills
 DEPLOYMENT SKILL
Optional 

This Special Skill allows its owner to provide MODs to a Remote in the same Army List.

- When deploying the owner of this Special Skill, the player will place a REMDRIVER Token beside a Remote already deployed on the game table.

- A Remote possessing a REMDRIVER Token will benefit from the MODs appearing in round brackets in the Unit Profile of the owner of this Special Skill.

- The player will remove the REMDRIVER Token at the end of the Order in which the owner of this Special Skill enters any Null State.

- A Remote cannot have more than one REMDRIVER Token.

## [UNOFFICIAL COMMENT]
Remdriver is one of the strongest “passive buff” profiles available in the N5 ruleset because it adds permanent MODs to a chosen Remote for as long as the Remdriver trooper remains alive and non-Null. These MODs can be BS, PH, CC, Dodge, or other stat improvements, depending on the unit profile.

The ability to assign the REMDRIVER Token during deployment means that:
- You do not need the Remdriver to spend Orders later to apply the buff.
- The buff persists with no range limit and requires no further upkeep.
- REMDRIVER interacts with the Remote’s stat line directly, modifying it before any other MOD calculations.

Because the buff ends immediately when the Remdriver enters a Null State, protecting the Remdriver can be as essential as protecting the Remote.

## Interactions with Other Rules

### **Remote Presence**
Remote Presence Remotes often have multiple structure levels, better resilience, and can frequently be Engineer-supported. A Remdriver buff (such as +1 BS or +1 PH) compounds their natural durability. They become significantly more order-efficient long-range or objective pressure pieces.

### **Fireteams**
If the chosen Remote is part of a Fireteam (Sectorials that allow it), Remdriver MODs apply **in addition to** Fireteam bonuses.  
**[UNOFFICIAL COMMENT]** This can create extremely high-BS or high-Burst defensive platforms.

### **Coordinated Orders**
The Remdriver effect applies to a Remote even when it participates in Coordinated Orders. The MODs influence the Remote’s Attribute for all Rolls it makes.

### **Null State Triggers**
The moment the Remdriver enters any Null State, the REMDRIVER Token is removed immediately at the **end of that same Order**.  
**[UNOFFICIAL COMMENT]** This can matter when the Remdriver is knocked Unconscious by an ARO during the Active Turn—your Remote will finish its current Roll with the buff, but will lose it before your next Order.

### **Multiple Remdrivers**
Because "a Remote cannot have more than one REMDRIVER Token," stacking MODs from multiple Remdrivers is impossible.  
**[UNOFFICIAL COMMENT]** However, multiple Remdrivers in an army allow redundancy and can support different Remotes.

## Comparison to Similar Effects

### **Remdriver vs. TAGCom**
- **Remdriver** affects **one Remote**, providing stat MODs directly.
- **TAGCom** affects **all TAGs in the Combat Group**, but only applies the specific MODs provided by the TAGCom profile.  
**Remdriver = single, strong buff.**  
**TAGCom = group-wide, lighter buffs.**

## Tactical Usage Notes

**Best Remdriver targets:**
- **Total Reaction REMs (TR HMG)**  
  Extra BS makes them terrifying ARO pieces.
- **Missile REMs**  
  Increased BS turns a template weapon into a devastating active-turn hitter.
- **EVO or Sensor REMs**  
  +WIP can dramatically improve Discover chains and mission utility.
- **Fast mobility REMs**  
  +PH helps Dodges, improving survivability.

**Protect the Remdriver:**
- Keep them in the backline or in full cover.
- Consider bodyguards or smoke support if possible.
- Avoid leaving them exposed to speculative fire or templates.
