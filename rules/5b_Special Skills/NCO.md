# NCO

Special Skills
 AUTOMATIC SKILL
Optional 

This Special Skill designates the trusted non-commissioned officer of the Lieutenant, who can operate under their direct orders.

- Allows the user to replace any Special Lieutenant Orders with Tactical Orders and to use them.

- This Special Skill does not require the NCO and the Lieutenant to be in the same Combat Group.

- If the Trooper with this Special Skill is a member of a Fireteam and is designated as the Team Leader, then he may use that Tactical Order to activate their Fireteam.

To use the Lieutenant Order, the Order must have been generated during the Order Count. Once generated, the Order may be spent during the Orders Phase, even if the Lieutenant has entered a Null State since then.

Isolated State

- Restriction: If a Trooper with the NCO Special Skill is in Isolated State, they cannot replace Special Lieutenant Orders with Tactical Orders or use them either.


**[UNOFFICIAL COMMENT]**

## UNOFFICIAL COMMENTARY — Purpose of NCO
NCO is effectively a mechanism to **unlock Lieutenant resources without revealing your Lieutenant**.  
It lets a non-Lieutenant trooper spend the Lieutenant’s Special Order(s) — including LTs with +1 Order — and converts each into a Tactical Order solely for that NCO.

This is extremely valuable in armies where the Lieutenant is vulnerable or positioned defensively. NCO provides flexibility by allowing aggressive pieces or Fireteam Leaders to harness otherwise unused LT Orders.

## Interactions and Edge Cases

### 1. **Lieutenant in a Different Combat Group**
NCO can use the LT Order even if the Lieutenant is in another Combat Group.  
This avoids the classic “my LT is isolated in Group 2” problem.  
Only the Special Lieutenant Order’s existence matters — not location.

### 2. **Lieutenant Enters Null State AFTER Order Count**
The rules explicitly state that as long as the LT Order was generated during the Order Count, it can be spent even if the Lieutenant later becomes Unconscious/Dead during the turn.  
NCO therefore **does not lose access** to the LT Order mid-turn.

### 3. **Fireteam Use**
If the NCO is Team Leader, the converted Tactical Order can be spent to activate the Fireteam.  
This makes NCO one of the strongest Skills for Fireteam-centric armies — especially for turn-1 aggression or fixing bad positioning without draining the main Order Pool.

### 4. **Isolated State**
If the NCO is Isolated:
- Cannot convert the LT Order into a Tactical Order  
- Cannot use the LT Order in any form  

However, the Lieutenant’s own LT Order still exists; only the NCO’s use of it is denied.  
Contrast this with the Lieutenant being Isolated (which triggers Loss of Lieutenant next turn).

### 5. **Strategos Interaction (Comparison)**
Strategos L1+ allows the Lieutenant to **convert LT Orders into Regular Orders**.  
**NCO does not convert anything into Regular Orders** — the Order becomes a Tactical Order spent only by the NCO.  
Using both together:
- If Strategos converts the LT Order into a Regular Order, then **there is no LT Order for NCO to use**.  
- Thus: *Strategos overrides NCO benefits.*

### 6. **Tactical Awareness Interaction**
Tactical Awareness adds a Tactical Order to the trooper who has TA.  
NCO does not affect TA Orders.   
But if it has tactical order, it stacks, producing large self-contained resource packages.

### 7. **Chain of Command Interaction**
Chain of Command does not itself interact with NCO.  
However:
- CoC often wants to stay hidden  
- NCO often wants to be active  
This leads to complementary list building (e.g., NCO piece spends orders; CoC hides to protect the LT slot).

### 8. **Coordinated Orders**
NCO can spend the converted Tactical Order **only on themselves or their Fireteam**.  
It does NOT allow Coordinated Orders (Tactical Orders cannot be used for Coordinated Orders unless explicitly permitted — they are not).

### 9. **NCO vs. Lieutenants with +1 Order**
If the LT has +1 Order, they produce **two** Special Lieutenant Orders.  
NCO can convert **each** to Tactical Orders.  
This effectively becomes:
- 2 extra NCO activations  
- Or 2 Fireteam activations if the NCO is Leader

This multiplication is one of the most efficient order-generation synergies in Infinity.

## PROS AND CONS OF NCO

### **Pros**
- Provides extra orders on an aggressive or key piece.  
- Does not reveal the Lieutenant.  
- Works even if LT and NCO are in different Combat Groups.  
- Strong synergy with Fireteams (free Team Leader activations).  
- Extremely potent with LT (+1 Order).  
- Helps avoid “wasted” LT Orders on defensive Lieutenants.

### **Cons**
- Shut down by **Isolated State**.  
- Mutually exclusive in function with **Strategos** (Strategos steals the order first).  
- Requires the LT to survive *at least into the Order Count*.  
- Tactical Orders can’t be used for coordinated actions.  

## Comparison: NCO vs Tactical Awareness vs Strategos

### **NCO**
- Uses the *Lieutenant’s* Special Order(s)  
- Order becomes Tactical Order for NCO  
- Best for aggressive attack pieces / Fireteam leaders  

**Pros:** Always available unless trooper is Null/undeployed.  
**Cons:** Only usable by its owner.

### **Strategos**
- Converts LT Orders into Regular Orders for the whole Combat Group  
- Most flexible use of the LT Order  

**Pros:** Whole pool benefits, no need for NCO  
**Cons:** Reveals the Lieutenant, makes NCO redundant

### **Summary**
- **NCO** = “high-impact free order for a chosen piece, keeps LT hidden”  
- **Strategos** = “group-level free order, but exposes LT”

## NCO Tactical Use Cases
- Running aggressive HI/MI NCO as the core of a Fireteam.  
- Armies with fragile Lieutenants that must stay back-line.  
- Alpha-strike lists requiring 1–2 extra activations on a key attacker.  
- Sectorials with good NCO profiles (e.g., heavy infantry or gunfighters).  
- Lists leveraging Lieutenant (+1 Order)
