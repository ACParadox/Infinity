# Tech-Recovery

Special Skills
 AUTOMATIC SKILL
Optional 

This Special Skill indicates the capacity to cancel States when an allied GizmoKit is applied to its user.

- The user must be in a State that can be canceled by the Engineer Special Skill.

- The user has received a successful hit from an allied GizmoKit, or it has been applied to them through Silhouette contact.

- By passing a Normal PH Roll, the user cancels all their States that can be canceled by the Engineer Special Skill ( Immobilized-A, Immobilized-B, Isolated, Targeted...), removing the corresponding State Tokens.

- Restriction. This Special Skill does not apply to Unconscious State, which must be canceled by applying the usual rules.

- Failing the Normal PH Roll has no negative consequences, and the Roll can be performed again in future Orders.

- If the user lists GizmoKit in their Unit Profile with a PH value between brackets, they will apply this PH value when a GizmoKit is used on them.

- This Special Skill remains active even when its owner is in a Null State.

Engineer can be used to cancel these States:

- Disconnected State

- Immobilized-A State

- Immobilized-B State

- Isolated State

- Stunned State

- Targeted State

- Unconscious State

A Trooper with the Aerial and Tech-Recovery Special Skills is in Unconscious, Immobilized-A, and Isolated States. An ally makes a successful BS Attack with its GizmoKit against them, so they can make a Normal PH Roll to cancel its Unconscious State. Upon passing the Roll, the Unconscious State is cancelled and the State Token is removed.

Now, the ally with a GizmoKit spends a new Order and makes another successful BS Attack against the same target, with the intention of canceling the two remaining States, as that Trooper has the Tech-Recovery Special Skill. The Trooper makes a Normal PH Roll and, after passing it, cancels the Immobilized-A and Isolated States, removing the corresponding State Tokens.


**[UNOFFICIAL COMMENT]**
Tech-Recovery allows a trooper to clear *multiple* Engineer-cancelable States at once after being hit by an allied GizmoKit. It does not work on Unconscious (that state must be canceled normally first), but once the model is conscious, any combination of Immobilized-A, Immobilized-B, Isolated, Targeted, Stunned, or Disconnected can all be removed by a single successful PH Roll.

**[UNOFFICIAL COMMENT – INTERACTION WITH GIZMOKIT]**
GizmoKit becomes dramatically more efficient when used on Tech-Recovery models:
- A normal Remote or HI must be repaired by an Engineer one State at a time, but a Tech-Recovery unit clears all eligible States in one roll.
- Long-range GizmoKit fire becomes a strong support tool, as a single hit can fully reset multiple crippling debuffs.

**[UNOFFICIAL COMMENT – INTERACTION WITH ENGINEER]**
Tech-Recovery does *not* replace the Engineer; instead, it allows the trooper to self-repair after a GizmoKit hit:
- Engineer is still required to cancel Unconscious.
- After Unconscious is cleared, Tech-Recovery handles the rest more efficiently than an Engineer spending multiple Orders.
- A Tech-Recovery trooper with an Engineer nearby effectively becomes extremely hard to permanently disable with debuff ammo (E/M, PARA, etc.).

**[UNOFFICIAL COMMENT – COMMON INTERACTIONS]**
• **E/M Ammunition:**  
  Usually inflicts Isolated + Immobilized-B on HI, TAGs, and REMs. Tech-Recovery removes both in one successful PH roll after being hit by a GizmoKit.

• **Stun Weapons / PARA Ammunition:**  
  These often apply additional Engineer-cancelable States. Tech-Recovery allows a one-roll reset, whereas standard troops require Engineer actions.

• **Targeted State:**  
  Tech-Recovery removes Targeted along with any other valid States, enabling a quick escape from guided missile setups.

• **Fireteam Support:**  
  In a Fireteam, a long-range GizmoKit from a member can clear the Team Leader’s debuffs without breaking Fireteam positioning to bring the Engineer forward.

**[UNOFFICIAL COMMENT – COMPARISON WITH OTHER RECOVERY SKILLS]**

1. **Tech-Recovery vs. Technorganic**
- Tech-Recovery does *not* allow self-cancellation of Unconscious.  
- Technorganic allows both Doctors and Engineers to cancel Unconscious.  
- Tech-Recovery shines in clearing multiple debuffs, not in reviving.

Pros (Tech-Recovery):
- Clears many States at once.  
- Works at long range with GizmoKit.  
- No downsides on failed rolls.

Cons (Tech-Recovery):
- Cannot cancel Unconscious.  
- Requires an external GizmoKit hit.  
- Still needs an Engineer/Doctor to bring the trooper back from Null.

**[UNOFFICIAL COMMENT – PROS]**
- Extremely order-efficient recovery after E/M or multiple States.
- Allows ranged state clearing via GizmoKit hits.
- Excellent for high-value HI/TAG/REM key pieces.
- No penalty for failed PH rolls.

**[UNOFFICIAL COMMENT – CONS]**
- Does nothing for Unconscious.  
- Requires ally to apply GizmoKit successfully.  
- Still PH-dependent; low-PH models may struggle.  
- Does not remove non-Engineer-cancelable States (e.g., Suppression Fire, Engaged).

**[UNOFFICIAL COMMENT – TACTICAL NOTES]**
- Keep an Engineer or GizmoKit-equipped troop close enough to support without exposing them to danger.  
- Best used on durable pieces expected to receive debuff ammo (E/M, PARA, Stun).  
- Combine with Fireteam members carrying GizmoKits for safe, repeatable long-range condition clearing.  
- Against factions with heavy hacking or E/M weapons, Tech-Recovery increases survivability massively.
