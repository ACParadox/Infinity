# Protheion

> **N5.3 change (September 2026):** When Protheion has a negative MOD in brackets, such as `Protheion (-3)` or `Protheion (-6)`, that MOD is applied to the **Enemy's Attribute** when performing the Face to Face Roll.

Special Skills
 AUTOMATIC SKILL
CC Special Skill, Optional. 

Users of this CC Special Skill can remove Wounds or increase the value of their Vitality Attribute whenever they inflict Wounds in Close Combat.

- In the Active or Reactive Turn, the Trooper must reach or be in Silhouette contact with the target and declare a CC Attack.
- The target must have the VITA Attribute.
- For each Wound they inflict on the target of the CC Attack, or Coup de Grâce they perform, the user removes 1 Wound they have received. If the user hasn't received any Wounds, they increase their VITA Attribute value by 1.
- Restriction: The value of the user's VITA Attribute may only be increased by a maximum of two points.
- If the user's VITA Attribute is higher than its original value, the player must place a Power-Up 1 or Power-Up 2 Token to indicate the current value.
- When multiple Wounds are inflicted in the same Order: first remove Wounds already received; then use remaining inflicted Wounds to increase VITA up to the +2 maximum; finally apply any Wounds inflicted on the Protheion user during that Order.
- **N5.3:** When declaring this Special Skill, any negative MOD between brackets is applied to the Enemy's Attribute in the Face to Face Roll.

## Protheion FAQs

Q: What happens if the target of a Protheion user fails more Saving Rolls than are needed for it to enter Dead State? For example, if an Unconscious target fails two or more Saving Rolls.

A: Any additional failed Saving Rolls have no effect and do not benefit the Protheion user.

**[UNOFFICIAL COMMENT]**
The N5.3 parenthetical MOD is an offensive Face-to-Face modifier: `Protheion (-3)` modifies the opponent's relevant Attribute by -3 for that Face-to-Face Roll. It is not a bonus to the Protheion user's own Attribute.
