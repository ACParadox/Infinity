# Infinity Spec-Ops

> **N5.3 change (September 2026): NEW RULE.** Infinity Spec-Ops and Request SpecBall were added in N5.3.

Special Skills
AUTOMATIC SKILL
Optional

Infinity Spec-Ops are customizable elite operatives. Their Unit Profile and later battlefield upgrade are configured through the Spec-Ops rules.

## Infinity Spec-Ops

- When creating the Army List, the player may customize a Trooper with this Special Skill.
- Select the normal Skill/Weapon/Equipment option for the profile, then choose **two different options** from the available Spec-Ops Chart.
- A Spec-Ops Trooper has an **Initial Profile** and an **Enhanced Profile** and always deploys using the Initial Profile.
- The two chosen Spec-Ops Chart options apply to both profiles.
- The Enhanced Profile is obtained by collecting the Trooper's SpecBall through **Request SpecBall**.
- Restriction: an Army List cannot include more than one Trooper with Infinity Spec-Ops.

# Request SpecBall

AUTOMATIC SKILL
Optional

## Requirements

- The player has a non-Null Trooper with Infinity Spec-Ops.
- It is **Game Round 2 or 3** and the player's Active Turn.

## Effects

- Place one 55 mm SpecBall Token using the Combat Jump placement rules and make its deployment Roll using **PH 15**. Request SpecBall cannot be used partway through the Order Expenditure Sequence.
- Before rolling, choose **two different items** from the SpecBall Chart for that drop.
- SpecBall items are unique and non-transferable.
- The SpecBall Token cannot be placed in Silhouette contact with Models, Markers, Tokens, or Scenario Objectives.
- When the allied Spec-Ops Trooper in a non-Null State enters Silhouette contact with its SpecBall, it automatically collects the contents. This cancels any Marker State it is in.
- At the end of that Order, replace the Initial Profile with the **Enhanced Profile**, applying the SpecBall items. Remove the SpecBall Token.
- Wounds and applicable States carry over from the Initial Profile to the Enhanced Profile.
- If a SpecBot was one of the selected items, place its Model in Silhouette contact with the Spec-Ops Trooper at the end of the Order.
- SpecBall Tokens are State Tokens; they do not block enemy movement and cannot be targeted by Deactivators.
- Restriction: **each player may use Request SpecBall only once per game.**

## Tournament note

The official Infinity Wiki notes that Spec-Ops rules are not allowed in official ITS Season 18 tournaments unless the relevant event/scenario rules state otherwise.
