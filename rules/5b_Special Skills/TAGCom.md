# TAGCom

Special Skills
 AUTOMATIC SKILL
Optional 

The TAGCom is the tactical uplink of the TAGs. It is their operational support and their eyes and ears on the ground, so it improves their survivability.

- While the user is deployed on the table in a non- Null State, all TAGs in their Combat Group benefit from the MODs listed between brackets in the user's Unit Profile.

- Individual TAGCom MODs are not cumulative, the player may only apply those that are different from each other.

# TAGCom — Unofficial Interactions & Commentary
# ============================================

## [UNOFFICIAL COMMENT]
TAGCom represents a TAG-focused command-and-control uplink. It gives global MODs (listed in the TAGCom user's profile) to *all TAGs in the same Combat Group*, as long as the TAGCom carrier is deployed and not in a Null State.

Because TAGCom lists no specific MODs in the rule itself, every army’s implementation depends entirely on the profile. Usual examples include BS bonuses, PH bonuses for Dodge, WIP bonuses for Reset, or defensive MODs—but always check the actual Unit Profile.
------------------------------------------------------------

## TAGCom Interactions with Core Game Systems
### 1. Combat Groups
**[UNOFFICIAL COMMENT]**
- TAGCom only affects TAGs *in the same Combat Group*.  
- Moving the TAGCom carrier to a different group mid-game (Command Tokens, Tactical Phases) will instantly switch which TAGs benefit.

### 2. Null State & Survival
**[UNOFFICIAL COMMENT]**
- Benefits end immediately when the TAGCom user enters **any Null State** (Unconscious, Dead, etc.).
- Doctor/Engineer recovery that cancels the Null State also *reactivates* the TAGCom benefits.
- Being Prone, Isolated, Immobilized, Targeted, etc. does **not** cancel TAGCom.

------------------------------------------------------------

## TAGCom Tactical Use Cases
### 1. TAG-focused Combat Groups
**[UNOFFICIAL COMMENT]**
- TAGCom is strongest when a group contains:
  - Multiple TAGs (primary),
  - A mix of TAGs with Tactical Awareness,
  - TAGs serving aggressive and reactive roles.

### 2. Defensive TAGs
**[UNOFFICIAL COMMENT]**
If the MOD includes Dodge/Reset bonuses:
- Improves reactive survivability.
- Makes TAGs harder to pin down with Hacking, Adhesive, or immobilizing ammo.

### 3. Aggressive TAGs
**[UNOFFICIAL COMMENT]**
If the MOD includes BS/PH/Movement bonuses:
- Improves alpha strikes.
- Enhances duo-TAG pushes or Coordinated Orders.

------------------------------------------------------------

## TAGCom Pros & Cons Summary
**[UNOFFICIAL COMMENT]**

**Pros**
- Wide-area, passive benefit for all TAGs in Combat Group.
- Synergizes extremely well with multi-TAG lists.
- Benefits return immediately if the TAGCom user is healed from Null.
- Can stack *distinct* MODs if you bring multiple TAGCom units.

**Cons**
- Entire ability shuts down if the TAGCom user enters a Null State.
- Does nothing for REMs, Heavy Infantry, or other non-TAG assets.
- Occupies points/slots for a model that might otherwise be optimized differently.
- Requires Combat Group planning to ensure TAGs are placed properly.
