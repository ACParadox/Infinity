# Explode

Special Skills
 AUTOMATIC SKILL
Attack, Obligatory. 

This Special Skill marks the Trooper's capacity to detonate in a blast

- The user must be in Unconscious State for this Special Skill to activate.

- This Special Skill forces its user to detonate automatically when he enters Unconscious state.

- At the end of the Order in which the user entered Unconscious State, before making Guts Rolls, the Trooper makes a Direct Template Attack, placing the center of the Circular Template (Blast Focus) over the center of their base.

- Explode applies Shock Ammunition, forcing targets to make a Saving Roll against ARM, with PS7.

- Enemy Troopers who are affected by the Attack and had performed a Dodge will avoid this Attack if they passed their PH Roll.

- Once all Rolls have been made, the user enters Dead State and is removed from the game table.

If a Trooper enters Dead State directly due to a Special Skill (e.g. Dogged ), an Ammunition (e.g. Shock ), or because he suffers several Wounds in a single Order, this Special Skill does not activate.

If the user activates the Dogged or No Wound Incapacitation Special Skills when entering Unconscious State, he does not Explode.

Template Attacks that affect allied Models or Markers are canceled, but the user of Explode still enters Dead State.


**[UNOFFICIAL COMMENT]**

### INTERACTIONS WITH OTHER RULES

**Dogged / No Wound Incapacitation (NWI)**
- If the Trooper activates Dogged or NWI when entering Unconscious, Explode does NOT occur.
- If something kills the Trooper directly (e.g., Shock, multiple Wounds in the same Order), the Trooper never became Unconscious → Explode does NOT trigger.

**Shock Ammunition**
- Shock that sends a Trooper directly to Dead prevents the Unconscious state → Explode cannot occur.
- Conversely, Explode itself uses Shock, so enemies without Immunity (Shock) risk being killed outright.

**Template Cancellation with Allies**
- It's a Direct Template Attack, so if the Explode template would affect allied Troopers, the Attack is canceled, but the user still dies.
- This prevents friendly-fire damage, but still removes your own model.

**Exrah**
- Exrah Troopers go directly to Dead when entering Unconscious and cannot be healed.
- Therefore, Exrah Troopers cannot use Explode (their rule supersedes Explode by denying the Unconscious step).

**States that cause direct Dead**
- Anything that skips or prevents Unconscious stops Explode:
  - Shock
  - Dogged/NWI refusal to enter Unconscious
  - Multiple Wounds dealt in the same Order
  - Any Special Rule that directly forces Dead

### TACTICAL NOTES

**When Explode is strong**
- Against densely positioned enemy Light Infantry or Skirmishers.
- When entering Unconscious in the enemy Active Turn: the explosion happens automatically with no Order investment from you.
- When used to threaten melee-heavy opponents: charging you risks detonation.

**When Explode is weak**
- Enemies declaring Dodge can avoid the blast.
- ARM rolls against PS7 Shock are often survivable for medium or heavy troops.
- Templates canceled by proximity to your own troops reduce offensive potential.

**Positioning Concerns**
- Because Explode activates at the end of the Order, enemies might reposition or Dodge before the effect resolves.
- Try to deny opponents easy Dodge AROs (e.g., forcing long-range gunfights).


### COMMON MISUNDERSTANDINGS (UNOFFICIAL CLARIFICATIONS)

**“Can you choose not to Explode?”**  
No. It is automatic unless the Trooper avoids Unconscious (Dogged/NWI activation) or is killed outright.

**“Does Explode happen in the middle of the Order?”**  
No. It happens at the **end of the Order** in which the Trooper entered Unconscious.

**“Does the explosion happen even if all allies are in the template?”**  
The Attack is canceled but the Trooper still dies. Cancellation only stops template effects, not the death.

### SUMMARY
Explode is a highly situational but potentially punishing area effect triggered by entering Unconscious.  
Its main tactical value lies in denying safe melee, deterring close-range engagements, and punishing poor positioning.  
Understanding how the condition "entering Unconscious" interacts with Shock, Dogged, and NWI is essential for proper rules resolution.
