# Wounds and Healing/Repair

Combat Module

As a rule, the target of an Attack receives one Wound for each successful hit. This is represented by a Wound Token (WOUND) next to the target, with a numerical value to indicate how many Wounds the Trooper has received. If the target has received as many Wounds as the value of its VITA / STR Attribute, place an Unconscious State Token (UNCONSCIOUS) as well.

Certain types of Ammunition, Attacks, Equipment, Hacking Programs, etc. force the target to make more than one Saving Roll for each success in the Attack Roll (For example, DA ammunition forces the target to perform 2 Saving Rolls for each successful Attack). Others inflict more than one Wound with each failed Saving Roll or cause a change in the state of the target.

In these cases, the special effects are explained in the rule or the Weapon Chart.

## Unconsciousness and Death

If a target receives as many Wounds as the value of its VITA / STR Attribute, it enters Unconscious State.

On the other hand, if the target receives more Wounds than the value of its VITA/STR Attribute, it enters Dead State.

### Wounds and Healing/Repair - Doctor

- The target must have the Vitality Attribute and be in Unconscious State.

- By passing a Normal WIP Roll, the target's Unconscious State is cancelled, by removing 1 single Wound from those it has received, unless a rule or Skill specified otherwise. If the WIP Roll fails, the target automatically enters the Dead State and is removed from the game table.

### Wounds and Healing/Repair - Engineer

- Engineer allows, by passing a Normal WIP Roll, removing a Wound from a target with the Structure Attribute (STR). This cancels Unconscious State if applicable.

### Wounds and Healing/Repair - Regeneration

- During the States Phase, the user makes a Normal PH Roll: If the Roll is a success, the Trooper removes 1 Wound, cancelling the Unconscious State if applicable. If the Roll fails, the Trooper receives 1 additional Wound.

- If the Roll is a success, the Trooper removes 1 Wound, cancelling the Unconscious State if applicable.

- If the Roll fails, the Trooper receives 1 additional Wound.

### Wounds and Healing/Repair - Protheion

- The target must have the VITA Attribute.

- For each Wound they inflict on the target of the CC Attack, or Coup de Grâce they perform, the user removes 1 Wound they have received. If the user hasn't received any Wounds, they increase their VITA Attribute value by 1.

### Wounds and Healing/Repair - GizmoKit

- The target of a GizmoKit must be an Allied Model with the STR Attribute.

- In both cases, by passing the PH Roll, the target removes a Wound. This cancels Unconscious State if applicable. If the PH Roll is failed, the target receives a Wound instead of removing it, entering Unconscious or Dead State if applicable.

### Wounds and Healing/Repair - MediKit

- A MediKit's target must be an Allied Model with the VITA Attribute and in Unconscious State, unless certain scenario rules say otherwise.


- In both cases, by passing the PH Roll, the target may remove one Wound and cancel their Unconscious State. If the PH Roll is failed, the target automatically enters Dead State and is removed from the game table.

### Wounds and Healing/Repair - Order Expenditure Sequence

If a Trooper receives and removes Wounds or States in the same Order, the positive effect is always applied first, followed by the negative effect.

**[UNOFFICIAL COMMENT]**
Entering the Unconscious State is not the same as being removed from play. An Unconscious Trooper still occupies space, blocks movement, denies enemy movement through that space, and can still influence the game indirectly. This often makes leaving an enemy Unconscious Trooper alive a deliberate tactical choice, especially if removing them would require additional Orders or expose a valuable attacker.

**[UNOFFICIAL COMMENT]**
Healing (Doctor) and Repair (Engineer) are Order-intensive actions whose real value depends on *tempo*.

Doctor and Engineer are not symmetric roles. Engineers are often more reliable in practice because REMs and TAGs frequently have higher Structure and Remote Presence (two unconscious states) and can be healed when not unconscious for multi-STR troopers. Engineers also interact with Equipment, Peripherals, and States unrelated to damage. 
Doctors, by contrast, are high-risk, high-reward specialists whose value spikes dramatically when supporting elite infantry.

**[UNOFFICIAL COMMENT]**
MediKits and GizmoKits introduce a unique interaction: they allow healing attempts at range, but at the cost of accuracy and often with harsher consequences for failure. These tools are best viewed as *opportunistic recovery options*, not primary healing plans. They shine when the alternative is abandoning a valuable model entirely.

One easily missed interaction is that healing and repair can cancel Null States during the same Order they are applied. Because positive effects are applied before negative ones during Resolution, a Trooper can be revived and still suffer other effects from that Order. This makes it possible for a model to stand up healed, only to immediately re-enter a dangerous situation if positioning was poor.

Not that unless using Doctor (2W) or Engineer (2W), the maximum healing amount is 1 wound. This means multi-wound Troopers with VITA will never go above 1 wound (they are only healed when unconscious).

**[UNOFFICIAL COMMENT]**
Shock and similar effects dramatically alter the value of healing. Against Shock-heavy opponents, relying on Doctors becomes a strategic liability rather than a safety net. In these matchups, positioning to avoid going Unconscious at all is often more important than planning for recovery.

Multi-Wound and multi-Structure Troopers gain disproportionate value from healing because each successful heal effectively restores an entire Order-generating piece. Healing a cheap line infantry is rarely worth the risk unless it directly affects scenario objectives or Order count. Healing an elite attacker can swing the entire turn.

**[UNOFFICIAL COMMENT]**
Unconscious models still belong to their Combat Group. This means they continue to influence Order economy indirectly by *not* contributing Orders but still occupying slots that might otherwise be Command Token–shifted or reorganized. Deciding whether to heal can therefore be an Order economy decision, not just a survivability one.

Engineers repairing Immobilized or Isolated REMs and TAGs often provide more value than repairing lost Structure. Restoring functionality without restoring durability can still be decisive, especially when the repaired model can immediately act or contest objectives.

**[UNOFFICIAL COMMENT]**
A common mistake is attempting healing under enemy ARO coverage. Even if the roll succeeds, the healed Trooper may immediately face lethal fire. Smoke, White Noise, body-blocking, or coordinated positioning should be considered part of the healing action, not optional extras.

From a strategic perspective, healing tools act as *deterrence*. An opponent may overcommit to fully killing models they would otherwise leave Unconscious, spending extra Orders and exposing themselves to counterplay. This psychological pressure is often as valuable as the actual healing.

**[UNOFFICIAL COMMENT]**
In scenario play, healing is frequently less about saving points and more about re-enabling Specialists. A single successful heal that allows a Specialist to push a button, flip an objective, or deny scoring can outweigh several failed attempts earlier in the game.

Finally, remember that choosing *not* to heal is often correct. A Doctor or Engineer who risks themselves to save a model may end up trading down in value. Infinity rewards selective recovery, not blanket attempts to keep everything alive.
