# Coordinated Orders

> **N5 FAQ v0.1 clarification (September 2026):** **Special Dice (`+1 SD`, etc.) still apply during a Coordinated Order.** SD modifiers do not change the weapon/Skill's Burst value, so the Coordinated Order Burst reduction does not remove them.

Command Module

A Coordinated Order is an organized combat action or maneuver carried out by several Troopers at once.

## Requirements
- Spend 1 Command Token and 1 Regular Order from the participating Troopers' Combat Group.
- Up to 4 Troopers can participate.
- Name one participating Trooper as the Spearhead.
- All participants declare and execute the same sequence of Skills.
- If a Skill requires a Trooper, Marker, or mission objective as a target, all participants use the same single target.
- Participants must have the same Training and be in the same Combat Group.
- Coordinated Orders are declared during the Orders Phase of the Active Turn.

## Effects
- The Spearhead uses half the indicated Burst of its weapon, Equipment, or Special Skill, **including bonuses**, rounded up.
- All other participants have Burst reduced to 1.
- **FAQ v0.1:** Special Dice MODs such as `+1 SD` are not Burst modifiers and therefore still apply.
- Each Reactive Trooper chooses only one activated Trooper as the target of its ARO.
- A participant that cannot meet a declared Skill's Requirements performs Idle for that Skill while the others act normally.
- For a Coordinated CC Attack, only the Spearhead performs the CC Attack and gains the applicable +1 B for allied Troopers in Silhouette contact with the target.
- Remove the Spearhead Token when the Coordinated Order ends.

Peripherals and their Controllers cannot participate in Coordinated Orders. Fireteam members also cannot participate while they remain members of that Fireteam.

## Coordinating Skills

Participants use the same Skill sequence, but may use different weapons/effects when those are all executions of the same Skill. For example, several participants can all declare BS Attack while using different legal BS weapons. Skills such as Speculative Attack or Intuitive Attack are distinct Skills and cannot be substituted for BS Attack within that coordinated declaration.

## Dodge and Reset

If the target declares Dodge or Reset as its ARO, resolve Face to Face interactions against the applicable attacking Rolls.

## States

If a Coordinated Order is used to activate a Game State, each participant must activate the same State.

## Hacking Programs

When coordinating Hacking Programs, each participant must use the same Hacking Program and the same single target where a target is required.

## Success + Failure

For coordinated use of Skills/Equipment such as Doctor, MediKit, or Engineer on a common target, apply the Coordinated Order rule for successful Rolls.

## Targetless / Deployable

Weapons or Equipment with Targetless or Deployable Traits do not have to target the same point on the table.

## Hidden Deployment / Airborne Deployment

Eligible Troopers in Hidden Deployment or off-table with Airborne Deployment-labelled Skills can be selected as described by the Coordinated Order rules, losing their own Order for that Turn where specified.

## FAQs

Q: If multiple Troopers use Surprise Attack against the same target through a Coordinated Order, do the Surprise Attack MODs stack?

A: No. Apply each Trooper's Surprise Attack MOD separately.

Q: If several Troopers activate at once and generate AROs, can AROs target Active Troopers using Stealth?

A: Yes, but the ARO becomes Idle if the Stealth user does not declare a Skill that allows that ARO to resolve.

### N5 FAQ v0.1

Q: How do Special Dice (`+1 SD`, etc.) MODs work during Coordinated Orders?

A: They still apply because SD modifiers do not change Burst values.

**[UNOFFICIAL COMMENT]**
Do not treat the Spearhead as Burst 1 by default. The Spearhead halves its listed Burst **including bonuses**, rounded up; the other participants are the ones reduced to B1. Special Dice are separate from Burst and survive the coordinated Burst reduction under FAQ v0.1.
