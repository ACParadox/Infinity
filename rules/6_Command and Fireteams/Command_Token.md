# Command Tokens

Command Module

Command Tokens represent the command and control resources at your disposal to support your combat force.

Each player has four (4) Command Tokens per game.

Lieutenant

- In the Unit Profile, this Special Skill may have additional abilities listed. Some examples are: +1 Command Token. The player that takes this Trooper as their Lieutenant will have one extra Command Token for the match.

- +1 Command Token. The player that takes this Trooper as their Lieutenant will have one extra Command Token for the match.

Command Tokens have three different gaming use modes:

- Strategic Use.

- Executive Use.

- Operational Use.

## Command Tokens: Strategic Use

The Strategic Use of Command Tokens has a special and unique nature, reflecting defensive intel actions deployed by Mission Control. Those actions are divided into Procedural and Logistical:

- Procedural: The player who has the first Player Turn may spend 1 single Command Token during their Deployment in order to set aside one extra Trooper and their Peripherals, which they will be able to deploy after their opponent, in step 3 of the Deployment Phase.

- Procedural: The player who has the second Player Turn may make Strategic Use of their Command Tokens during the Tactical Phase of their opponent's first Turn to perform one of the following actions: 
    - Remove two Regular Orders for this Turn from their opponent's Order Pool. The player may choose which Combat Groups these Orders correspond to. This option may only be performed during the opponent's Tactical Phase, right after the Order Count, but only if the number of Orders ( Regular + Irregular + Tactical ) is higher than ten. The Orders of Troopers in Hidden Deployment State, or off table via Airborne Deployment Skills, are not counted for this limit. 

    - Prevent the adversary from using more than one single Command Token during that first Turn. 
    
    - One Trooper from that player's Army List can activate the Suppressive Fire State (along with their Peripherals, if they are a Controller), following the Activation rules of the Skill.

- Logistical: After both players have completed their Deployment, and following the established Initiative order, each player may spend 1 Command Token to gain 2 Speedball Tokens (see Request Speedball ).

- Remove two Regular Orders for this Turn from their opponent's Order Pool. The player may choose which Combat Groups these Orders correspond to. This option may only be performed during the opponent's Tactical Phase, right after the Order Count, but only if the number of Orders ( Regular + Irregular + Tactical ) is higher than ten. The Orders of Troopers in Hidden Deployment State, or off table via Airborne Deployment Skills, are not counted for this limit.

- Prevent the adversary from using more than one single Command Token during that first Turn.

- One Trooper from that player's Army List can activate the Suppressive Fire State (along with their Peripherals, if they are a Controller), following the Activation rules of the Skill.

Each player may spend a maximum of two Command Tokens for Strategic Use, one on a Procedural option and one on a Logistical option.

## Command Tokens: Executive Use

Executive Use of Command Tokens is made during the player's Executive Use of Command Tokens step of their Tactical Phase, which represents executive actions performed by Mission Control.

For each Command Token expended, the player may do one of the following:

- Permanently move an Allied Trooper and all their Peripherals to a different Combat Group, keeping in mind the 10-member limit.

- Cancel the Possessed State of an Allied Trooper.

When a player moves a G: Jumper Trooper into a different Combat Group, he will move all the Proxies, as they are considered to be a single Trooper in each Combat Group.

## Command Tokens: Operational Use

Players may make Operational Use of their Command Tokens in their Active Turn. This represents the tactical use of intel resources by Mission Control. For each Command Token expended, the player may perform one of the following actions:

- Declare a Coordinated Order, spending a Regular Order from the Order Pool of the participating Troopers' Combat Group.

- Have an Allied Trooper automatically pass or fail a Guts Roll, as desired, ignoring the result on the die and any Special Skills the Trooper might have.

- Transforms the Irregular Order provided by an Irregular Trooper into a single Regular Order, substituting the corresponding Order Token for that Player Turn and adding it to the Order Pool of the Trooper's Combat Group.

- Have one Trooper be unaffected by Retreat! This Trooper ignores the effects of the Retreat! situation until the end of the game.

- Reroll a failed WIP Roll when trying to use the Special Skill Doctor on a Trooper with a Cube. This reroll does not provide a new ARO to the enemy.

- Reroll a failed WIP Roll when trying to use the Special Skill Engineer on a Trooper with the Remote Presence Special Skill. This reroll does not provide a new ARO to the enemy.

- Create a new Fireteam by placing a Fireteam Leader Token (FIRETEAM LEADER) next to a Trooper that meets the army's Fireteam Chart Requirements.

Players may expend as many Command Tokens during a single Active Turn as they desire, assuming they have enough. Players may also use more than one Command Token for the same effect.

Players cannot expend Command Tokens during their Reactive Turn.

Isolated State

- Restriction: The Irregular Order of an Isolated Trooper cannot be transformed in a Regular Order.

Counterintelligence

- This Special Skill counteract the effects of the Strategic Use of a Command Token by reducing to one the number of Orders the adversary can nullify.

- Alternatively, this Special Skill counteracts the limit on Command Token use imposed by the adversary due to the Strategic Use of a Command Token, increasing it to two.

## Command Tokens: Example

During her Active Turn, a Doctor tries to use her Special Skill Doctor to heal an Allied Trooper, who is currently Unconscious. She expends one Short Skill of her Order, but fails her WIP Roll. However, her player uses a Command Token to reroll the WIP Roll. Without expending or declaring a new Order, the Doctor rolls her WIP again. Sadly, luck is not on her side, and she fails again. Still her player wants to spend a new Command Token and give the Doctor one further opportunity to pass her WIP Roll and heal the Allied Trooper. This will be her last chance, but only because her player has no more Command Tokens left to spend.

A practical way to think about Command Tokens is:
- One-time strategic disruption (mostly Turn 1)
- Ongoing efficiency smoothing (orders, rerolls, restructuring)
- Emergency recovery tools (Doctor, Engineer, Possessed)

**[UNOFFICIAL COMMENT]**
The Speedball items available are the following:

- VitaPack: Allows cancellation of the Unconscious State of another Allied Trooper with the Vitality Attribute, by removing one single Wound from those they have received.
VitaPack is applied by spending a Short Skill of an Order while in Silhouette contact with the Unconscious Allied Trooper.

- AutoRepairS(uite): Allows cancellation of the Unconscious State of another Allied Trooper with the STR Attribute, by removing one or two (if applicable) Wounds from those they have received.
AutoRepairS(uite) is applied by spending a Short Skill of an Order while in Silhouette contact with the Unconscious Allied Trooper.

- Switch On: Allows cancellation of the Immobilized A and B, Isolated, and Stunned States of another Allied Trooper.
Switch On is applied by spending a Short Skill of an Order while in Silhouette contact with the Allied Trooper.

- Jetpack: The bearer can use the Super-Jump (Jet Propulsion) Special Skill during one Order only. This use of the item is restricted to Troopers with Silhouette 2.

- Overkill: The bearer of this Speedball item may choose between two use modes. The first mode allows its user to cancel their Unloaded State and regain all expended uses of their Disposable weapons or pieces of Equipment, in the Conclusion Step 5.2 of the Order. Alternatively, the second mode grants the user the BS Attack (SR-1) Skill during one Order only.

- NanoShield: If a Trooper has to make any Saving Rolls, they must automatically apply a +2 MOD to all their Saving Rolls in the Resolution Step 5 of that Order.


**[UNOFFICIAL COMMENT]**
Extra Reserve Trooper is often undervalued compared to Order removal, keeping an extra model in reserve allows you to:
- Counter-deploy obvious attack pieces (TAGs, MSV snipers, strong ARO anchors)
- Hide key information such as Fireteam composition or Lieutenant candidates

This is especially strong if your list includes:
- Strong ARO units
- Minelayer and infiltrating Troopers where positioning is key
- Hidden Deployment or Marker-heavy armies
- Sectorials where Fireteam composition matters at deployment

The biggest trap is using this automatically without a clear counter-deployment goal.

**[UNOFFICIAL COMMENT]**
Reduce Opponent’s Order Pool (remove 2 Regular Orders) is the most universally powerful Turn 1 Command Token use. It directly converts into:
- Fewer attack attempts
- Less board repositioning
- Reduced redundancy for failed Face to Face rolls

This is especially punishing against:
- Alpha-strike lists
- Lists with one main attack piece
- Armies relying on Coordinated Orders Turn 1

This is a GO TO use, as the orders are a very finite and key resource in the game.

Note that this is reduced by 1 order if an opponent's Trooper has Counterintelligence. But even reduced to 1 order this is often useful anyways.


**[UNOFFICIAL COMMENT]**
Command Token Restriction (opponent may only use 1 Command Token in Turn 1) is subtle but brutal when combined with Order removal. Together, they:
- Prevent Coordinated Orders for board clearing
- Prevent Fireteam reform after early losses
- Prevent converting Irregular Orders during recovery

This use shines against Sectorials and Fireteam-centric lists. Against vanilla lists, its value is often lower unless the opponent relies heavily on Coordinated Orders.

This is very situational as the opponent is likely to just no use the tokens and use them next turn.

Note that this the limit increased to 2 Command Token Use limit if a Trooper has Counterintelligence.

**[UNOFFICIAL COMMENT]**
Suppressive Fire via Command Token before the opponent’s Turn 1 is often overlooked. It is strongest when used on:
- Durable midfield units
- Units covering narrow firelanes
- Models with strong defensive MOD stacking

Very very situational, but could potentially be used to counter an alpha strike or assassination attempt using suppressive fire.


**[UNOFFICIAL COMMENT]**
Speedball usage is highly scenario- and faction-dependent and often misplayed due to timing confusion. Key points players miss:
- The Command Token is spent after deployment to acquire Speedballs
- Speedballs must be physically picked up and then used
- Some effects are automatic buffs, others require a Short Skill

Strategically, Speedballs are strongest when:
- Supporting a central attack piece
- Enabling a risky alpha strike
- Recovering from States without spending multiple Orders

Jetpack and Overkill are often underestimated compared to NanoShield, but mobility and disposable recovery can swing entire turns.

The speedballs have a couple of flaws:
- Randomness elements: PH roll to place and the 2nd speedball
- This can be mitigated by having a speedbal by usable in the DZ edge.
- Need to be picked up by a Trooper
- If Trooper dies and nobody picks it up, it's useless.
- For conditionally useful Speedball, you need to not forget to use it.
- Many Speedball options require a Short skill to use.

It COULD MAYBE be useful if their use is planned in advance:
- VitaPack/AutoRepairs/SwitchOn given to a Trooper supporting a TAG/key piece that has no Doctor/Eng support.
- Jetpack given to a key piece with positionning destination in mind.
- Overkill to a key piece to give it more use of expendables (Discoball, Pitcher), when Baggage not available.


**[UNOFFICIAL COMMENT]**
Combat Group Reorganization is a good long-term Command Token uses. It is effectively:
- Order efficiency insurance
- A way to recover from casualties
- A method to consolidate attack resources mid-game

Best practices include:
- Moving surviving attack pieces into a healthy Order pool
- Draining empty or crippled Combat Groups
- Keeping support pieces grouped late game
- Optimizing the main battle group by moving Troopers from secondary group

Both this an converting Irregular Orders to Regular Orders help optimize orders. Which one to use depends on:
1) If some irregular orders aren't useful: convert
2) If secondary group as extra orders that aren't super useful (and there's a space empty in main group), transfer.


**[UNOFFICIAL COMMENT]**
Cancel Possessed State is a niche but game-saving use. Its real value is psychological:
- It discourages over-commitment to hacking strategies
- It protects expensive TAGs from catastrophic loss

Only useful if you have a TAG, and it's been possessed, but still a key use to keep a token or two reserved if this is likely to happen.


**[UNOFFICIAL COMMENT]**
Coordinated Orders are deceptively expensive. One Command Token for four activations worth it if:
- All participants meaningfully contribute
- The Order replaces multiple single Orders
- The action bypasses ARO pressure (e.g. coordinated movement)

They are strongest early game for repositioning and late game for objective grabs, but weak for inefficient attacks.

Examples of usage is 4 moving non-Fireteam Troopers.
Last order of turn to activate 4 suppressive fire states.


**[UNOFFICIAL COMMENT]**
Auto pass or fail Guts Rolls is often ignored, but it enables:
- Staying in Suppressive Fire when survival matters
- Failing Guts intentionally to retreat into safety
- Maintaining board control without extra Orders

This is a finesse tool, not a power play, but experienced players extract consistent value from it.


**[UNOFFICIAL COMMENT]**
Convert Irregular Order to Regular is always useful but rarely urgent. It is best when:
- You need one extra push Order for a decisive play
- Loss of Lieutenant has disrupted your plan
- You have a irregular trooper with nothing much to do (ex. a Warcor)

Avoid converting Orders on troopers that will only Idle.
This could be an easy, simple use of 3 Command Tokens if you have a defensive irregular piece.
This can also be a good final turn use of tokens if some tokens were conditional kept for other uses (ex. reroll Doctor/Eng).

You might even keep a Warcor or cheap defensive irregular in your army just to easily use this command token use.


**[UNOFFICIAL COMMENT]**
Doctor and Engineer rerolls are a key conditional use of Command token:
- If you've taken the time to move a Doctor/Eng to a downed Trooper, reroll a failed roll means:
    - You've "gained" an order by not wasting this order not-healing
    - You've gained a second order (or more) by having another unit back
    - You've gained the use of a unit again.


**[UNOFFICIAL COMMENT]**
Reform Fireteam is situational. It is best used:
- After unavoidable ARO casualties
- Before committing a Fireteam attack

It's only useful if the loss happens early: the Fireteam can save many orders in the long run.


**[UNOFFICIAL COMMENT]**
A good approach is to compare Command Token uses by Order:
- How many orders does this give or does it remove for the opponent.

Since you can often use "Convert Irregular Order to Regular" this is often a good heuristic.
