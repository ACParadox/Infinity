# Order Expenditure Sequence

> **N5 FAQ v0.1 clarification (September 2026):** All details of a Skill must be specified when it is declared **except the target's position**, which is chosen during Resolution before measuring Range. If declaration order among simultaneously activated Troopers matters, the **Active Player chooses who declares first**.

Each time the Active Player spends an Order to activate a Trooper, follow the Order Expenditure Sequence:

1. **Activation** — declare the activated Trooper, expend the Order, and declare the first Basic Short Skill or Long Skill. Resolve movement declaration/measurement as required by the movement rules.
2. **Reactive Player's AROs** — check and declare eligible AROs.
3. **Declaration of the Second Skill** — declare the second Short Skill if applicable.
4. **Reactive Player's AROs** — check and declare AROs for Troopers that could not declare one in the first ARO window.
5. **Resolution** — check Requirements, measure ranges, determine MODs, make Rolls, apply Effects, then Conclusion effects such as Guts Rolls and Alert.

## Declaration details

All details and choices related to executing a Basic Short Skill, Short Skill, or Long Skill must be specified when it is declared.

- For movement, specify the complete route.
- For an Attack, specify the weapon/equipment/Special Skill/Ammunition or other option, target(s), firing point, Burst division, and other required choices.
- **FAQ v0.1 exception:** the **target's position** is selected during Resolution, before measuring Range.
- **FAQ v0.1 simultaneous declarations:** where several active game elements declare together and the order of those declarations matters, the Active Player chooses the declaration order.

When declaring Alert!, any Basic Short Skill, or the Long Skills Jump or Climb, check their Requirements when declared. For other Skills declared as part of an Order or ARO, check Requirements in Resolution unless their own rule says otherwise.

If a declared Skill, weapon, or piece of Equipment fails its Requirements when checked, it becomes Idle; declared uses of Disposable items are still expended.

The type, status, and expenditure of Orders is Open Information and must be tracked visibly.

If a Trooper receives and removes Wounds or States during the same Order, apply the positive effect first and the negative effect afterward, as specified by the current rules.

## FAQ v0.1

Q: Do you need to specify all details of a Skill when declaring it—for example the target or White Noise template placement?

A: Yes, except for the **target's position**, which is chosen in the Resolution step before measuring Ranges. If declaration order is important, the Active Player chooses who declares first.

**[UNOFFICIAL COMMENT]**
The FAQ does not create permission to defer ordinary Skill choices. Its narrow exception is the target's position used at Resolution; weapon/mode, target identity, Burst allocation, template placement where applicable, and other declaration choices are still declared at the appropriate declaration step.
