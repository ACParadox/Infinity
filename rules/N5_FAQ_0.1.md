# Infinity N5 FAQ v0.1 — September 2026

**Release:** September 2026  
**Status:** Authoritative local FAQ layer for N5.3. Entries are deduplicated from the official wiki, which cross-lists a ruling on every related rule page.

## Skill declaration details and simultaneous activations

> **N5 FAQ v0.1 clarification** — When declaring a Skill, declare the required details at declaration time. The target's exact position is the exception and is selected during Resolution before measuring Range. When several Troopers are activated simultaneously and the order in which their declarations matters, the Active Player chooses the declaration order.

## Fired Deployables and vertical surfaces

> **N5 FAQ v0.1 clarification** — A Deployable fired/placed through the applicable BS Attack mechanic cannot have its Token placed on a vertical surface. The Token must be fully supported. This applies to affected Deployable weapons/equipment such as Pitchers, Drop Bears, Disco Ballers, and Mine Dispensers.

## Camouflaged Marker with the actual element in Total Cover

> **N5 FAQ v0.1 clarification** — If an Attack hits a Camouflaged Marker but the actual game element represented by that Marker is in Total Cover from the Attack, an Attack that would force a Saving Roll reveals the Marker, but the underlying game element is not hit because it has Total Cover.

## Special Dice in Coordinated Orders

> **N5 FAQ v0.1 clarification** — Special Dice modifiers such as `+1 SD` still apply in a Coordinated Order because SD modifiers do not change the weapon's Burst value.

## Peripheral declaration when the Controller cannot execute the Skill

> **N5 FAQ v0.1 clarification** — In the Active Turn, a Controller and its Peripherals declare the same Skill. If the Controller or a Peripheral cannot perform that Skill because of Stunned, Immobilized, Engaged, or another restriction, that individual game element performs Idle instead; this does not prevent the others from executing the declared Skill if they can.

## Fireteam creation minimums after formation

> **N5 FAQ v0.1 clarification** — Losing a Trooper that was required to create a Fireteam does **not** by itself cancel the Fireteam. The `Min` requirement in Fireteam Charts is checked when creating the Fireteam. FT Master can impose an additional rule that overrides this general answer.

## Fireteam type does not change when members are lost

> **N5 FAQ v0.1 clarification** — A Fireteam retains its original Type after losing members. For example, a Haris reduced to two members remains a Haris rather than becoming a Duo.

## Firewall granted by a Hacking Device

> **N5 FAQ v0.1 clarification** — If a Trooper's Hacking Device provides Firewall, the Firewall MODs apply against any Comms Attack targeting that Trooper while the Hacking Device is active. They stop applying when the Hacking Device is disabled, for example because the Trooper is Isolated or in a Null State.

## Undeployed Peripheral (Ancillary) and Killed scoring

> **N5 FAQ v0.1 clarification** — A Peripheral (Ancillary) that was never deployed does **not** count as Killed for scenario objectives. It only counts as Killed if it was deployed and then entered Dead State, or was in a Null State at the end of the game.
