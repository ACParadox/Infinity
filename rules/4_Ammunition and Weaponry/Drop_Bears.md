# Drop Bears

"Drop Bear" is the colloquial name used in the military for a thrown version of the Mine. The operator of this weapon can throw it, even over an obstacle, or alternatively can deploy it within arm's reach like an old-fashioned mine.

This weapon has two modes of use, Deployable Mode and BS Mode:

- Drop Bear (Deployable Mode): In this Mode, Drop Bears work just like a Mine, so are placed with the Place Deployable or Intuitive Attack Common Skills, except that a Mine Token [Mine (-3)] is placed instead of a Camouflage Marker.

- Drop Bear (BS Mode): You do not need a target to throw a Drop Bear as a BS Weapon, simply choose the desired location and make the corresponding Roll. If you pass the Roll, the Drop Bear is successfully deployed and becomes a Mine, placing a Mine Token [MINE (-3)] in the Conclusion step of the Order. A Drop Bear cannot detonate during the Order it is used in BS Mode. In BS Weapon Mode, Drop Bears cannot be placed where there is an enemy Camouflage Marker inside its Trigger Area. This restriction does not apply if there is a valid, non-camouflaged enemy inside the Trigger Area

- The Disposable (3) Trait is shared between all Modes. The bearer of this weapon has only three uses available, no matter which Modes are used.

Once deployed, Drop Bears work just like Mines.

## Drop Bears FAQs

Q: When using Place Deployable and declaring where the Deployable will be placed, what happens if a Trooper moves into that space before the Conclusion of the Order?

A: The Trooper that declared Place Deployable may place the Deployable in a different position (still following the Place Deployable rule), and if this is not possible, the Deployable will be lost.

This also applies to weapons that place a Deployable Weapon or Equipment on a successful Roll, such as Disco Ballers, Pitchers, and Drop Bears (BS Mode).

### Drop Bears - Interaction Note
Related rules: ARO, Face-to-Face, Partial Cover.

**Drop Bears — Rules Recap (Official Text Excerpts)**  
From the N5 rules:  
- A Drop Bear is a thrown version of a Mine. It can be used in **Deployable Mode** or **BS Mode**.  
- **Deployable Mode**: Works like placing a Mine using *Place Deployable* touching the trooper silhouette.. A **Mine (-3)** Token is placed.   

- **BS Mode**: Targetless throw. Choose a location, make a Roll. On success, in the *Conclusion* step, place a **Mine (-3)** Token. It **cannot detonate during the same Order**. It **cannot be placed if an enemy Camouflage Marker is inside its Trigger Area**, unless a non-Camouflaged enemy is also inside.   

- **Disposable (3)** applies to both modes.   
- Once deployed, Drop Bears function as standard Mines.   

**[UNOFFICIAL COMMENT]**

**Drop Bears - Interaction with ARO**  
- Throwing a Drop Bear in **BS Mode** is a BS Attack (Targetless, Speculative Attack allowed) and therefore generates AROs normally if the acting Trooper is seen.  

- AROs will usually be **BS Attacks** or **Dodges**.  

- Since Drop Bears in BS Mode cannot detonate during the same Order, the defender cannot be harmed by the mine within that Order. 

- ARO Dodge does **not** oppose the placement unless the Dodge specifically affects LoF or movement—this is a *Normal Roll* for the Drop Bear user, unless an enemy BS Attack or other opposing skill makes it **Face-to-Face** (see below).

**Drop Bears - Interaction with Face-to-Face**  
- Drop Bear *BS Mode* placement becomes **Face-to-Face** only if the ARO is a skill that *affects the outcome of the attack*, such as a BS Attack.  

- If the ARO is a Dodge, it usually **does not oppose** the placement and the Roll is Normal.  

- Because Drop Bears are **Targetless**, LoF is not needed to the final placement point, allowing the user to fight Face-to-Face with a defending shooter and still drop a mine near them if they succeed.

### Drop Bears - Practical Interaction Notes (Unofficial Analysis)

**Comparison: Drop Bears vs. Regular Mines**  
**Similarities:**  
- After placement, both function as Mines with identical trigger rules and Shock templates.  
**Differences:**  
- **Drop Bears** may be only thrown at range (8–16” band with +3).  
- **Regular Mines** can only be placed with Place Deployable (silhouette contact).  

### Comparison: Drop Bears vs. Mine Dispenser  
**Mine Dispenser** uses BS Mode *identical to Drop Bears* but fires **actual Mines** with AP/EM/Shock variants depending on the profile.  
- **Pros (Mine Dispenser):** Longer maximum range; more lethal ammo types; better for indirect pressure.  
- **Pros (Drop Bears):** Cheaper cost, easier to equip on many units, and usually more flexible in tight environments.

### Drop Bears - Tactical Usage Notes  
- Excellent for **locking down corners** before an assault.  
- Strong when combined with **Direct Template weapons**, forcing awful positioning choices.  
- Effective for punishing opponents trying to trade AROs—win or lose, the mine still gets placed if the throw succeeds.
