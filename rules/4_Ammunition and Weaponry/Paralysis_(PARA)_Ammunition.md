# Paralysis (PARA) Ammunition

This ammunition has been specially designed not to cause any real harm, but it is powerful enough to immobilize any adversary.

- After a successful attack using Paralysis (PARA) Ammunition, the target must make a Saving Roll ( PH -6) per hit suffered.

- If the target fails the PH-6 Roll, it enters Immobilized-A State. Place an Immobilized-A Marker (IMM A) next to it.

- Critical hits with Paralysis (PARA) Ammunition cause the target to make an additional PH-6 Roll.

- This Ammunition has no effect on targets that have no PH Attribute. In that case, the target will not roll and will ignore the effects of this Ammunition.

## PARA Example

In the case of the Heavy Riotstopper, a Direct Template weapon that uses PARA ammunition, if it hits a target with a PH Attribute of 12, this Trooper will have to make a PH-6 Roll (12 – 6 = 6). Therefore, any result equal to or lower than 6 will mean that the target avoids entering Immobilized-A State. Otherwise, an Immobilized-A State Token will have to be placed in contact with the target’s base.

### Interaction Note
Related rules: ARO, Face-to-Face, Partial Cover.

**[UNOFFICIAL COMMENT]**
**Paralysis (PARA) Ammunition — Interactions and Unofficial Commentary**

PARA Ammunition is a *non-lethal, PH-based disabling effect* that imposes a **PH-6 Saving Roll** and inflicts **Immobilized-A State** on failure.

**Immobilized-A State**
- Troopers in Immobilized-A State cannot declare any Skill or ARO, except Dodge, applying a -6 PH MOD.

- Automatic Special Skills and Equipment continue to work, but the Trooper must still respect all declaration restrictions.

- Troopers in the Immobilized-A state State continue to provide Orders for their Order Pool.

- The affected Trooper may cancel this state via a successful Normal or Face to Face Dodge Roll, applying the -6 PH MOD provided by this state.

- A Trooper with the Engineer Special Skill (or an equivalent Skill) may cancel the Immobilized-A state by spending one Short Skill of an Order while in Silhouette contact with the affected Trooper, and passing a Normal WIP Roll (or the Roll specified by the Special Skill or Scenario).


#### How PARA interacts with core rules:

- **Face-to-Face Rolls**  
  PARA attacks are resolved like any other BS or CC Attack: if they oppose another declaration (Dodge, BS Attack, etc.) they become a Face-to-Face Roll. PARA CC Weapons may impose additional MODs (e.g., PARA CC Weapon -3 imposes a -3 to the target’s Face-to-Face Rolls).  
  PARA’s effect only triggers if the attack hits and the PH-6 Save is failed.

- **ARO**  
  As a non-lethal disabling tool, PARA is strong in ARO because a *single failed PH-6 immediately removes most ARO options from the target* on subsequent Orders.  
  An Immobilized-A Trooper may only declare **Dodge (-6)** as their ARO.

- **Partial Cover**  
  PARA Rolls use **PH-6**, not ARM/BTS. Partial Cover provides **+3 ARM/BTS only**, so it **does not protect against PARA**.  
  PARA also does not require LoF modifiers other than the usual attack modifiers; only the attack roll, not the Save, is affected.

### Paralysis (PARA) Ammunition — Comparisons, Pros & Cons

**PARA vs Stun Ammunition**  
- Both are **non-lethal** and impose a debuffing State (PARA → IMM-A; Stun → Stunned).  
- PARA is **harder to resist** (PH-6) but can be escaped by Dodge; Stun requires time or Engineer to clear.  
- PARA removes most actions by forcing IMM-A; Stun prevents Attacks but still allows movement and Dodges without -6.

**PARA vs E/M**  
- PARA uses **PH-6**; E/M uses **BTS/2**.  
- PARA always causes **IMM-A**; E/M often causes **IMM-B + Isolated** for HI/REM/TAG/VH—much harsher.  
- PARA affects anything with PH; E/M has target limitations.  

**PARA vs Normal ammo**  
- Normal inflicts Wounds (ARM/BTS based). PARA doesn’t harm or use ARM/BTS at all.  
- PARA is ideal vs resilient, single-Wound, or objectives-focused Troopers (Specialists, button-pushers).

### Paralysis (PARA) Ammunition — Tactical Uses (Unofficial)

**Strengths**
- *Order denial tool:* Immobilized-A blocks almost all activity—perfect for shutting down melee threats or objectives Troopers.  
- *Great in ARO:* One hit can lock down an attacker for the rest of the turn.  
- *Template PARA weapons* (e.g., Riotstoppers, MadTraps) are especially punishing due to bypassing Face-to-Face restrictions.
- Troopers can shoot Immobilized-A enemies without fear of retaliation from a BS Attack ARO.

**Weaknesses**
- PARA relies on **PH-6**, which is still a single roll—high-PH units can shrug it off.  
- IMM-A can be removed via Dodge (-6) or Engineer, so resilient enemies can sometimes break free quickly.  

**Situational Notes**
- PARA is excellent for crowd control in dense terrain or where templates catch multiple targets.  
- MadTraps using PARA automatically engage when triggered, providing reliable perimeter lockdown.

**[UNOFFICIAL COMMENT]**
### Paralysis (PARA) Ammunition — Pros & Cons Summary

**Pros:**
- Non-lethal but extremely disabling.  
- Short-circuits aggressive units by removing their action economy.  
- Great defensive and area-control value.  
- Ignores ARM/BTS stacking, cover bonuses, and many defensive immunities.

**Cons:**
- Has counters: Dodge (-6), Engineer.  
- High-PH units resist surprisingly well.  
- Does not remove Orders (unlike Isolated).  
- Ineffective vs targets *without* a PH Attribute.
