# N5.3 Modifier Clarifications

> **N5.3 change (September 2026):** This file records the N5.3 modifier clarifications called out in the official changelog. Use these interpretations if an older local module page omits them.

Official references:
- https://infinityuniverse.com/en/news/infinity-rules-update-5-3
- https://infinitythewiki.com/Modifiers

## Dodge (ARM+3)

> **N5.3 change / clarification:** `Dodge (ARM+3)` means that when the user declares Dodge, the user applies **+3 ARM if they fail the PH Roll**.

This is a conditional ARM modifier attached to the Dodge declaration; it is not a permanent +3 ARM bonus.

## PARA CCW (-6)

> **N5.3 change / clarification:** `PARA CCW (-6)` means that when the Trooper uses the PARA CCW, **opponents in any Face to Face Rolls suffer a -6 MOD**.

This follows the general modifier convention: negative MODs on non-Automatic Skills/Weapons/Equipment apply to the enemy during the relevant Face to Face Roll.

## Related N5.3 modifier rule

See `5b_Special Skills/Protheion.md` for the N5.3 Protheion clarification: a negative parenthetical Protheion MOD is applied to the **enemy's Attribute** in the Face to Face Roll.
