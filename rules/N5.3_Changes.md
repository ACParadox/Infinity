# Infinity N5.3 Rules Changes

**Release:** September 1, 2026  
**Status:** Authoritative local N5.3 override. If an older rule page conflicts with an entry below, this N5.3 wording wins.

Official sources:
- https://infinityuniverse.com/en/news/infinity-rules-update-5-3
- https://infinitythewiki.com/Category:N5.3_Update

## General / presentation

> **N5.3 change** — Blue text in the official rulebook identifies text modified or added by the update.

## New rule: Infinity Spec-Ops

> **N5.3 change** — Added the **Infinity Spec-Ops** Special Skill and **Request SpecBall** support mechanic. A Spec-Ops is customized when building the Army List, begins with its Initial Profile, and may obtain its Enhanced Profile and the selected SpecBall support items by recovering its SpecBall. Each player can use the Spec-Ops support mechanic once per game. See the dedicated `Infinity_Spec-Ops` rule page when present.

## Movement

> **N5.3 change** — **General Movement / Prone:** Berserk joins Jump as an exception to changing Prone state while using Movement-labelled Skills/AROs. The current wording applies to a Skill or ARO with the Movement Label, except Jump and Berserk.

> **N5.3 change** — **Climb / Partial Cover:** A Trooper performing the Climb Skill, or holding onto a vertical surface, cannot benefit from Partial Cover MODs.

> **N5.3 change** — **Super-Jump:** A parenthetical Super-Jump movement modifier such as `Super-Jump (+X")` applies when Jump is declared as a Short Skill, as specified by the current rule text.

> **N5.3 change** — **Aerial:** Troopers with Aerial do not activate Weapons with the Boost Trait.

## Combat / resolution

> **N5.3 change** — **Guts Rolls:** When resolving the requirement to improve protection from an attacker, use the positions from which the enemy actually performed the Attack, rather than unrelated positions occupied during the Order.

> **N5.3 change** — **Close Combat:** The multiple-combatants wording was corrected from “more than 2 Troopers” to **“2 or more Troopers”** in Silhouette contact for the applicable Close Combat support interaction.

> **N5.3 change** — **Modifiers:** Added/clarified how profile modifiers such as `Dodge (ARM+3)` and `PARA (-6)` are applied. A modifier shown in parentheses belongs to the named Skill/Equipment/weapon interaction described by that rule; it is not a generic Attribute modifier outside that context.

> **N5.3 change** — **Protheion:** A negative Protheion modifier such as `Protheion (-3)` applies to the enemy's Attribute in the Face-to-Face Roll.

## Hacking / equipment

> **N5.3 change** — **Firewall:** Firewall is **Automatic Equipment**. It applies its listed negative WIP MOD to an enemy declaring a Comms Attack against the protected Trooper and grants the protected Trooper +3 to Saving Rolls against Comms Attacks. Only one Firewall can benefit a Trooper at a time.

> **N5.3 change** — **Hacking Devices:** Hacking Devices are treated as **Automatic Equipment**.

> **N5.3 change** — **Baggage / Reload / Unloaded:** N5.3 wording explicitly allows the Baggage source to be an allied **Trooper or game element**. Reload and Unloaded-state cancellation use the same broader wording.

## Weapons

> **N5.3 change** — **Kobra Pistol:** BS Mode is **SHOCK**; CC Mode is **DA**.

> **N5.3 change** — **Trench-Hammer:** It is no longer `Disposable (3)` in either use option.

> **N5.3 change** — Added **Breaker Sniper Rifle**, **AP Red Fury**, and **AP Thunderbolt**.

> **N5.3 change** — Added the **Thunderbolt** weapon category.

## Common Skills / support

> **N5.3 change** — **Request Speedball:** Each Speedball uses the Combat Jump rules and makes its PH Roll using **PH 15**.

> **N5.3 change** — **Deployable Cover:** Deployable Cover is now **Disposable (2)** and has **Perimeter**.

## Special Skills

> **N5.3 change** — **Impetuous:** The restriction was rewritten. Impetuous Troopers cannot enter Marker States or another State whose own rule prohibits it. During an Impetuous activation, Move/Jump/Climb cancels Prone as specified and the Trooper cannot finish that movement by entering Prone.

> **N5.3 change** — **Minelayer:** A Minelayer cannot deploy its Deployable Weapon/Equipment with an enemy Trooper or Camouflage Marker inside that deployable's Trigger Area; for Perimeter Weapons/Equipment, the restriction uses the deployable's Zone of Control. This closes the Deployable Repeater/Minelayer exploit.

> **N5.3 change** — **Peripheral (Cyberplug):** Cyberplug wording was revised around Connected versus Autonomous operation. Apply the current Cyberplug subtype text; a Controller can have the allowed Cyberplugs but no more than the permitted number may be Connected at once.

> **N5.3 change** — **Strategos L2:** L2 was aligned with L1 so that it includes the L1 reserve/Lieutenant-order benefits in addition to the L2 Combat Group transfer effect.

## Fireteams / Peripherals

> **N5.3 change** — **Fireteam Integrity:** If the Fireteam Leader becomes the Controller of a Peripheral, the Fireteam is cancelled. If another Fireteam member becomes a Peripheral Controller, that Trooper leaves the Fireteam.

## Marker / state wording

> **N5.3 change** — **Camouflaged State:** The restricted ARO list now governs which AROs may be **declared** against the Camouflage Marker, rather than merely which AROs can eventually be executed.

> **N5.3 change** — **Immobilized-B:** Added a hacking example clarifying declaration/resolution while an IMM-B Trooper is targeted by a hacking attack.

> **N5.3 change** — **Labels / Null:** The Labels section now explicitly lists the Null States: **Dead, Disconnected, Possessed, Sepsitorized, and Unconscious**.

> **N5.3 change** — **Decoy / Holoecho marker classification:** The wiki tags these pages in the N5.3 update set but notes the Marker classification itself was actually changed in N5.2. Treat this as documentation catch-up rather than a new September 2026 gameplay change.

## Terrain

> **N5.3 change** — **Special Terrain:** Corrected the setup terminology from **Difficult Movement** to **Difficult Terrain** when assigning characteristics to Special Terrain areas.
