# Immobilized-B State

> **N5.3 change (September 2026):** Added the explicit **Hacking Program vs. IMM-B** example: an IMM-B Trooper can declare only Reset at WIP -3; against a hacking Attack such as Trinity this creates a Face to Face Roll, and winning the Reset both cancels the hits and cancels IMM-B.
>
> **N5 FAQ v0.1 clarification (September 2026):** A Peripheral may still execute a declared Skill when its Controller cannot because of IMM-B or another restriction; the Controller declares the same Skill but performs Idle instead.

Game States and Glossary

## Activation
- The Trooper or game element ("Trooper" from now on) suffers a successful Attack or Effect using Ammunition, a Hacking Program, game condition, or Scenario Special Rule capable of causing this State.

## Effects
- Troopers in Immobilized-B State cannot declare any Skill, Attack, or ARO except Reset, applying a -3 WIP MOD.
- Automatic Special Skills and Equipment continue to work, but the Trooper must still respect all declaration restrictions.
- Troopers in Immobilized-B State continue to provide Orders for their Order Pool.

## Cancellation
- The affected Trooper may cancel this State via a successful Normal or Face to Face Reset Roll, applying the -3 WIP MOD provided by this State.
- A Trooper with Engineer or an equivalent Skill may cancel IMM-B by spending the required Short Skill in Silhouette contact and passing the applicable Roll.

## N5.3 example — Hacking Program vs. Trooper in IMM-B

A Reactive Trooper in IMM-B is targeted by an Active Trooper using Move + Trinity. The IMM-B Trooper can declare only Reset as its ARO and applies -3 WIP. Trinity and Reset are resolved as a Face to Face Roll. If the IMM-B Trooper wins the Face to Face Roll, it avoids the Trinity hits and successfully cancels IMM-B. If it loses, the successful Trinity hits are resolved normally.

## Immobilized-B and Carbonite
- Any failed Saving Roll from Carbonite causes the target to enter Immobilized-B State.

## Immobilized-B and Electromagnetic (E/M) Ammunition
- If the target fails a Saving Roll and is HI, TAG, REM, or VH, it also enters Immobilized-B State in addition to Isolated as specified by E/M Ammunition.

## Immobilized-B and Cybermines
- Hackable Troopers and Hackers that fail either applicable Cybermine Saving Roll enter Immobilized-B State instead of Stunned State.

## FAQ v0.1

Q: In the Active Turn, if a Peripheral's Controller is unable to declare a Skill because it is Stunned, Immobilized, etc., can the Peripheral still declare the Skill?

A: Yes. The Controller and all Peripherals declare the same Skill; any individual game element that cannot perform it executes Idle instead.

**[UNOFFICIAL COMMENT]**
IMM-B is a declaration lockout except for Reset. Automatic Skills/Equipment still function, but they do not create additional legal Skill declarations. The N5.3 example specifically confirms the common hacking case: Reset can oppose a Comms Attack such as Trinity in a Face to Face Roll and, if successful, also cancels IMM-B.
