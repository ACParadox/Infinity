# Category: Null

> **N5.3 change (September 2026):** The rules now explicitly list **Dead, Disconnected, Possessed, Sepsitorized, and Unconscious** as the five States with the **Null** Label.

Game States and Glossary

## Null Label

A Game State with this Label indicates that, in this state, the Trooper will not provide an Order, or Victory Points, to the player.

## Null States

- Dead State
- Disconnected State
- Possessed State
- Sepsitorized State
- Unconscious State
