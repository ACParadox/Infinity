## New normal unit

### Ioann Bann, Varangian Dog-Warrior

- **Added as a new unit.**
- Fireteam charts were updated in every sectorial to which Ioann Bann belongs.
- InfinityDB post-N5.3 source unit ID: `1940` in the inspected O-12 member data.

## Existing-unit changes

### Najjarun Engineers

- Added **Deactivator**.
- InfinityDB's reconciliation confirms the shared profile equipment resolves to Deactivator across the three native options in the inspected post-N5.3 Haqqislam snapshot.

### Sāchā, Xenotech Hunters

- **Availability updated.**
- InfinityDB's N5.3 reconciliation explicitly verifies current selected AVA 1 entries in Torchlight Brigade, Kestrel Colonial Force, Invincible Army and USAriadna, while noting that a complete faction-wide before/after matrix was not pinned in that audit.
- Treat the official Corvus Belli changelog as authority for the fact that availability changed; use current InfinityDB/Army data for the present roster matrix.

### Racerbots

- **Bangbomb corrected from a Skill to Equipment.**
- This is a classification/data correction, not a newly granted Bangbomb effect.
- InfinityDB notes that native source data can retain both legacy/source buckets; its maintained classification maps Bangbomb as Equipment.

## Fireteam impact

- Fireteam charts were updated to support the new Spec-Ops / Team-Ops system.
- Ioann Bann's applicable sectorial Fireteam charts were updated.

## Related N5.3 rules changes that can alter unit-profile interpretation

These are rules/weapon changes rather than individual Army-profile balance changes, but they materially affect profiles carrying the relevant item:

- Kobra Pistol: **Shock** in BS Mode; **DA** in CC Mode.
- Trench-Hammer: no longer **Disposable (3)**.
- Added **Breaker Sniper Rifle**, **AP Red Fury**, and **AP Thunderbolt**.
- Added Thunderbolt weapon category.
- Firewall and Hacking Devices are explicitly **Automatic Equipment**.
- Deployable Cover becomes **Disposable (2)** and **Perimeter**.

For the full rules-side changes, see `rules/N5.3_Changes.md` and the versioned N5.3 rule reference files.
