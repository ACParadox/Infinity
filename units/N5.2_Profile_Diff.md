## Source conflicts / unresolved exact numbers

The release article sometimes says only “costs reviewed.” The affected profile is still present above, but this file does not invent an old/new number where the exact semantic option pairing is uncertain. The pinned historical JSON remains the source for a future field-level audit of those individual option IDs.

This distinction is intentional: **complete coverage of affected profiles is more important than manufacturing false precision from reordered/replaced option IDs.**
